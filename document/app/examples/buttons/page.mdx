# Buttons

Create calls to action for common tasks, from a single primary action to grouped controls.

## Variants

Use a solid button for the main action, an outline for a secondary choice, and a text variant for
lower-emphasis actions.

<CodeExample>
    <div className="d-flex flex-wrap align-items-center gap-3">
        <Button variant="solid" theme="primary">
            Get started
        </Button>
        <Button variant="outline" theme="secondary">
            Learn more
        </Button>
        <Button variant="text" theme="primary">
            Cancel
        </Button>
    </div>
</CodeExample>

## Button group

Group actions that share a context.

<CodeExample>
    <ButtonGroup aria-label="Text alignment">
        <Button variant="outline" theme="secondary" active>
            Left
        </Button>
        <Button variant="outline" theme="secondary">
            Center
        </Button>
        <Button variant="outline" theme="secondary">
            Right
        </Button>
    </ButtonGroup>
</CodeExample>
