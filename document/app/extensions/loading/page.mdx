# Loading

[`Loading`][1] shows a full-page loading overlay with a [Spinner](../../components/spinner/) and a message. It
covers the viewport with a translucent backdrop, so render it only while blocking work is running.

## Example

<CodeExample
    source="document/component/Documentation/Components/LoadingDemo.tsx"
    code={`<Button onClick={showLoading}>Show loading</Button>

{loading && <Loading>Loading...</Loading>}`}

>

    <LoadingDemo />

</CodeExample>

## Usage

<CodeCard>{`import { Loading } from 'idea-react';

{
uploading && <Loading>Uploading…</Loading>;
}`}</CodeCard>

The children replace the default `Loading...` text. For loading states inside a button or a table,
use the [Spinner button](../spinner-button/) or [Table spinner](../table-spinner/) instead.

Set `opacity={100}` for a fully opaque backdrop, such as while restoring persisted application state.
Keep the covered content `inert` until restoration finishes so keyboard focus cannot enter it.
