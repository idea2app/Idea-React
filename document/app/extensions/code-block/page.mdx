# Code block

[`CodeBlock`][1] renders syntax-highlighted code with [Shiki][2]. String children are highlighted
as-is, while React elements are serialized to JSX source first.

## Example

<CodeBlock language="tsx" className="border rounded p-3">
    {`export const Hello = () => <strong>Hello, Idea React!</strong>;`}
</CodeBlock>

## Language

`language` accepts `javascript`, `jsx`, `typescript`, or `tsx`. The highlighted markup is injected
inline, so the block needs no client-side JavaScript.

## Color scheme

Highlight colors follow the inherited CSS `color-scheme`: `light`, `dark`, or `light dark`
to follow the system preference. Bootstrap theme containers work automatically, including
nested containers with a different theme. Changing the scheme updates highlighting without
rerendering the component.
