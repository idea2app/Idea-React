# Spinner button

[`SpinnerButton`][1] extends [Button](../../components/button/) with a `loading` state that shows an inline
[Spinner](../../components/spinner/) and disables the button while work is in progress.

## Example

<LiveExample>
    <div className="d-flex flex-wrap gap-2">
        <SpinnerButton theme="primary" animation="border" loading />
        <SpinnerButton theme="primary" animation="grow" type="submit" loading>
            Submit
        </SpinnerButton>
    </div>
</LiveExample>

## Usage

<CodeCard>
    <SpinnerButton theme="primary" animation="grow" loading>
        Submit
    </SpinnerButton>
</CodeCard>

All [Button](../../components/button/) props pass through, and `animation` selects the spinner animation. When the
button has no children while loading, a visually hidden "Loading..." label keeps it accessible.
