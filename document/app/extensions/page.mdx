# Idea React extensions

Idea React complements Bootstrap 6 with reusable React and MobX components. Each extension has its
own guide, linked below with its primary purpose.

| Export                | Guide                                       | Purpose                                             |
| --------------------- | ------------------------------------------- | --------------------------------------------------- |
| `ClickBoundary`       | [Click boundary](./click-boundary/)         | Detects clicks outside a component boundary         |
| `CodeBlock`           | [Code block](./code-block/)                 | Syntax-highlighted code block                       |
| `Countdown`           | [Countdown](./countdown/)                   | Renders a countdown from a target time              |
| `Dialog`              | [Dialog model](./dialog-model/)             | Collects dialog results through promises            |
| `MarkdownView`        | [Markdown view](./markdown-view/)           | Synchronous Markdown rendering with GitHub styles   |
| `HorizontalMarquee`   | [Horizontal marquee](./horizontal-marquee/) | Horizontally scrolls overflowing content            |
| `Icon`                | [Icon](./icon/)                             | Bootstrap Icons font wrapper                        |
| `LiveTSX`             | [Live TSX](./live-tsx/)                     | Renders editable or evaluated TSX examples          |
| `Loading`             | [Loading](./loading/)                       | Full-page loading overlay                           |
| `MonthCalendar`       | [Month calendar](./month-calendar/)         | Interactive month grid with selectable date entries |
| `Nameplate`           | [Nameplate](./nameplate/)                   | Displays a person with an avatar and name           |
| `OverlayBox`          | [Overlay box](./overlay-box/)               | Adds tooltip and popover triggers and positioning   |
| `PageNav`             | [Page nav](./page-nav/)                     | Builds a table of contents from page headings       |
| `ScrollNav`           | [Scroll nav](./scroll-nav/)                 | Horizontally scrollable navigation                  |
| `Select` and `Option` | [Select](./select/)                         | Accessible menu-backed value selector               |
| `ShareBox`            | [Share box](./share-box/)                   | Captures content as a shareable image               |
| `SpinnerButton`       | [Spinner button](./spinner-button/)         | Button with an inline loading indicator             |
| `TableSpinner`        | [Table spinner](./table-spinner/)           | Loading row for a data table                        |
| `TextTruncate`        | [Text truncate](./text-truncate/)           | Expands and collapses long text                     |
| `Time`                | [Time](./time/)                             | Formats a date or time value                        |
| `TimeDistance`        | [Time distance](./time-distance/)           | Displays relative time distance                     |
| `Timeline`            | [Timeline](./timeline/)                     | Presents chronological events                       |
| `TypeEcho`            | [Type echo](./type-echo/)                   | Animates typed text                                 |
| `UserRankView`        | [User rank](./user-rank/)                   | Displays ranked users                               |
| `VerticalMarquee`     | [Vertical marquee](./vertical-marquee/)     | Vertically scrolls overflowing content              |
| `ZodiacBar`           | [Zodiac bar](./zodiac-bar/)                 | Displays zodiac signs for a year range              |

Core Bootstrap component wrappers are documented in the [component catalog][1]. Source files and
public API types are available in the [API reference][2].

For rich-text editing, see the [React Bootstrap Editor guide][3]. It demonstrates
the separate `react-bootstrap-editor` package, not an Idea React export.
