# Idea React extensions

Idea React complements Bootstrap 6 with reusable React and MobX components. Each extension has its
own guide, linked below with its primary purpose.

| Export                   | Purpose                                             |
| ------------------------ | --------------------------------------------------- |
| [`ClickBoundary`][1]     | Detects clicks outside a component boundary         |
| [`CodeBlock`][2]         | Syntax-highlighted code block                       |
| [`Countdown`][3]         | Renders a countdown from a target time              |
| [`DialogBox`][4] model  | Collects dialog results through promises            |
| [`MarkdownView`][5]      | Synchronous Markdown rendering with GitHub styles   |
| [`HorizontalMarquee`][6] | Horizontally scrolls overflowing content            |
| [`Icon`][7]              | Bootstrap Icons font wrapper                        |
| [`LiveTSX`][8]           | Renders editable or evaluated TSX examples          |
| [`Loading`][9]           | Full-page loading overlay                           |
| [`MonthCalendar`][10]    | Interactive month grid with selectable date entries |
| [`Nameplate`][11]        | Displays a person with an avatar and name           |
| [`OverlayBox`][12]       | Adds tooltip and popover triggers and positioning   |
| [`PageNav`][13]          | Builds a table of contents from page headings       |
| [`ScrollNav`][14]        | Horizontally scrollable navigation                  |
| [`ShareBox`][15]         | Captures content as a shareable image               |
| [`SpinnerButton`][16]    | [Button][17] with an inline loading indicator       |
| [`TableSpinner`][18]     | Loading row for a data table                        |
| [`TextTruncate`][19]     | Expands and collapses long text                     |
| [`Time`][20]             | Formats a date or time value                        |
| [`TimeDistance`][21]     | Displays relative time distance                     |
| [`Timeline`][22]         | Presents chronological events                       |
| [`TypeEcho`][23]         | Animates typed text                                 |
| [`UserRankView`][24]     | Displays ranked users                               |
| [`VerticalMarquee`][25]  | Vertically scrolls overflowing content              |
| [`ZodiacBar`][26]        | Displays zodiac signs for a year range              |

Core Bootstrap component wrappers are documented in the [component catalog][27]. Source files and
public API types are available in the [API reference][28].

Related libraries such as rich-text editing are listed in the [Ecosystem][29].
