# Select

[`Select`][1] is an accessible value selector built on the [Menu](../../components/menu/) component: a button
toggles a keyboard-navigable menu of `Option` items.

## Example

<CodeExample
    source="document/component/Documentation/Components/SelectDemo.tsx"
    code={`<Select value={value} onChange={setValue}>
    <Option value="0">idea2app</Option>
    <Option value="1">freeCodeCamp</Option>
</Select>`}
>
    <SelectDemo />
</CodeExample>

## Usage

`Select` is controlled: pass the current `value` and update it in `onChange`.

<CodeCard>
    <Select value="react" onChange={() => {}}>
        <Option value="react">React</Option>
        <Option value="vue">Vue</Option>
    </Select>
</CodeCard>

The toggle shows the selected option's content, or render a custom label with `valueRender`. Button
styling props such as `theme`, `variant`, `size`, and `disabled` pass through to the toggle, and
`align` positions the menu.

Set `placeholder` for an empty selection and `name` to submit the controlled value through a hidden
native form field. Disabled selectors do not submit values, and disabled options cannot be selected.
Selected options expose their selected state. For searchable, grouped or multiple choices, use
the [Combobox][2] form component instead.
