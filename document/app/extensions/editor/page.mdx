# React Bootstrap Editor

[React Bootstrap Editor][1] is a separate rich-text editor library built on [Edkit][2],
React, MobX, and Bootstrap. Idea React no longer exports an `Editor` component;
import `Editor` directly from `react-bootstrap-editor`.

## Install

```sh
npm install react-bootstrap-editor mobx mobx-react react react-dom
```

The current 3.x release uses Bootstrap 6 and stage-3 decorators. Keep
`experimentalDecorators` disabled and `useDefineForClassFields` enabled in TypeScript.

## Example

The editor runs in the browser. In a server-rendered application, put the smallest
component that mounts it behind a client boundary.

<DocumentCodeExample source="document/component/Document/EditorDemo.tsx">
    <DocumentEditorDemo />
</DocumentCodeExample>

The `defaultValue` is an HTML string. The editor keeps a hidden input named by
`name` in sync with the current markup, so a native form submission can read it.
`onChange` receives the updated HTML string. The `tools` prop accepts a list of
Edkit tool constructors; omitting it uses the library's default toolbar.

## Display content

Editor output is HTML, not Markdown. Only render trusted or sanitized HTML in
your application. Use [MarkdownView][3] for Markdown source instead.

See the [upstream demo][4] and [editor API][5] for toolbar customization and media tools.
