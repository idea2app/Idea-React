# Editor

[`Editor`][1] embeds the block-style [Editor.js][2] rich text editor as a Bootstrap form control.
The editor saves its data into a hidden `<input>`, so it participates in native form submission.

## Usage

Editor.js only runs in the browser, so render the component on the client:

<CodeBlock language="tsx">{`import { Button, Editor, Form } from 'idea-react';

<Form method="post">
    <Editor name="content" required defaultValue={savedDocument} tools={customTools} />
    <Button variant="solid" theme="primary">Save</Button>
</Form>;`}</CodeBlock>

The wrapper saves on blur and serializes the latest Editor.js `OutputData` as JSON into the hidden
input named by `name`. All [react-editor-js props][3], such as `tools` and `onInitialize`, pass
through to the underlying editor.

Render saved documents with the [Editor HTML](../editor-html/) component.
