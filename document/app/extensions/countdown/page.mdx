# Countdown

[`Countdown`][1] renders the remaining time to a target moment as a list of time sections, updating
every second until the end time is reached.

## Example

<LiveExample>
    <Countdown
        className="d-flex gap-3"
        endTime="2035-01-01T00:00:00"
        units={[
            { scale: 24, label: 'days' },
            { scale: 60, label: 'hours' },
            { scale: 60, label: 'minutes' },
            { scale: 1000, label: 'seconds' }
        ]}
    />
</LiveExample>

## Units

`units` lists the sections from largest to smallest. Each `scale` is the amount of the next smaller
unit that makes up one of the current unit, ending at milliseconds.

<CodeCard>
    <Countdown
        endTime="2030-01-01T00:00:00"
        units={[
            { scale: 24, label: 'days' },
            { scale: 60, label: 'hours' },
            { scale: 60, label: 'minutes' },
            { scale: 1000, label: 'seconds' }
        ]}
        onEnd={endTime => console.log('Finished at', endTime)}
    />
</CodeCard>

`itemClassName` styles each section, and `onEnd` fires once when the countdown reaches zero.
