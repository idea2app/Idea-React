# Forms

Idea React wraps native form elements with Bootstrap 6 styling. Native names, values, constraints,
refs, autocomplete and accessibility attributes pass through.

## Quick start

<CodeExample>
    <Form aria-label="Profile">
        <FormField>
            <FormLabel htmlFor="overviewEmail">Email address</FormLabel>
            <FormControl
                id="overviewEmail"
                name="email"
                type="email"
                required
                aria-describedby="overviewHelp"
            />
            <FormText id="overviewHelp">We will never share your email.</FormText>
        </FormField>
        <FormFieldset disabled className="mt-3">
            <FormLegend>Unavailable settings</FormLegend>
            <FormControl aria-label="Unavailable setting" placeholder="Disabled by the fieldset" />
        </FormFieldset>
    </Form>
</CodeExample>

Use `FormField` for labels, descriptions and feedback; `FormGroup` groups related fields.
`FormFieldset disabled` disables its native descendants. Always provide visible labels or
accessible names and connect help text with `aria-describedby`. A readonly control remains
focusable and submitted; a disabled control does not.
