# Combobox

A customizable select-like component built with markup-first HTML, powered by the Menu component for positioning and keyboard navigation.

## Overview

The combobox component provides a styled select experience using a `Combobox` with `ComboboxOption` children — rendered as a toggle button paired with a menu overlay. Unlike traditional select enhancements, the combobox is markup-first: you declare the options as React children. The JavaScript handles show/hide, selection state, form submission via a hidden input, and keyboard navigation.

- Full control over menu item content (icons, descriptions, badges, images — anything)
- Live search/filtering
- Check mark indicators for selected items
- Single and multiple selection modes
- Full keyboard navigation and accessibility
- Form submission via auto-created hidden input

## Example

Use `Combobox` with `ComboboxOption` children. Each selectable option needs a `value` prop.

<DocumentCodeExample>
    <Combobox name="option" placeholder="Select an item…">
        <ComboboxOption value="1">Option one</ComboboxOption>
        <ComboboxOption value="2">Option two</ComboboxOption>
        <ComboboxOption value="3">Option three</ComboboxOption>
    </Combobox>
</DocumentCodeExample>

### Placeholders

Set placeholder text with the `placeholder` prop. The `.combobox-value` element shows this text when nothing is selected, styled with `.combobox-placeholder`.

<DocumentCodeExample>
    <Combobox name="country" placeholder="Pick a country…">
        <ComboboxOption value="us">United States</ComboboxOption>
        <ComboboxOption value="uk">United Kingdom</ComboboxOption>
        <ComboboxOption value="ca">Canada</ComboboxOption>
    </Combobox>
</DocumentCodeExample>

### Pre-selected value

Set `defaultValue` on `Combobox` to pre-select an option, or use `value` and `onChange` for controlled selection. The toggle text updates automatically on initialization.

<DocumentCodeExample>
    <Combobox name="role" placeholder="Choose a role…" defaultValue="editor">
        <ComboboxOption value="admin">Admin</ComboboxOption>
        <ComboboxOption value="editor">Editor</ComboboxOption>
        <ComboboxOption value="viewer">Viewer</ComboboxOption>
    </Combobox>
</DocumentCodeExample>

### With form field

Use the [form field][1] component to layout and wrap your combobox with a label, description, and validation feedback messages in a vertical stack.

<DocumentCodeExample>
    <FormField>
        <FormLabel htmlFor="exampleCombobox">Combobox</FormLabel>
        <Combobox id="exampleCombobox" name="country" placeholder="Pick a country…">
            <ComboboxOption value="us">United States</ComboboxOption>
            <ComboboxOption value="uk">United Kingdom</ComboboxOption>
            <ComboboxOption value="ca">Canada</ComboboxOption>
        </Combobox>
    </FormField>
</DocumentCodeExample>

## Form submission

The combobox creates a hidden `<input>` for form submission using the required `name` prop. The hidden input’s `name` matches the prop and its `value` updates whenever the selection changes.

```tsx
<Combobox name="country" defaultValue="us">
    <ComboboxOption value="us">United States</ComboboxOption>
    <ComboboxOption value="ca">Canada</ComboboxOption>
</Combobox>
```

For multiple selection, the component creates one hidden input per selected value, all sharing the same name. Read these values with `FormData.getAll(name)`.

## Usage

`Combobox` manages selection with `defaultValue`, or `value` and `onChange` for controlled state. Pass `search`, `searchNormalize`, `multiple`, and sizing options as props; no plugin initialization is needed.

### Options

Pass options directly as `Combobox` props. The wrapper manages the menu and form inputs.

| Name              | Type    | Default  | Description                                                          |
| ----------------- | ------- | -------- | -------------------------------------------------------------------- |
| `multiple`        | boolean | `false`  | Enable multi-select mode. Selections toggle and the menu stays open. |
| `name`            | string  | Required | Name for the auto-created hidden inputs.                             |
| `placeholder`     | string  | `''`     | Placeholder text for the toggle.                                     |
| `search`          | boolean | `false`  | Enable search input in the menu.                                     |
| `searchNormalize` | boolean | `false`  | Normalize accented characters for search matching.                   |

## Accessibility

The combobox component follows WAI-ARIA combobox patterns:

- The toggle button has `aria-haspopup="listbox"` and `aria-expanded`.
- Each `ComboboxOption` receives `role="option"` and `aria-selected` automatically.
- Full keyboard navigation: Arrow keys, Home, End, Enter, Space, Escape, and Tab.
- Disabled items have the `disabled` attribute and `aria-disabled="true"`.

## CSS custom properties

The combobox uses CSS custom properties prefixed with `--bs-combobox-*` for the toggle, and inherits `--bs-menu-*` properties from the Menu component for the menu overlay. See the [source SCSS][2] for the full list of available tokens.
