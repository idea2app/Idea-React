# Combobox

A searchable value selector built on the library's keyboard-navigable `Menu`. Options can contain
custom React content, icons, descriptions and selected check indicators.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="comboboxLanguage">Language</FormLabel>
        <Combobox
            id="comboboxLanguage"
            name="language"
            defaultValue="ts"
            placeholder="Choose a language"
            search
            searchNormalize
        >
            <ComboboxGroup label="Web">
                <ComboboxOption
                    value="js"
                    icon="filetype-js"
                    description="Browser scripting"
                    checkedIcon
                >
                    JavaScript
                </ComboboxOption>
                <ComboboxOption
                    value="ts"
                    icon="filetype-tsx"
                    description="Typed JavaScript"
                    checkedIcon
                >
                    TypeScript
                </ComboboxOption>
            </ComboboxGroup>
            <ComboboxGroup label="Other">
                <ComboboxOption value="unavailable" disabled>
                    Unavailable
                </ComboboxOption>
            </ComboboxGroup>
        </Combobox>
    </FormField>
    <Combobox
        name="skills"
        defaultValue={['react', 'ts']}
        multiple
        controlSize="sm"
        placeholder="Choose skills"
        className="mt-3"
    >
        <ComboboxOption value="react" checkedIcon>
            React
        </ComboboxOption>
        <ComboboxOption value="ts" checkedIcon>
            TypeScript
        </ComboboxOption>
        <ComboboxOption value="css" checkedIcon>
            CSS
        </ComboboxOption>
    </Combobox>
</CodeExample>

Use `value` / `onChange` for controlled selection or `defaultValue` for internal MobX state.
`multiple` uses string arrays, keeps the menu open and shows a count for multiple selections.
Selected values submit hidden fields under `name`; disabled fields do not submit.

`search` filters options; `searchNormalize` ignores accents. Override `searchText` on rich options,
and customize `searchPlaceholder` / `noResultsText`. Groups without matching choices are hidden.
Use `controlSize="sm"` or `"lg"`, `disabled`, and `validation` for sizing and states.
For asynchronous choices, load data in your model and replace the option children; controlled
values remain intact while results load.

Arrow keys, Home/End, Escape and Tab use the shared Menu behavior. Associate a visible label with
`id`, or provide `aria-label`. The popup exposes listbox, option and selected states.
