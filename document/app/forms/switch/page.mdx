# Switch

`FormSwitch` wraps a native checkbox with switch semantics and an optional inline label.

## Quick start

<CodeExample>
    <FormSwitch inputProps={{ name: 'notifications', defaultChecked: true }} theme="success">
        Notifications
    </FormSwitch>
    <FormField className="mt-3">
        <FormSwitch
            size="lg"
            width="2.75rem"
            indicatorWidth="1.5rem"
            inputProps={{ id: 'switchSync', name: 'sync' }}
        />
        <FormLabel plain htmlFor="switchSync">
            Automatic sync
        </FormLabel>
        <FormText>Keep changes up to date.</FormText>
    </FormField>
    <FormSwitch className="mt-3" size="sm" inputProps={{ disabled: true, defaultChecked: true }}>
        Disabled
    </FormSwitch>
</CodeExample>

Pass native state, events, disabled state, names and accessibility attributes in `inputProps`.
Use `size="sm"` or `"lg"`, any `theme`, and optional `width` / `indicatorWidth` for custom proportions.
`validation` applies feedback styling. A separate label must target `inputProps.id`.
