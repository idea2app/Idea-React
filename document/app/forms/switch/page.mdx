# Switch

Custom toggle component built on top of native `<input>` checkbox elements.

## Basic switch

Switches work by layering an invisible checkbox over the custom switch indicator. This preserves interactivity while giving you a completely customizable layer underneath. `FormSwitch` supplies `role="switch"` on the checkbox. Pass native input attributes through `inputProps`.

<CodeExample>
    <FormSwitch inputProps={{ defaultValue: '', id: 'switch' }} />
</CodeExample>

## With form field

Wrap `FormSwitch` in a `FormField` layout wrapper and add your label. The grid layout places the switch and label side by side.

<CodeExample>
    <div className="d-flex flex-column gap-3">
        <FormField>
            <FormSwitch inputProps={{ defaultValue: '', id: 'switchMdLabel' }} />
            <FormLabel htmlFor="switchMdLabel" plain>
                Default switch
            </FormLabel>
        </FormField>
    </div>
</CodeExample>

## Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter color to help indicate the input’s state.

<CodeExample>
    <Stack className="gap-2">
        <FormField>
            <FormSwitch
                inputProps={{ defaultValue: '', id: 'switchDisabledLabel', disabled: true }}
            />
            <FormLabel htmlFor="switchDisabledLabel" plain>
                Disabled switch
            </FormLabel>
        </FormField>
        <FormField>
            <FormSwitch
                inputProps={{
                    defaultValue: '',
                    id: 'switchCheckedDisabledLabel',
                    disabled: true,
                    defaultChecked: true
                }}
            />
            <FormLabel htmlFor="switchCheckedDisabledLabel" plain>
                Disabled checked switch
            </FormLabel>
        </FormField>
    </Stack>
</CodeExample>

## Custom width

Customize your switch for any width and indicator size you need by overriding the CSS variables. For example, for a more modern look, you could widen the switch and indicator.

<CodeExample>
    <div className="d-flex flex-column gap-3">
        <FormField>
            <FormSwitch
                inputProps={{ defaultValue: '', id: 'switchCustomWidth' }}
                width="2.75rem"
                indicatorWidth="1.5rem"
            />
            <FormLabel htmlFor="switchCustomWidth" plain>
                Custom width switch
            </FormLabel>
        </FormField>
    </div>
</CodeExample>
