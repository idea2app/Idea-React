# Switch

Custom toggle component built on top of native `<input>` checkbox elements.

## Basic switch

Switches work by layering an invisible checkbox over the custom switch indicator. This preserves interactivity while giving you a completely customizable layer underneath. `FormSwitch` supplies `role="switch"` on the checkbox. Pass native input attributes such as `id`, `name`, `disabled`, and `defaultChecked` directly to `FormSwitch`.

<DocumentCodeExample>
    <FormSwitch defaultValue="" id="switch" />
</DocumentCodeExample>

## With form field

Wrap `FormSwitch` in a `FormField` layout wrapper and add your label. The grid layout places the switch and label side by side.

<DocumentCodeExample>
    <div className="d-flex flex-column gap-3">
        <FormField>
            <FormSwitch defaultValue="" id="switchMdLabel" />
            <FormLabel htmlFor="switchMdLabel" plain>
                Default switch
            </FormLabel>
        </FormField>
    </div>
</DocumentCodeExample>

## Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter color to help indicate the input’s state.

<DocumentCodeExample>
    <Stack gap={2}>
        <FormField>
            <FormSwitch defaultValue="" id="switchDisabledLabel" disabled />
            <FormLabel htmlFor="switchDisabledLabel" plain>
                Disabled switch
            </FormLabel>
        </FormField>
        <FormField>
            <FormSwitch defaultValue="" id="switchCheckedDisabledLabel" disabled defaultChecked />
            <FormLabel htmlFor="switchCheckedDisabledLabel" plain>
                Disabled checked switch
            </FormLabel>
        </FormField>
    </Stack>
</DocumentCodeExample>

## Custom width

Customize your switch for any width and indicator size you need by overriding the CSS variables. For example, for a more modern look, you could widen the switch and indicator.

<DocumentCodeExample>
    <div className="d-flex flex-column gap-3">
        <FormField>
            <FormSwitch
                defaultValue=""
                id="switchCustomWidth"
                width="2.75rem"
                indicatorWidth="1.5rem"
            />
            <FormLabel htmlFor="switchCustomWidth" plain>
                Custom width switch
            </FormLabel>
        </FormField>
    </div>
</DocumentCodeExample>

### Variables

```css
.example {
    --bs-switch-height: 1.25rem;
    --bs-switch-width: calc(var(--bs-switch-height) * 1.75);
    --bs-switch-padding: 0.0625rem;
    --bs-switch-margin-block: 0.125rem;
    --bs-switch-transition-duration: var(--bs-control-transition-duration);
    --bs-switch-transition-timing: var(--bs-control-transition-timing);
    --bs-switch-bg: var(--bs-bg-3);
    --bs-switch-border-width: var(--bs-border-width);
    --bs-switch-border-color: var(--bs-border-color);
    --bs-switch-indicator-bg: var(--bs-white);
    --bs-switch-indicator-width: calc(
        var(--bs-switch-height) - var(--bs-switch-padding) * 2 - var(--bs-switch-border-width) * 2
    );
    --bs-switch-indicator-height: calc(
        var(--bs-switch-height) - var(--bs-switch-padding) * 2 - var(--bs-switch-border-width) * 2
    );
    --bs-switch-checked-bg: var(--bs-control-checked-bg);
    --bs-switch-checked-border-color: var(--bs-switch-checked-bg);
    --bs-switch-checked-indicator-bg: var(--bs-white);
    --bs-switch-disabled-bg: var(--bs-control-disabled-bg);
    --bs-switch-disabled-indicator-bg: var(--bs-fg-3);
}
```
