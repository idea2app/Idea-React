# Password strength

`PasswordStrength` loads Bootstrap's password scorer and associates it with a password input in
the same parent, or an explicit `input` selector/element. It exposes accessible meter values.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="strengthPassword">Password</FormLabel>
        <FormControl id="strengthPassword" type="password" autoComplete="new-password" />
        <PasswordStrength
            input="#strengthPassword"
            aria-label="Password strength"
            minLength={10}
            messages={{ weak: 'Try a longer password' }}
        />
    </FormField>
    <FormField className="mt-3">
        <FormLabel htmlFor="strengthBarPassword">Password with bar meter</FormLabel>
        <FormControl id="strengthBarPassword" type="password" />
        <PasswordStrength input="#strengthBarPassword" variant="bar" showText={false} />
    </FormField>
    <PasswordStrength strength="fair" className="mt-3" aria-label="Static fair password" />
    <PasswordStrength
        strength="strong"
        variant="bar"
        showText={false}
        className="mt-3"
        aria-label="Static strong password"
    />
</CodeExample>

The four levels are `weak`, `fair`, `good` and `strong`. The default scorer considers minimum
length, extra length, upper/lowercase letters, digits and special characters.
Customize `minLength`, `weights`, `thresholds`, `messages`, or supply a `scorer`.
`showText={false}` hides feedback. `strength` renders a static CSS-only meter and skips plugin
initialization; omit it for live scoring. A strength hint is not a substitute for server validation.
