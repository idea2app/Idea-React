# Range

Use our custom range inputs for consistent cross-browser styling with a filled track, value bubble, and tick marks.

## Overview

The native `<input type="range">` is hard to style and can’t show a filled track in a consistent, cross-browser way using CSS alone—only Firefox offers `::-moz-range-progress`, and CSS can’t read an input’s value. So our range is a small **JavaScript component**: use `FormRange`, which wraps a native range input, and the plugin keeps a `--bs-range-fill` custom property (0–1) in sync, which the CSS uses to draw the fill, the value bubble, and tick marks.

`FormRange` owns the component's theme tokens, so the input and any decorations inherit them. Each mounted component initializes automatically.

<CodeExample>
    <FormLabel htmlFor="range1">Example range</FormLabel>
    <FormRange id="range1" />
</CodeExample>

## Disabled

Add the `disabled` boolean attribute on the input to give it a grayed out appearance, remove pointer events, and prevent focusing.

<CodeExample>
    <FormLabel htmlFor="disabledRange">Disabled range</FormLabel>
    <FormRange id="disabledRange" disabled />
</CodeExample>

## Min and max

Range inputs have implicit values for `min` and `max`—`0` and `100`, respectively. You may specify new values for those using the `min` and `max` attributes.

<CodeExample>
    <FormLabel htmlFor="range2">Example range</FormLabel>
    <FormRange min="0" max="5" id="range2" />
</CodeExample>

## Steps

By default, range inputs “snap” to integer values. To change this, you can specify a `step` value. In the example below, we double the number of steps by using `step="0.5"`.

<CodeExample>
    <FormLabel htmlFor="range3">Example range</FormLabel>
    <FormRange min="0" max="5" step="0.5" id="range3" />
</CodeExample>

## Value bubble

Set `bubble` to show a value bubble that follows the thumb. The bubble reuses our [tooltip][1] styles.

<CodeExample>
    <FormLabel htmlFor="rangeBubble">Brightness</FormLabel>
    <FormRange min="0" max="100" defaultValue="60" id="rangeBubble" bubble />
</CodeExample>

## Tick marks

Link a `<datalist>` to the input with the `list` attribute and the plugin renders a tick mark for each `<option>`, positioned at its value (even when the values are unevenly spaced). An `<option>`’s `label` is shown beneath its tick.

<CodeExample>
    <FormLabel htmlFor="rangeTicks">Temperature</FormLabel>
    <FormRange
        min="0"
        max="100"
        step="25"
        defaultValue="50"
        list="rangeTicksList"
        id="rangeTicks"
    />
    <datalist id="rangeTicksList">
        <option label="Cold" value="0" />
        <option value="25" />
        <option label="Mild" value="50" />
        <option value="75" />
        <option label="Hot" value="100" />
    </datalist>
</CodeExample>

## With form field

Wrap `FormRange` in `FormField` to pair it with a label and description.

<CodeExample>
    <FormField>
        <FormLabel htmlFor="rangeField">Volume</FormLabel>
        <FormRange id="rangeField" bubble />
        <FormText>Adjust the volume level.</FormText>
    </FormField>
</CodeExample>

## Usage

`FormRange` initializes and disposes the plugin automatically. Pass `bubble` and `formatter` as props, and use `onValueChange` for numeric updates. Native `value` and `defaultValue` control the input value.

Each `FormRange` is initialized automatically when mounted—the component is JavaScript-driven, so the fill won’t render without the plugin.

### Options

| Name        | Type     | Default | Description                                                  |
| ----------- | -------- | ------- | ------------------------------------------------------------ |
| `bubble`    | boolean  | `false` | Show a value bubble above the thumb.                         |
| `formatter` | function | `null`  | `(value) => string` used for the bubble and tick label text. |
