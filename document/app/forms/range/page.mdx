# Range

`FormRange` wraps a native range input in `.form-range`. The wrapper updates the `--range-fill`
property as the input changes. The optional value bubble is provided by Bootstrap's JavaScript
plugin.

## Overview

<CodeExample>
    <FormField>
        <FormLabel htmlFor="rangeExample">Example range</FormLabel>
        <FormRange id="rangeExample" defaultValue={50} />
    </FormField>
</CodeExample>

## Theme colors

Pass a theme name to the wrapper:

<CodeExample>
    <FormRange aria-label="Themed range" theme="primary" defaultValue={60} />
</CodeExample>

## Disabled

<CodeExample>
    <FormRange aria-label="Disabled range" disabled />
</CodeExample>

## Min and max

<CodeExample>
    <FormField>
        <FormLabel htmlFor="rangeMinMax">Example range</FormLabel>
        <FormRange id="rangeMinMax" min={10} max={50} defaultValue={20} />
    </FormField>
</CodeExample>

## Steps

Use native `step` to set the allowed increments.

<CodeExample>
    <FormRange aria-label="Range with half steps" min={0} max={10} step={0.5} defaultValue={5} />
</CodeExample>

## Value bubble

<CodeExample>
    <FormField>
        <FormLabel htmlFor="rangeBubble">Brightness</FormLabel>
        <FormRange id="rangeBubble" name="brightness" bubble defaultValue={40} />
    </FormField>
</CodeExample>

## Tick marks

Connect a native `datalist` with the input's `list` attribute.

<CodeExample>
    <>
        <FormRange aria-label="Temperature" list="temperatureTicks" min={0} max={100} />
        <datalist id="temperatureTicks">
            <option value="0" label="Cold" />
            <option value="50" label="Warm" />
            <option value="100" label="Hot" />
        </datalist>
    </>
</CodeExample>

## With form field

Use `FormField` to associate a visible label and description.

## Usage

Every `.form-range` wrapper updates its track fill from the input value. The value bubble requires
Bootstrap's range plugin.

### Via data attributes

`bubble` adds `data-bs-bubble` to the wrapper. The input's native `list` attribute and a `datalist`
provide tick marks.

### Via JavaScript

The range plugin can also be initialized and updated programmatically by the consuming application.

### Dependencies

The JavaScript-powered value bubble and tick marks require Bootstrap's range plugin.

### Options

Native range props such as `min`, `max`, `step`, and `value` are forwarded. The plugin exposes
the optional value bubble.

### Methods

The range plugin supports programmatic updates and disposal.

### Events

The plugin emits a change event when the range value changes.

## CSS

The Bootstrap stylesheet reads `--range-fill` to render the filled track.
