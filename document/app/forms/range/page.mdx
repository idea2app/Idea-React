# Range

`FormRange` initializes Bootstrap's range plugin for a filled track, optional value bubble and
datalist tick marks. The wrapper disposes its plugin on unmount.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="rangeVolume">Volume</FormLabel>
        <FormRange
            id="rangeVolume"
            name="volume"
            min={0}
            max={100}
            step={0.5}
            defaultValue={50}
            bubble
            theme="primary"
            list="rangeVolumeTicks"
            aria-describedby="rangeVolumeHelp"
        />
        <datalist id="rangeVolumeTicks">
            <option value="0" label="Silent" />
            <option value="25" />
            <option value="100" label="Loud" />
        </datalist>
        <FormText id="rangeVolumeHelp">Adjust the volume level.</FormText>
    </FormField>
    <FormRange aria-label="Disabled range" disabled theme="success" className="mt-3" />
</CodeExample>

Native `min`, `max`, `step`, `disabled`, `value` and `defaultValue` pass through. Without a value,
the native midpoint is used. Tick positions can be uneven; option labels appear below them.
`formatter` customizes bubble text, and `onValueChange` reports numeric plugin updates.
Use `onInput` or `onChange` for native events and `wrapperClassName` for wrapper layout.
