# Floating labels

Place the control before its label inside `FormFloatingLabel`. Text inputs and textareas need a
nonempty `placeholder` so their empty state can be detected.

## Quick start

<CodeExample>
    <FormFloatingLabel>
        <FormControl id="floatingEmail" type="email" placeholder="name@example.com" />
        <FormLabel htmlFor="floatingEmail">Email address</FormLabel>
    </FormFloatingLabel>
    <FormFloatingLabel className="mt-3">
        <FormTextArea id="floatingMessage" placeholder="Message" rows={3} />
        <FormLabel htmlFor="floatingMessage">Message</FormLabel>
    </FormFloatingLabel>
    <FormFloatingLabel className="mt-3">
        <FormSelect id="floatingCountry" defaultValue="ca">
            <option value="ca">Canada</option>
        </FormSelect>
        <FormLabel htmlFor="floatingCountry">Country</FormLabel>
    </FormFloatingLabel>
    <FormFloatingLabel always className="mt-3">
        <DatePicker id="floatingDate" />
        <FormLabel htmlFor="floatingDate">Date</FormLabel>
    </FormFloatingLabel>
    <InputGroup className="mt-3">
        <InputGroupText>@</InputGroupText>
        <FormFloatingLabel>
            <FormControl
                id="floatingUsername"
                placeholder="Username"
                validation="invalid"
                aria-describedby="floatingError"
            />
            <FormLabel htmlFor="floatingUsername">Username</FormLabel>
        </FormFloatingLabel>
        <FormFeedback id="floatingError">Choose a username.</FormFeedback>
    </InputGroup>
</CodeExample>

`always` keeps labels floating, useful for date/time and externally populated controls.
Native `disabled`, `readOnly` and `FormControl plaintext` remain supported. Use ordinary grid
utilities around the floating wrappers for responsive layouts, and `FormFeedback` for validation.
Avoid multiple-select and size-expanded select fields inside floating labels.
