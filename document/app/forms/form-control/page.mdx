# Form controls

Give textual `<input>`, `<textarea>`, and `<select>` elements an upgrade with custom styles, sizing, focus states, and more.

> **Heads up!** `<select>` elements are now styled with `.form-control` for ease of use.

Form control styles are available for most textual inputs (including date and time types), textareas, and select elements. We uniformly style them with the `.form-control` class with element-specific modifiers as needed.

<CodeExample>
    <FormLabel htmlFor="exampleFormControlInput" className="mb-2">
        Email address
    </FormLabel>
    <FormControl type="email" id="exampleFormControlInput" placeholder="name@example.com" />
</CodeExample>

## With form field

Use the [form field][1] component to layout and wrap your inputs with a label, description, and validation feedback messages in a vertical stack.

<CodeExample>
    <Stack gap={3}>
        <FormField>
            <FormLabel htmlFor="exampleFormControlInput1">Email address</FormLabel>
            <FormControl
                type="email"
                id="exampleFormControlInput1"
                placeholder="name@example.com"
            />
            <FormText> We’ll never share your email with anyone else. </FormText>
        </FormField>
    </Stack>
</CodeExample>

## Textarea

Textareas use the same `.form-control` class as inputs. Modify their height by using the `rows` attribute or using custom CSS.

<CodeExample>
    <Stack gap={3}>
        <FormField>
            <FormLabel htmlFor="exampleFormControlTextarea1">Example textarea</FormLabel>
            <FormTextArea id="exampleFormControlTextarea1" />
        </FormField>
        <FormField>
            <FormLabel htmlFor="exampleFormControlTextarea2">Taller textarea</FormLabel>
            <FormTextArea id="exampleFormControlTextarea2" rows={4} />
        </FormField>
    </Stack>
</CodeExample>

## Select

Basic select element styles are provided by the `.form-control` class. Styles are limited by the browser—options and popovers cannot be styled.

<CodeExample>
    <FormField>
        <FormLabel htmlFor="exampleFormControlSelect2">Example select</FormLabel>
        <FormSelect id="exampleFormControlSelect2">
            <option>Choose one…</option>
            <option value="1">One</option>
            <option value="2">Two</option>
            <option value="3">Three</option>
        </FormSelect>
    </FormField>
</CodeExample>

The `multiple` attribute is supported on select elements:

<CodeExample>
    <div>
        <FormLabel htmlFor="exampleFormControlSelect3">Multiple select</FormLabel>
        <FormSelect
            id="exampleFormControlSelect3"
            multiple
            aria-label="Multiple select example"
            defaultValue={['Open this select menu']}
        >
            <option>Open this select menu</option>
            <option value="1">One</option>
            <option value="2">Two</option>
            <option value="3">Three</option>
        </FormSelect>
    </div>
</CodeExample>

As is the `size` attribute:

<CodeExample>
    <div>
        <FormLabel htmlFor="exampleFormControlSelect4">Size 3 select</FormLabel>
        <FormSelect
            id="exampleFormControlSelect4"
            size={3}
            aria-label="Size 3 select example"
            defaultValue="Open this select menu"
        >
            <option>Open this select menu</option>
            <option value="1">One</option>
            <option value="2">Two</option>
            <option value="3">Three</option>
        </FormSelect>
    </div>
</CodeExample>

## Form text

Block-level or inline-level form text can be created using `.form-text`.
`FormText` is inline by default; set `block` for descriptions that belong on their own line.

> Form text should be explicitly associated with the form control it relates to using the `aria-describedby` attribute. This will ensure that assistive technologies—such as screen readers—will announce this form text when the user focuses or enters the control.

Form text below inputs can be styled with `.form-text`. If a block-level element will be used, a top margin is added for easy spacing from the inputs above.

<CodeExample>
    <FormLabel htmlFor="inputPassword5">Password</FormLabel>
    <FormControl type="password" id="inputPassword5" aria-describedby="passwordHelpBlock" />
    <FormText id="passwordHelpBlock" block>
        Your password must be 8-20 characters long, contain letters and numbers, and must not
        contain spaces, special characters, or emoji.
    </FormText>
</CodeExample>

Inline text can use any typical inline HTML element (be it a `<span>`, `<small>`, or something else) with nothing more than the `.form-text` class.

<CodeExample>
    <Row className="g-3 align-items-center">
        <Col xs="auto">
            <FormLabel htmlFor="inputPassword6" column>
                Password
            </FormLabel>
        </Col>
        <Col xs="auto">
            <FormControl
                type="password"
                id="inputPassword6"
                aria-describedby="passwordHelpInline"
            />
        </Col>
        <Col xs="auto">
            <FormText id="passwordHelpInline"> Must be 8-20 characters long. </FormText>
        </Col>
    </Row>
</CodeExample>

## States

### Disabled

Add the `disabled` boolean attribute on an input to give it a grayed out appearance, remove pointer events, and prevent focusing.

<CodeExample>
    <Stack gap={3}>
        <FormControl
            type="text"
            placeholder="Disabled input"
            aria-label="Disabled input example"
            disabled
        />
        <FormControl
            type="text"
            defaultValue="Disabled readonly input"
            aria-label="Disabled input example"
            disabled
            readOnly
        />
        <FormSelect
            aria-label="Disabled select example"
            disabled
            defaultValue="Open this select menu"
        >
            <option>Open this select menu</option>
            <option value="1">One</option>
            <option value="2">Two</option>
            <option value="3">Three</option>
        </FormSelect>
        <FormTextArea
            rows={3}
            placeholder="Disabled textarea"
            aria-label="Disabled textarea example"
            disabled
        />
    </Stack>
</CodeExample>

### Readonly

Add the `readonly` boolean attribute on an input to prevent modification of the input’s value. `readonly` inputs can still be focused and selected, while `disabled` inputs cannot.

<CodeExample>
    <FormControl
        type="text"
        defaultValue="Readonly input here..."
        aria-label="readonly input example"
        readOnly
    />
</CodeExample>

### Readonly plain text

If you want to have `<input readonly>` elements in your form styled as plain text, replace `.form-control` with `.form-control-plaintext` to remove the default form field styling and preserve the correct `margin` and `padding`.

<CodeExample>
    <Row className="mb-3">
        <FormLabel htmlFor="staticEmail" column className="sm:col-2">
            Email
        </FormLabel>
        <Col sm={10}>
            <FormControl
                type="text"
                readOnly
                id="staticEmail"
                defaultValue="email@example.com"
                plaintext
            />
        </Col>
    </Row>
    <Row className="mb-3">
        <FormLabel htmlFor="inputPassword" column className="sm:col-2">
            Password
        </FormLabel>
        <Col sm={10}>
            <FormControl type="password" id="inputPassword" />
        </Col>
    </Row>
</CodeExample>

<CodeExample>
    <Form className="row g-3">
        <Col xs="auto">
            <FormLabel htmlFor="staticEmail2" plain className="visually-hidden">
                Email
            </FormLabel>
            <FormControl
                type="text"
                readOnly
                id="staticEmail2"
                defaultValue="email@example.com"
                plaintext
            />
        </Col>
        <Col xs="auto">
            <FormLabel htmlFor="inputPassword2" plain className="visually-hidden">
                Password
            </FormLabel>
            <FormControl type="password" id="inputPassword2" placeholder="Password" />
        </Col>
        <Col xs="auto">
            <Button type="submit" theme="primary" variant="solid" className="mb-3">
                Confirm identity
            </Button>
        </Col>
    </Form>
</CodeExample>

## Types

Nearly all input types are supported, but not all are documented here. Input types requiring additional classes or changes are shown below.

### Date & Time

No additional classes are needed for date and time inputs. Exact functionality and appearance are dependent on the browser and operating system. However, you can also use [our datepicker component][2] to create a more consistent experience across browsers with JavaScript.

<CodeExample>
    <Stack gap={3}>
        <FormControl
            type="datetime-local"
            aria-label="Date and time picker"
            defaultValue="2026-02-24T13:00"
        />
        <FormControl
            type="datetime-local"
            aria-label="Date and time picker with seconds"
            defaultValue="2026-02-24T13:00:30"
            step="1"
        />
        <FormControl
            type="datetime-local"
            aria-label="Date and time picker with milliseconds"
            defaultValue="2026-02-24T13:00:30.500"
            step="0.001"
        />
        <FormControl type="date" aria-label="Date picker" defaultValue="2026-02-24" />
        <FormControl type="time" aria-label="Time picker" defaultValue="13:00" />
        <FormControl type="month" aria-label="Month picker" defaultValue="2026-02" />
        <FormControl type="week" aria-label="Week picker" defaultValue="2026-W09" />
    </Stack>
</CodeExample>

### Color

Set the `type="color"` and add `.form-control-color` to the `<input>` alongside `.form-control`. We use the modifier class to set fixed `height`s and override some inconsistencies between browsers.

<CodeExample>
    <FormLabel htmlFor="exampleColorInput">Color picker</FormLabel>
    <FormControl
        type="color"
        id="exampleColorInput"
        defaultValue="#631aff"
        title="Choose your color"
        color
    />
</CodeExample>

Sizes are also supported:

<CodeExample>
    <Stack gap={3}>
        <div>
            <FormLabel htmlFor="exampleColorInputLg">Large color picker</FormLabel>
            <FormControl
                type="color"
                id="exampleColorInputLg"
                defaultValue="#631aff"
                title="Choose your color"
                color
                controlSize="lg"
            />
        </div>
        <div>
            <FormLabel htmlFor="exampleColorInputSm">Small color picker</FormLabel>
            <FormControl
                type="color"
                id="exampleColorInputSm"
                defaultValue="#631aff"
                title="Choose your color"
                color
                controlSize="sm"
            />
        </div>
    </Stack>
</CodeExample>

### Datalists

Datalists allow you to create a group of `<option>`s that can be accessed (and autocompleted) from within an `<input>`. These are similar to `<select>` elements, but come with more menu styling limitations and differences. While most browsers and operating systems include some support for `<datalist>` elements, their styling is inconsistent at best.

Learn more about [support for datalist elements][3].

<CodeExample>
    <FormLabel htmlFor="exampleDataList">Datalist example</FormLabel>
    <FormControl list="datalistOptions" id="exampleDataList" placeholder="Type to search..." />
    <datalist id="datalistOptions">
        <option value="San Francisco" />
        <option value="New York" />
        <option value="Seattle" />
        <option value="Los Angeles" />
        <option value="Chicago" />
    </datalist>
</CodeExample>

You can also combine with the `.form-control-caret` class to add a caret to inputs without requiring a select element.

<CodeExample>
    <FormLabel htmlFor="exampleDataListCaret">Datalist example with caret</FormLabel>
    <FormControl
        list="datalistOptionsCaret"
        id="exampleDataListCaret"
        placeholder="Type to search..."
        caret
    />
    <datalist id="datalistOptionsCaret">
        <option value="San Francisco" />
        <option value="New York" />
        <option value="Seattle" />
        <option value="Los Angeles" />
        <option value="Chicago" />
    </datalist>
</CodeExample>

### File

`input[type="file"]` elements are styled with the `::file-selector-button` pseudo element to add a button to the input. You only need to add the `.form-control` class, plus any size modifiers you need.

<CodeExample>
    <Stack gap={5}>
        <FormField>
            <FormLabel htmlFor="formFile">Default file input example</FormLabel>
            <FormControl type="file" id="formFile" />
        </FormField>
        <FormField>
            <FormLabel htmlFor="formFileMultiple">Multiple files input example</FormLabel>
            <FormControl type="file" id="formFileMultiple" multiple />
        </FormField>
        <FormField>
            <FormLabel htmlFor="formFileDisabled">Disabled file input example</FormLabel>
            <FormControl type="file" id="formFileDisabled" disabled />
        </FormField>
        <FormField>
            <FormLabel htmlFor="formFileSm">Small file input example</FormLabel>
            <FormControl id="formFileSm" type="file" controlSize="sm" />
        </FormField>
        <FormField>
            <FormLabel htmlFor="formFileLg">Large file input example</FormLabel>
            <FormControl id="formFileLg" type="file" controlSize="lg" />
        </FormField>
    </Stack>
</CodeExample>

### Ghost

Ghost inputs are a special type of input, not native to the browser, that removes all default input styling when your wrapper handles spacing, border, and focus styles. This is useful for custom composites like search bars and command inputs. Swap the `.form-control` class for `.form-ghost` to remove the default styling.

`.form-ghost` removes the input’s focus outline, so consider using `:focus-within` on a parent element to provide a visible focus indicator.

<CodeExample>
    <FormField>
        <FormLabel htmlFor="exampleGhostInput">Search</FormLabel>
        <div className="d-flex align-items-center gap-3 p-3 border rounded-3">
            <Icon name="file-earmark-code" aria-hidden="true" />
            <FormGhost
                type="search"
                id="exampleGhostInput"
                placeholder="Search docs"
                aria-label="Search docs"
            />
        </div>
    </FormField>
</CodeExample>

You can also use the [form-adorn component][4] to provide prebuilt styles for your ghost input.
