# OTP input

One accessible native input is rendered as digit slots. Bootstrap's plugin handles editing,
formatted paste, SMS autofill, masking and keyboard navigation automatically.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="otpCode">Verification code</FormLabel>
        <OTPInput
            id="otpCode"
            name="code"
            length={6}
            groups={[3, 3]}
            separator="-"
            aria-describedby="otpHelp"
        />
        <FormText id="otpHelp">Enter the six-digit code sent to your phone.</FormText>
    </FormField>
    <OTPInput aria-label="Four-digit PIN" length={4} connected mask size="lg" className="mt-3" />
    <OTPInput
        aria-label="Alphanumeric code"
        length={6}
        type="alphanumeric"
        connected
        defaultValue="ABC123"
        validation="valid"
        wrapperClassName="mt-3"
    />
    <OTPInput aria-label="Disabled code" length={6} size="sm" disabled wrapperClassName="mt-3" />
</CodeExample>

`length` controls slot count. Choose `type="numeric"` (default), `"alphanumeric"` or `"alpha"`;
paste strips unsupported characters. `mask` hides slot contents without disabling SMS autofill.
`groups` and `separator` add decorative dividers, and `connected` joins slot borders.

Native `value`, `defaultValue`, `onChange`, `disabled`, `required` and refs target the real input.
`onValueChange` reports sanitized plugin values; `onComplete` reports a filled code.
`validation` styles the container; `className` styles the input, while `wrapperClassName` styles
the slot group. Give the input an accessible label and connect help text with `aria-describedby`.
Slots shrink to fit narrow containers while preserving grouped separators and every digit.
