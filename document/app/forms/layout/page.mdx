# Layout

Give your forms some structure—from inline to horizontal to custom grid implementations—with our form layout options.

## Forms

Every group of form fields should reside in a `<form>` element. Bootstrap provides no default styling for the `<form>` element, but there are some powerful browser features that are provided by default.

- New to browser forms? Consider reviewing [the MDN form docs][1] for an overview and complete list of available attributes.
- `<button>`s within a `<form>` default to `type="submit"`, so strive to be specific and always include a `type`.

Since Bootstrap applies `display: block` and `width: 100%` to almost all our form controls, forms will by default stack vertically. Additional classes can be used to vary this layout on a per-form basis.

## Utilities

[Margin utilities][2] are the easiest way to add some structure to forms. They provide basic grouping of labels, controls, optional form text, and form validation messaging. We recommend sticking to `margin-bottom` utilities, and using a single direction throughout the form for consistency.

Feel free to build your forms however you like, with `<fieldset>`s, `<div>`s, or nearly any other element.

<CodeExample>
    <div className="mb-3">
        <FormLabel htmlFor="formGroupExampleInput">Example label</FormLabel>
        <FormControl
            type="text"
            id="formGroupExampleInput"
            placeholder="Example input placeholder"
        />
    </div>
    <div className="mb-3">
        <FormLabel htmlFor="formGroupExampleInput2">Another label</FormLabel>
        <FormControl
            type="text"
            id="formGroupExampleInput2"
            placeholder="Another input placeholder"
        />
    </div>
</CodeExample>

## Form grid

More complex forms can be built using our grid classes. Use these for form layouts that require multiple columns, varied widths, and additional alignment options. **Requires the `$enable-grid-classes` Sass variable to be enabled** (on by default).

<CodeExample>
    <Row>
        <Col>
            <FormControl type="text" placeholder="First name" aria-label="First name" />
        </Col>
        <Col>
            <FormControl type="text" placeholder="Last name" aria-label="Last name" />
        </Col>
    </Row>
</CodeExample>

## Gutters

By adding [gutter modifier classes][3], you can have control over the gutter width in as well the inline as block direction. **Also requires the `$enable-grid-classes` Sass variable to be enabled** (on by default).

<CodeExample>
    <Row className="g-3">
        <Col>
            <FormControl type="text" placeholder="First name" aria-label="First name" />
        </Col>
        <Col>
            <FormControl type="text" placeholder="Last name" aria-label="Last name" />
        </Col>
    </Row>
</CodeExample>

More complex layouts can also be created with the grid system.

## Horizontal form

Create horizontal forms with the grid by adding the `.row` class to form groups and using `.{breakpoint}:col-*` classes (e.g. `.sm:col-2`) to specify the width of your labels and controls. Be sure to add `.col-form-label` to your `<label>`s as well so they’re vertically centered with their associated form controls.

At times, you maybe need to use margin or padding utilities to create that perfect alignment you need. For example, we’ve removed the `padding-top` on our stacked radio inputs label to better align the text baseline.

<CodeExample>
    <Form>
        <Row className="mb-3">
            <Col as={FormLabel} sm={2} htmlFor="inputEmail3" column>
                Email
            </Col>
            <Col sm={10}>
                <FormControl type="email" id="inputEmail3" />
            </Col>
        </Row>
        <Row className="mb-3">
            <Col as={FormLabel} sm={2} htmlFor="inputPassword3" column>
                Password
            </Col>
            <Col sm={10}>
                <FormControl type="password" id="inputPassword3" />
            </Col>
        </Row>
        <Row as="fieldset" className="mb-3">
            <Col as={FormLegend} sm={2} column className="pt-0">
                Radios
            </Col>
            <Col sm={10}>
                <FormGroup>
                    <FormField className="mb-1">
                        <Radio
                            name="gridRadios"
                            id="gridRadios1"
                            defaultValue="option1"
                            defaultChecked
                        />
                        <FormLabel htmlFor="gridRadios1" plain>
                            First radio
                        </FormLabel>
                    </FormField>
                    <FormField className="mb-1">
                        <Radio name="gridRadios" id="gridRadios2" defaultValue="option2" />
                        <FormLabel htmlFor="gridRadios2" plain>
                            Second radio
                        </FormLabel>
                    </FormField>
                    <FormField>
                        <Radio name="gridRadios" id="gridRadios3" defaultValue="option3" disabled />
                        <FormLabel htmlFor="gridRadios3" plain>
                            Third disabled radio
                        </FormLabel>
                    </FormField>
                </FormGroup>
            </Col>
        </Row>
        <Row className="mb-3">
            <Col sm={{ span: 10, offset: 2 }}>
                <FormField>
                    <Checkbox id="gridCheck1" />
                    <FormLabel htmlFor="gridCheck1" plain>
                        Example checkbox
                    </FormLabel>
                </FormField>
            </Col>
        </Row>
        <Button type="submit" theme="primary" variant="solid">
            Sign in
        </Button>
    </Form>
</CodeExample>

### Horizontal form label sizing

Be sure to use `.col-form-label-sm` or `.col-form-label-lg` to your `<label>`s or `<legend>`s to correctly follow the size of `.form-control-lg` and `.form-control-sm`.

<CodeExample>
    <Row className="mb-3">
        <Col as={FormLabel} sm={2} htmlFor="colFormLabelSm" column controlSize="sm">
            Email
        </Col>
        <Col sm={10}>
            <FormControl
                type="email"
                id="colFormLabelSm"
                placeholder="col-form-label-sm"
                controlSize="sm"
            />
        </Col>
    </Row>
    <Row className="mb-3">
        <Col as={FormLabel} sm={2} htmlFor="colFormLabel" column>
            Email
        </Col>
        <Col sm={10}>
            <FormControl type="email" id="colFormLabel" placeholder="col-form-label" />
        </Col>
    </Row>
    <Row>
        <Col as={FormLabel} sm={2} htmlFor="colFormLabelLg" column controlSize="lg">
            Email
        </Col>
        <Col sm={10}>
            <FormControl
                type="email"
                id="colFormLabelLg"
                placeholder="col-form-label-lg"
                controlSize="lg"
            />
        </Col>
    </Row>
</CodeExample>

## Column sizing

As shown in the previous examples, our grid system allows you to place any number of `.col`s within a `.row`. They’ll split the available width equally between them. You may also pick a subset of your columns to take up more or less space, while the remaining `.col`s equally split the rest, with specific column classes like `.sm:col-7`.

<CodeExample>
    <Row className="g-3">
        <Col sm={7}>
            <FormControl type="text" placeholder="City" aria-label="City" />
        </Col>
        <Col sm>
            <FormControl type="text" placeholder="State" aria-label="State" />
        </Col>
        <Col sm>
            <FormControl type="text" placeholder="Zip" aria-label="Zip" />
        </Col>
    </Row>
</CodeExample>

## Auto-sizing

The example below uses a flexbox utility to vertically center the contents and changes `.col` to `.col-auto` so that your columns only take up as much space as needed. Put another way, the column sizes itself based on the contents.

<CodeExample>
    <Row as={Form} className="gy-2 gx-3 align-items-center">
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingInput" plain className="visually-hidden">
                Name
            </FormLabel>
            <FormControl type="text" id="autoSizingInput" placeholder="Jane Doe" />
        </Col>
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingInputGroup" plain className="visually-hidden">
                Username
            </FormLabel>
            <InputGroup>
                <InputGroupText>@</InputGroupText>
                <FormControl type="text" id="autoSizingInputGroup" placeholder="Username" />
            </InputGroup>
        </Col>
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingSelect" plain className="visually-hidden">
                Preference
            </FormLabel>
            <FormSelect id="autoSizingSelect" defaultValue="Choose...">
                <option>Choose...</option>
                <option value="1">One</option>
                <option value="2">Two</option>
                <option value="3">Three</option>
            </FormSelect>
        </Col>
        <Col xs="auto">
            <FormField>
                <Checkbox id="autoSizingCheck" />
                <FormLabel htmlFor="autoSizingCheck" plain>
                    Remember me
                </FormLabel>
            </FormField>
        </Col>
        <Col xs="auto">
            <Button type="submit" theme="primary" variant="solid">
                Submit
            </Button>
        </Col>
    </Row>
</CodeExample>

## Inline forms

Use the `.row-cols-*` classes to create responsive horizontal layouts. By adding [gutter modifier classes][3], we’ll have gutters in horizontal and vertical directions. On narrow mobile viewports, the `.col-12` helps stack the form controls and more. The `.align-items-center` aligns the form elements to the middle, making checkboxes and labels align properly.

<CodeExample>
    <Row as={Form} lg="auto" className="g-3 align-items-center">
        <Col xs={12}>
            <FormLabel htmlFor="inlineFormInputGroupUsername" plain className="visually-hidden">
                Username
            </FormLabel>
            <InputGroup>
                <InputGroupText>@</InputGroupText>
                <FormControl type="text" id="inlineFormInputGroupUsername" placeholder="Username" />
            </InputGroup>
        </Col>
        <Col xs={12}>
            <FormLabel htmlFor="inlineFormSelectPref" plain className="visually-hidden">
                Preference
            </FormLabel>
            <FormSelect id="inlineFormSelectPref" defaultValue="Choose...">
                <option>Choose...</option>
                <option value="1">One</option>
                <option value="2">Two</option>
                <option value="3">Three</option>
            </FormSelect>
        </Col>
        <Col xs={12}>
            <FormField>
                <Checkbox id="inlineFormCheck" />
                <FormLabel htmlFor="inlineFormCheck" plain>
                    Remember me
                </FormLabel>
            </FormField>
        </Col>
        <Col xs={12}>
            <Button type="submit" theme="primary" variant="solid">

        </Col>
    </Row>
</CodeExample>
