# Form layout

Use Bootstrap's grid and spacing utilities to lay out controls. `FormField` composes with `Row` and
`Col`; all control wrappers retain their native form behavior.

## Forms

<CodeExample>
    <Form>
        <Row className="g-3">
            <Col md={6}>
                <FormField>
                    <FormLabel htmlFor="layoutFirst">First name</FormLabel>
                    <FormControl id="layoutFirst" name="firstName" />
                </FormField>
            </Col>
            <Col md={6}>
                <FormField>
                    <FormLabel htmlFor="layoutLast">Last name</FormLabel>
                    <FormControl id="layoutLast" name="lastName" />
                </FormField>
            </Col>
        </Row>
    </Form>
</CodeExample>

## Utilities

Use spacing utilities such as `mb-3`, `g-3`, and responsive grid classes to control form layouts.

## Form grid

`Row` and `Col` expose the standard grid. Use responsive `Col` props to adjust layout at
breakpoints.

## Gutters

Use the grid's `g-*` utilities to set horizontal and vertical gutters.

## Horizontal form

Use grid columns to align labels and controls horizontally.

<CodeExample>
    <Form>
        <Row className="mb-3">
            <Col md={3}>
                <FormLabel htmlFor="layoutHorizontal">Email</FormLabel>
            </Col>
            <Col md={9}>
                <FormControl id="layoutHorizontal" type="email" />
            </Col>
        </Row>
    </Form>
</CodeExample>

### Horizontal form label sizing

Set the label column width with the relevant responsive `Col` props.

## Column sizing

Set column widths through the `Col` breakpoint props.

## Auto-sizing

Combine `Row`, `Col`, and flex utilities for compact forms. Keep controls usable at narrow viewport
widths.

## Inline forms

Use an auto-sized responsive row to align compact controls. Preserve labels or accessible names for
every input.
