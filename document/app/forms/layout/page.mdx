# Layout

Give your forms some structure—from inline to horizontal to custom grid implementations—with our form layout options.

## Forms

Every group of form fields should reside in a `Form` element. `Form` preserves native browser form behavior and passes standard form attributes through.

- New to browser forms? Consider reviewing [the MDN form docs][1] for an overview and complete list of available attributes.
- `Button` components inside a `Form` default to `type="button"`, so set `type="submit"` explicitly on submit buttons.

The form control wrappers fill their available width, so fields stack vertically by default. Use spacing and grid utilities through the layout components' `className` props to vary this layout.

## Utilities

Margin utilities are the easiest way to add structure to forms. Pass them through `FormField`'s
`className` to space labels, controls, optional form text, and validation feedback. Use a single
direction throughout the form for consistency.

Use semantic elements such as `fieldset` where appropriate; the `Form` wrapper can also render as a different element with its `as` prop.

<CodeExample>
    <FormField className="mb-3">
        <FormLabel htmlFor="formGroupExampleInput">Example label</FormLabel>
        <FormControl
            type="text"
            id="formGroupExampleInput"
            placeholder="Example input placeholder"
        />
    </FormField>
    <FormField className="mb-3">
        <FormLabel htmlFor="formGroupExampleInput2">Another label</FormLabel>
        <FormControl
            type="text"
            id="formGroupExampleInput2"
            placeholder="Another input placeholder"
        />
    </FormField>
</CodeExample>

## Form grid

Use `Row` and `Col` for form layouts that require multiple columns, varied widths, and additional
alignment options. Set responsive column spans with the `Col` breakpoint props.

<CodeExample>
    <Row>
        <Col>
            <FormControl type="text" placeholder="First name" aria-label="First name" />
        </Col>
        <Col>
            <FormControl type="text" placeholder="Last name" aria-label="Last name" />
        </Col>
    </Row>
</CodeExample>

## Gutters

Set gutter utilities through `Row`'s `className` to control spacing between columns in both
directions.

<CodeExample>
    <Row className="g-3">
        <Col>
            <FormControl type="text" placeholder="First name" aria-label="First name" />
        </Col>
        <Col>
            <FormControl type="text" placeholder="Last name" aria-label="Last name" />
        </Col>
    </Row>
</CodeExample>

More complex layouts can also be created with the grid system.

<CodeExample>

## Horizontal form

Create horizontal forms with the `Row` and `Col` layout components. Set the column breakpoint props (such as `sm={2}`) to size labels and controls, and use the `column` prop on `FormLabel` or `FormLegend` to align the label with its control.

Use margin or padding utilities through `className` on `Row`, `Col`, or `FormLabel` to adjust
alignment. For example, removing top padding from a stacked radio label can better align its text
baseline.

<CodeExample>
    <Form>
        <Row className="mb-3">
            <Col as={FormLabel} sm={2} htmlFor="inputEmail3" column>
                Email
            </Col>
            <Col sm={10}>
                <FormControl type="email" id="inputEmail3" />
            </Col>
        </Row>
        <Row className="mb-3">
            <Col as={FormLabel} sm={2} htmlFor="inputPassword3" column>
                Password
            </Col>
            <Col sm={10}>
                <FormControl type="password" id="inputPassword3" />
            </Col>
        </Row>
        <Row as="fieldset" className="mb-3">
            <Col as={FormLegend} sm={2} column className="pt-0">
                Radios
            </Col>
            <Col sm={10}>
                <FormGroup>
                    <FormField className="mb-1">
                        <Radio
                            name="gridRadios"
                            id="gridRadios1"
                            defaultValue="option1"
                            defaultChecked
                        />
                        <FormLabel htmlFor="gridRadios1" plain>
                            First radio
                        </FormLabel>
                    </FormField>
                    <FormField className="mb-1">
                        <Radio name="gridRadios" id="gridRadios2" defaultValue="option2" />
                        <FormLabel htmlFor="gridRadios2" plain>
                            Second radio
                        </FormLabel>
                    </FormField>
                    <FormField>
                        <Radio name="gridRadios" id="gridRadios3" defaultValue="option3" disabled />
                        <FormLabel htmlFor="gridRadios3" plain>
                            Third disabled radio
                        </FormLabel>
                    </FormField>
                </FormGroup>
            </Col>
        </Row>
        <Row className="mb-3">
            <Col sm={{ span: 10, offset: 2 }}>
                <FormField>
                    <Checkbox id="gridCheck1" />
                    <FormLabel htmlFor="gridCheck1" plain>
                        Example checkbox
                    </FormLabel>
                </FormField>
            </Col>
        </Row>
        <Button type="submit" theme="primary" variant="solid">
            Sign in
        </Button>
    </Form>
</CodeExample>

### Horizontal form label sizing

Set `controlSize` on `FormLabel` or `FormLegend` to match the `controlSize` of the associated form control.

<CodeExample>
    <Row className="mb-3">
        <Col as={FormLabel} sm={2} htmlFor="colFormLabelSm" column controlSize="sm">
            Email
        </Col>
        <Col sm={10}>
            <FormControl
                type="email"
                id="colFormLabelSm"
                placeholder="col-form-label-sm"
                controlSize="sm"
            />
        </Col>
    </Row>
    <Row className="mb-3">
        <Col as={FormLabel} sm={2} htmlFor="colFormLabel" column>
            Email
        </Col>
        <Col sm={10}>
            <FormControl type="email" id="colFormLabel" placeholder="col-form-label" />
        </Col>
    </Row>
    <Row>
        <Col as={FormLabel} sm={2} htmlFor="colFormLabelLg" column controlSize="lg">
            Email
        </Col>
        <Col sm={10}>
            <FormControl
                type="email"
                id="colFormLabelLg"
                placeholder="col-form-label-lg"
                controlSize="lg"
            />
        </Col>
    </Row>
</CodeExample>

## Column sizing

Place any number of `Col` components in a `Row` to split the available width equally. Set a
breakpoint prop such as `sm={7}` to size one column while the remaining columns share the rest.

<CodeExample>
    <Row className="g-3">
        <Col sm={7}>
            <FormControl type="text" placeholder="City" aria-label="City" />
        </Col>
        <Col sm>
            <FormControl type="text" placeholder="State" aria-label="State" />
        </Col>
        <Col sm>
            <FormControl type="text" placeholder="Zip" aria-label="Zip" />
        </Col>
    </Row>
</CodeExample>

## Auto-sizing

The example below passes a flexbox alignment utility through `Row`'s `className` and sets the `Col`
component's `xs` prop to `"auto"`, so each column takes only as much space as its contents need.

<CodeExample>
    <Row as={Form} className="gy-2 gx-3 align-items-center">
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingInput" plain className="visually-hidden">
                Name
            </FormLabel>
            <FormControl type="text" id="autoSizingInput" placeholder="Jane Doe" />
        </Col>
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingInputGroup" plain className="visually-hidden">
                Username
            </FormLabel>
            <InputGroup>
                <InputGroupText>@</InputGroupText>
                <FormControl type="text" id="autoSizingInputGroup" placeholder="Username" />
            </InputGroup>
        </Col>
        <Col xs="auto">
            <FormLabel htmlFor="autoSizingSelect" plain className="visually-hidden">
                Preference
            </FormLabel>
            <FormSelect id="autoSizingSelect" defaultValue="Choose...">
                <option>Choose...</option>
                <option value="1">One</option>
                <option value="2">Two</option>
                <option value="3">Three</option>
            </FormSelect>
        </Col>
        <Col xs="auto">
            <FormField>
                <Checkbox id="autoSizingCheck" />
                <FormLabel htmlFor="autoSizingCheck" plain>
                    Remember me
                </FormLabel>
            </FormField>
        </Col>
        <Col xs="auto">
            <Button type="submit" theme="primary" variant="solid">
                Submit
            </Button>
        </Col>
    </Row>
</CodeExample>

## Inline forms

Use responsive `Col` props to create horizontal layouts. Add gutter and alignment utilities through
`Row`'s `className`; on narrow viewports, set `xs={12}` on each `Col` to stack the controls.

<CodeExample>
    <Row as={Form} lg="auto" className="g-3 align-items-center">
        <Col xs={12}>
            <FormLabel htmlFor="inlineFormInputGroupUsername" plain className="visually-hidden">
                Username
            </FormLabel>
            <InputGroup>
                <InputGroupText>@</InputGroupText>
                <FormControl type="text" id="inlineFormInputGroupUsername" placeholder="Username" />
