# Form layout

Use `FormField` for individual controls and `FormGroup` for related choices. Bootstrap's spacing,
grid, gutter and flex utilities arrange wrappers without additional layout components.

## Quick start

<CodeExample>
    <Form aria-label="Address">
        <div className="row g-3">
            <FormField className="md:col-6">
                <FormLabel htmlFor="layoutCity">City</FormLabel>
                <FormControl id="layoutCity" name="city" />
            </FormField>
            <FormField className="md:col-6">
                <FormLabel htmlFor="layoutCountry">Country</FormLabel>
                <FormSelect id="layoutCountry" name="country" defaultValue="ca">
                    <option value="ca">Canada</option>
                    <option value="us">United States</option>
                </FormSelect>
            </FormField>
        </div>
        <FormGroup className="mt-3">
            <div className="row g-3 align-items-center">
                <FormLabel column controlSize="sm" htmlFor="layoutEmail" className="sm:col-2">
                    Email
                </FormLabel>
                <div className="sm:col-10">
                    <FormControl id="layoutEmail" type="email" controlSize="sm" />
                </div>
            </div>
        </FormGroup>
    </Form>
</CodeExample>

For horizontal forms, `FormLabel column` aligns labels with controls; combine its `controlSize`
with matching input sizing. Use column utilities to set widths, gutter utilities to control
spacing, and auto columns or flex wrapping for compact inline forms. Fieldsets and legends
provide native grouping when the content forms a single accessible choice.
