# Radio

Use the same native `name` for mutually exclusive choices.

## Quick start

<CodeExample>
    <FormGroup>
        <FormLabel>Shipping</FormLabel>
        <FormField>
            <Radio
                id="radioStandard"
                name="shipping"
                value="standard"
                defaultChecked
                theme="primary"
            />
            <FormFieldContent>
                <FormLabel plain htmlFor="radioStandard">
                    Standard
                </FormLabel>
                <FormText>Arrives in 5–7 business days.</FormText>
            </FormFieldContent>
        </FormField>
        <FormField>
            <Radio id="radioExpress" name="shipping" value="express" size="lg" />
            <FormLabel plain htmlFor="radioExpress">
                Express
            </FormLabel>
        </FormField>
        <FormField>
            <Radio id="radioDisabled" name="shipping" size="sm" disabled />
            <FormLabel plain htmlFor="radioDisabled">
                Unavailable
            </FormLabel>
        </FormField>
    </FormGroup>
</CodeExample>

`size="sm"` and `"lg"` adjust the control; `theme` accepts all button themes. Native `checked`,
`defaultChecked`, `onChange`, `required` and `disabled` pass through. Use `validation` and
`FormFeedback` for server feedback. `FormCheck type="radio"` is an equivalent shorthand.
