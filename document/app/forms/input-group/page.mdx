# Input group

Use `InputGroup` to attach text, buttons, and other controls to a form input. Keep the accessible
label in a surrounding `FormField` or give the control an accessible name.

## Examples

<CodeExample>
    <InputGroup>
        <InputGroupText>@</InputGroupText>
        <FormControl aria-label="Username" placeholder="Username" />
    </InputGroup>
</CodeExample>

## With form field

<CodeExample>
    <FormField>
        <FormLabel htmlFor="groupUsername">Username</FormLabel>
        <InputGroup>
            <InputGroupText>@</InputGroupText>
            <FormControl id="groupUsername" name="username" />
        </InputGroup>
    </FormField>
</CodeExample>

### Buttons

<CodeExample>
    <InputGroup>
        <FormControl aria-label="Recipient" placeholder="Recipient" />
        <Button>Submit</Button>
    </InputGroup>
</CodeExample>

### Textarea

<CodeExample>
    <InputGroup>
        <InputGroupText>Message</InputGroupText>
        <FormTextArea aria-label="Message" rows={2} />
    </InputGroup>
</CodeExample>

### Select

<CodeExample>
    <InputGroup>
        <InputGroupText>Country</InputGroupText>
        <FormSelect aria-label="Country" defaultValue="ca">
            <option value="ca">Canada</option>
            <option value="jp">Japan</option>
        </FormSelect>
    </InputGroup>
</CodeExample>

### File input

<CodeExample>
    <InputGroup>
        <InputGroupText>Upload</InputGroupText>
        <FormControl aria-label="Upload a file" type="file" />
    </InputGroup>
</CodeExample>

### Checkboxes and radios

<CodeExample>
    <InputGroup>
        <InputGroupText>
            <FormCheck aria-label="Include" />
        </InputGroupText>
        <FormControl aria-label="Item" placeholder="Item" />
    </InputGroup>
</CodeExample>

### Multiple inputs

Multiple controls can be composed as children.

<CodeExample>
    <InputGroup>
        <InputGroupText>Name</InputGroupText>
        <FormControl aria-label="First name" />
        <FormControl aria-label="Last name" />
    </InputGroup>
</CodeExample>

### Multiple addons

<CodeExample>
    <InputGroup>
        <InputGroupText>$</InputGroupText>
        <InputGroupText>0.00</InputGroupText>
        <FormControl aria-label="Amount" />
    </InputGroup>
</CodeExample>

### Button addons

<CodeExample>
    <InputGroup>
        <FormControl aria-label="Search terms" placeholder="Search" />
        <Button>Search</Button>
    </InputGroup>
</CodeExample>

### Buttons with menus

Use the existing `Menu` wrapper alongside an input group when an addon needs a menu. The menu and
its trigger remain separately accessible controls.

### Segmented buttons

Compose buttons and controls as direct children. Use the existing button group wrapper for
semantically related button segments.

## Border radius

Bootstrap controls the adjoining border radii based on the order of the children. For groups with
multiple controls, keep the markup order consistent with the visual order.

## Sizing

Pass `size="sm"` or `"lg"` to `InputGroup` to apply the matching input group size class.
