# Input group

Combine controls with text or button addons. Put labels outside the group; size the group, not
its individual controls.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="groupUsername">Username</FormLabel>
        <InputGroup size="lg">
            <InputGroupText>@</InputGroupText>
            <FormControl id="groupUsername" />
            <InputGroupButton variant="outline" theme="secondary">
                Check
            </InputGroupButton>
        </InputGroup>
    </FormField>
    <InputGroup className="mt-3">
        <InputGroupText>$</InputGroupText>
        <FormControl aria-label="Amount" type="number" />
        <InputGroupText>.00</InputGroupText>
        <InputGroupIgnore>
            <FormControl aria-label="Hidden metadata" type="hidden" />
        </InputGroupIgnore>
    </InputGroup>
    <InputGroup className="mt-3">
        <InputGroupText>
            <Checkbox aria-label="Include message" />
        </InputGroupText>
        <FormTextArea aria-label="Message" rows={2} />
    </InputGroup>
    <InputGroup size="sm" className="mt-3">
        <InputGroupText>Country</InputGroupText>
        <FormSelect aria-label="Country" defaultValue="ca">
            <option value="ca">Canada</option>
        </FormSelect>
        <InputGroupButton variant="outline">Apply</InputGroupButton>
    </InputGroup>
    <InputGroup className="mt-3">
        <FormControl type="file" aria-label="Upload" />
        <InputGroupButton variant="outline">Upload</InputGroupButton>
    </InputGroup>
    <InputGroup className="mt-3">
        <InputGroupButton variant="outline">Action</InputGroupButton>
        <InputGroupMenu label="More" split toggleProps={{ variant: 'outline' }}>
            <MenuItem>Another action</MenuItem>
            <MenuItem>Something else</MenuItem>
        </InputGroupMenu>
        <FormControl aria-label="Value with segmented actions" />
    </InputGroup>
</CodeExample>

Use `size="sm"` or `"lg"`. Groups support multiple controls, multiple addons, checkboxes and radios.
`InputGroupButton` accepts all `Button` props and puts addon styling on the button itself.
`InputGroupIgnore` adds the border-radius exclusion to its single child without another DOM
wrapper, useful for hidden controls. `InputGroupMenu` reuses Menu keyboard and dismissal behavior,
placing its button and popup directly inside the group. Combine `split` with `InputGroupButton`
for segmented actions; omit `split` for a normal dropdown addon.
