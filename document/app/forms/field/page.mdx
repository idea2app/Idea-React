# Field

`FormField` lays out any control, label, description and validation feedback. Checkbox, radio and
switch children automatically use a two-column layout.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="fieldEmail">Email</FormLabel>
        <FormControl id="fieldEmail" type="email" aria-describedby="fieldHelp" />
        <FormText id="fieldHelp">Use your work email.</FormText>
    </FormField>
    <FormGroup className="mt-3">
        <FormLabel>Choose a plan</FormLabel>
        <FormField card>
            <Radio id="fieldBasic" name="fieldPlan" defaultChecked />
            <FormFieldContent>
                <FormLabel plain htmlFor="fieldBasic">
                    Basic
                </FormLabel>
                <FormText>$9/month — For individuals.</FormText>
            </FormFieldContent>
        </FormField>
        <FormField card>
            <Radio id="fieldPro" name="fieldPlan" />
            <FormFieldContent>
                <FormLabel plain htmlFor="fieldPro">
                    Pro
                </FormLabel>
                <FormText>$29/month — For teams.</FormText>
            </FormFieldContent>
        </FormField>
    </FormGroup>
    <FormField className="mt-3">
        <FormLabel>Terms and conditions</FormLabel>
        <Checkbox id="fieldTerms" validation="invalid" required aria-describedby="fieldError" />
        <FormFieldContent>
            <FormLabel plain htmlFor="fieldTerms">
                I agree
            </FormLabel>
            <FormFeedback id="fieldError">Please accept the terms.</FormFeedback>
        </FormFieldContent>
    </FormField>
</CodeExample>

Use `FormLabel plain` beside a checkbox, radio or switch. A regular `FormLabel` becomes an overhead
title. `FormGroup` supplies shared spacing; `FormField card` highlights selectable cards.
The same wrappers accept selects, textareas, ranges, input groups, adornments, comboboxes and OTPs.
