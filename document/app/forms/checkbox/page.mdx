# Checkbox

`Checkbox` is a native checkbox with theme, size and indeterminate support.

## Quick start

<CodeExample>
    <FormField>
        <Checkbox id="checkSubscribe" name="subscribe" defaultChecked theme="primary" />
        <FormFieldContent>
            <FormLabel plain htmlFor="checkSubscribe">
                Subscribe to updates
            </FormLabel>
            <FormText>Receive our weekly digest.</FormText>
        </FormFieldContent>
    </FormField>
    <div className="d-flex gap-3 mt-3">
        <Checkbox aria-label="Mixed selection" indeterminate />
        <Checkbox aria-label="Small checkbox" size="sm" defaultChecked theme="success" />
        <Checkbox aria-label="Large checkbox" size="lg" />
        <Checkbox aria-label="Disabled checkbox" disabled defaultChecked />
    </div>
</CodeExample>

Use `checked` with `onChange` for controlled state, or `defaultChecked` for native state.
`indeterminate` updates the native property and announces mixed state. All button theme names
are accepted. Native `required` and `disabled` work normally; `validation` selects valid or
invalid feedback styling. `FormCheck` also supports these props.
