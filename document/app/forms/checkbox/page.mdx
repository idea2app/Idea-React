# Checkbox

Highly customizable, native checkbox `<input>` elements for presenting toggleable options.

## Basic checkbox

`Checkbox` applies the `.check` class directly on its native `<input>`. This does the following:

- Overrides the default `<input>` appearance with themed colors.
- Renders the `:checked` and indeterminate icons via a CSS `mask` on the input’s `::before` pseudo-element, so the mark inherits the contrast color and no inline SVG is needed. The appropriate icon is shown based on the input’s state.

For folks looking to replace our provided icons, override the `--bs-check-icon-checked` and `--bs-check-icon-indeterminate` CSS variables (or the `--check-icon-*` Sass tokens) with your own `mask-image` URLs.

Labels and layout are handled with additional HTML and CSS.

<CodeExample>
    <Checkbox id="check" defaultChecked />
</CodeExample>

## Indeterminate

Checkboxes can utilize the indeterminate pseudo class. There is no available HTML attribute for specifying it; the `indeterminate` prop sets the native JavaScript property.

<CodeExample>
    <Checkbox id="checkIndeterminate" indeterminate />
</CodeExample>

## With form field

Wrap `Checkbox` in a `FormField` layout wrapper and add your label. The grid layout places the checkbox and label side by side.

<CodeExample>
    <FormField>
        <Checkbox id="checkLabel" />
        <FormLabel htmlFor="checkLabel" plain>
            Example new checkbox
        </FormLabel>
    </FormField>
</CodeExample>

## Description

Add a description or other content after the label. We recommend wrapping the label and description in a `.form-field-content` to ensure appropriate spacing and alignment.

<CodeExample>
    <FormField>
        <Checkbox id="checkDescription" />
        <FormFieldContent>
            <FormLabel htmlFor="checkDescription" plain>
                Example new checkbox
            </FormLabel>
            <FormText>Supporting description for the above label.</FormText>
        </FormFieldContent>
    </FormField>
</CodeExample>

## Disabled

Add the `disabled` attribute and the associated `<label>`s are automatically styled to match with a lighter color to help indicate the input’s state.

<CodeExample>
    <Stack gap={2}>
        <FormField>
            <Checkbox id="checkDisabled" disabled />
            <FormLabel htmlFor="checkDisabled" plain>
                Example new checkbox
            </FormLabel>
        </FormField>
        <FormField>
            <Checkbox id="checkDisabledChecked" defaultChecked disabled />
            <FormLabel htmlFor="checkDisabledChecked" plain>
                Example new checkbox
            </FormLabel>
        </FormField>
    </Stack>
</CodeExample>

## Sizes

Set `size="sm"` or `size="lg"` to make your checkbox appear smaller or larger.

            <FormLabel htmlFor="checkSizeSm" plain>

        </FormField>
