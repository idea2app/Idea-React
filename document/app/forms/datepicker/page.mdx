# Datepicker

`DatePicker` defaults to a native date input. Set `enhanced` to initialize Bootstrap's
Vanilla Calendar Pro integration automatically. `DatePickerButton` and `DatePickerInline`
provide button-triggered and always-visible calendars.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="datepickerNative">Native date</FormLabel>
        <DatePicker id="datepickerNative" name="date" min="2026-01-01" max="2026-12-31" />
    </FormField>
    <FormField className="mt-3">
        <FormLabel htmlFor="datepickerRange">Date range</FormLabel>
        <FormAdornment htmlFor="datepickerRange">
            <FormAdornmentIcon name="calendar-week" aria-hidden="true" />
            <DatePicker
                id="datepickerRange"
                name="range"
                enhanced
                ghost
                selectionMode="multiple-ranged"
                displayMonthsCount={2}
                selectedDates={['2026-06-25', '2026-07-08']}
                firstWeekday={0}
                placement="center"
                options={{ locale: 'en-US', dateFormat: { dateStyle: 'medium' } }}
            />
        </FormAdornment>
    </FormField>
    <DatePickerButton
        className="mt-3"
        variant="outline"
        selectionMode="multiple"
        leadingIcon="calendar-week"
    >
        Select dates
    </DatePickerButton>
    <DatePickerInline className="mt-3" datepickerTheme="dark" />
</CodeExample>

Enhanced mode supports `selectionMode="single"`, `"multiple"` or `"multiple-ranged"`.
Combine `displayMonthsCount` and `selectedDates` for multi-month ranges. `min` / `max` bound an
input's dates; the button and inline variants accept `options.dateMin` / `dateMax`.

Use `firstWeekday`, `placement` (`left`, `center`, `right`, `auto`) and `datepickerTheme`.
`options` accepts every Bootstrap datepicker option, including `locale`, `dateFormat` (Intl
options or a formatter), `displayElement`, `positionElement` and all `vcpOptions`. Top-level
settings override equivalent `options` fields. `onDatesChange` receives selected date strings;
native input events are also preserved. Refs target the input, button or inline container.

The picker inherits the surrounding theme unless overridden. For Shadow DOM, provide compatible
styles inside the root and use element references for positioning and display options.
