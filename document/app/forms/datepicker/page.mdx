# Datepicker

A flexible calendar and date picker popover with support for input or button toggles, range selection, multiple months, and more.

## Overview

The Bootstrap Datepicker is a wrapper around [Vanilla Calendar Pro][1] that provides a consistent, accessible date selection experience. It supports light/dark themes, input binding, and flexible configuration via React props.

<DocumentCodeExample>
    <FormLabel htmlFor="datepicker1">Datepicker</FormLabel>
    <DatePicker
        id="datepicker1"
        autoComplete="off"
        placeholder="Choose date…"
        enhanced
        className="w-12"
    />
</DocumentCodeExample>

Note that we’re using a width utility of `.w-12` to ensure the input is wide enough to accommodate the date format and imply some affordance for the expected type of input.

## How it works

- Use `DatePicker enhanced` to enable the datepicker on a native input
- `enhanced` renders a text input to avoid conflicts with native browser date pickers; without it, `DatePicker` retains the browser’s native date input
- When focused, the calendar popup appears below the input
- Selecting a date updates the input value and closes the picker
- The picker also closes on a click outside it, on <kbd>Escape</kbd>, or when focus moves to an element outside it
- The picker respects Bootstrap’s color modes (`data-bs-theme`)
- Configurable with any [Vanilla Calendar Pro option][2] via `options.vcpOptions`

## Examples

### With form field

Use the [form field][3] component to layout and wrap your inputs with a label, description, and validation feedback messages in a vertical stack.

<DocumentCodeExample>
    <FormField>
        <FormLabel htmlFor="datepicker2">Datepicker field</FormLabel>
        <DatePicker
            id="datepicker2"
            autoComplete="off"
            placeholder="Choose date…"
            enhanced
            className="w-12"
        />
        <FormText> We’ll never share your email with anyone else. </FormText>
    </FormField>
</DocumentCodeExample>

### With icon

Use the [form adorn component][4] to add a calendar icon alongside the datepicker input. When the input is inside a `.form-adorn` wrapper, the calendar automatically positions relative to the wrapper instead of the input.

<DocumentCodeExample>
    <FormLabel htmlFor="datepickerIconStart">Select date</FormLabel>
    <FormAdornment className="w-12">
        <FormAdornmentIcon name="calendar-week" aria-hidden="true" />
        <DatePicker
            id="datepickerIconStart"
            autoComplete="off"
            placeholder="Choose date…"
            enhanced
            ghost
        />
    </FormAdornment>
</DocumentCodeExample>

### Min & Max dates

Restrict the selectable date range using the `min` and `max` props.

<DocumentCodeExample>
    <FormLabel htmlFor="datepickerMinMax">Event date (2026 only)</FormLabel>
    <DatePicker
        id="datepickerMinMax"
        autoComplete="off"
        placeholder="Select a date in 2026"
        enhanced
        min="2026-01-01"
        max="2026-12-31"
        className="w-12"
    />
</DocumentCodeExample>

### Multiple dates

Enable multiple date selection with `selectionMode="multiple"`.

<DocumentCodeExample>
    <FormLabel htmlFor="datepicker3">Select multiple dates</FormLabel>
    <DatePicker
        id="datepicker3"
        autoComplete="off"
        placeholder="Select date range…"
        enhanced
        selectionMode="multiple"
    />
</DocumentCodeExample>

### Multiple months

Display multiple months side-by-side with the `displayMonthsCount` option. This is useful for date range selection where users need to see more context.

<DocumentCodeExample>
    <FormLabel htmlFor="datepickerMultiMonth">Select date range</FormLabel>
    <DatePicker
        id="datepickerMultiMonth"
        autoComplete="off"
        placeholder="Select start and end dates"
        enhanced
        selectionMode="multiple-ranged"
        displayMonthsCount={2}
    />
</DocumentCodeExample>

### Date range

Select a range of dates with `selectionMode="multiple-ranged"`. Use `selectedDates` to preselect a date range.

<DocumentCodeExample>
    <FormLabel htmlFor="datepicker4">Select date range</FormLabel>
    <DatePicker
        id="datepicker4"
        autoComplete="off"
        placeholder="Select start and end dates…"
        enhanced
        selectionMode="multiple-ranged"
        selectedDates={['2026-06-10', '2026-06-18']}
    />
</DocumentCodeExample>

### Multi-month date range

For selecting date ranges that span multiple months, combine `selectionMode="multiple-ranged"` with `displayMonthsCount={2}` to show two months side-by-side, making it easier for users to select across month boundaries.

<DocumentCodeExample>
    <FormLabel htmlFor="datepickerRangeTwoMonths">Select date range</FormLabel>
    <DatePicker
        id="datepickerRangeTwoMonths"
        autoComplete="off"
        placeholder="Select start and end dates…"
        enhanced
        selectionMode="multiple-ranged"
        displayMonthsCount={2}
        selectedDates={['2026-06-25', '2026-07-08']}
    />
</DocumentCodeExample>

## Options

### First day of week

Set the first day of the week (0 = Sunday, 1 = Monday, etc.) with `firstWeekday`.

<DocumentCodeExample>
    <FormLabel htmlFor="datepicker6">Week starts on Sunday</FormLabel>
    <DatePicker
        id="datepicker6"
        autoComplete="off"
        placeholder="Select a date"
        enhanced
        firstWeekday={0}
        className="w-12"
    />
</DocumentCodeExample>

### Button trigger

Use `DatePickerButton` instead of an input for use cases like dashboard date filters. Set `leadingIcon` to preserve an icon when the date updates.

<DocumentCodeExample>
    <DatePickerButton type="button" leadingIcon="calendar-week" theme="secondary" variant="outline">
        Select date
    </DatePickerButton>
</DocumentCodeExample>

For date range selection (e.g., dashboard time filters), use `selectionMode="multiple-ranged"`. The calendar will close after both start and end dates are selected.

<DocumentCodeExample>
    <DatePickerButton
        type="button"
        leadingIcon="calendar-week"
        selectionMode="multiple-ranged"
        theme="secondary"
        variant="outline"
    >
        Last 7 days
    </DatePickerButton>
</DocumentCodeExample>

You can also display the selected date in a separate element using `options.displayElement`:

```tsx
<DatePickerButton
    selectionMode="multiple-ranged"
    options={{ displayElement: "#date-display" }}
>
    Choose dates
</DatePickerButton>
<span id="date-display" />
```

### Inline mode

Render the calendar inline (always visible, no popup) with `DatePickerInline`. This is useful for embedding a calendar directly in the page.

<DocumentCodeExample>
    <DatePickerInline />
</DocumentCodeExample>

Inline datepickers with date range selection:

<DocumentCodeExample>
    <DatePickerInline selectionMode="multiple-ranged" />
</DocumentCodeExample>

Multiple months inline:

<DocumentCodeExample>
    <DatePickerInline displayMonthsCount={2} />
</DocumentCodeExample>

To bind to a form field, include a hidden input inside the container. The value will be updated with the selected date(s) in `YYYY-MM-DD` format:

<DocumentCodeExample>
    <Form>
        <DatePickerInline>
            <FormControl type="hidden" name="selected_date" />
        </DatePickerInline>
        <Button type="submit" theme="primary" variant="solid" className="mt-3">
            Submit
        </Button>
    </Form>
</DocumentCodeExample>

### Custom date formatting

Control how dates are displayed using `options.dateFormat`. Pass an [`Intl.DateTimeFormat` options object][5] or a custom function.

```tsx
<DatePicker
    enhanced
    options={{ dateFormat: { month: "short", day: "numeric", year: "numeric" } }}
/>
<DatePicker
    enhanced
    options={{ dateFormat: (date, locale) => date.toLocaleDateString(locale, { month: "short", day: "numeric" }) }}
/>
```

## Dark mode

The datepicker automatically adapts to Bootstrap’s color modes. When `data-bs-theme="dark"` is set on a parent element or the `<html>` tag, the calendar popup inherits that theme.

### Inherited from parent

When a parent element has a theme, both the input and calendar popup inherit it:

<DocumentCodeExample>
    <div data-bs-theme="dark" className="p-3 bg-body fg-body rounded">
        <FormLabel htmlFor="datepickerDark">Dark mode datepicker</FormLabel>
        <DatePicker id="datepickerDark" autoComplete="off" placeholder="Select a date" enhanced />
    </div>
</DocumentCodeExample>

### Datepicker-only theme

Use `datepickerTheme` to set the datepicker popup’s theme independently of the input. This is useful when you want a light input with a dark datepicker, or vice versa:

<DocumentCodeExample>
    <FormLabel htmlFor="datepickerTheme">Light input, dark datepicker</FormLabel>
    <DatePicker
        id="datepickerTheme"
        autoComplete="off"
        placeholder="Select a date"
        enhanced
        datepickerTheme="dark"
        className="w-12"
    />
</DocumentCodeExample>

## Usage

`DatePicker enhanced`, `DatePickerButton`, and `DatePickerInline` initialize and dispose the calendar automatically. Pass supported settings as props, plugin settings through `options` and advanced Vanilla Calendar Pro settings through `options.vcpOptions`, and receive selected dates with `onDatesChange`.

### Options

| Name                      | Type                     | Default     | Description                                                                                                       |
| ------------------------- | ------------------------ | ----------- | ----------------------------------------------------------------------------------------------------------------- |
| `min` / `options.dateMin` | string, number, Date     | `null`      | Minimum selectable date. Format: `YYYY-MM-DD`                                                                     |
| `max` / `options.dateMax` | string, number, Date     | `null`      | Maximum selectable date. Format: `YYYY-MM-DD`                                                                     |
| `options.dateFormat`      | object, function         | `null`      | Date formatting. Pass `Intl.DateTimeFormat` options or a `function(date, locale)`.                                |
| `options.displayElement`  | string, element, boolean | `null`      | Element to show formatted date. For buttons, defaults to the button itself. Set to `false` to disable.            |
| `displayMonthsCount`      | number                   | `1`         | Number of months to display side-by-side in the calendar.                                                         |
| `firstWeekday`            | number                   | `1`         | First day of week (0 = Sunday, 1 = Monday, etc.)                                                                  |
| `inline`                  | boolean                  | `false`     | Render calendar inline (always visible, no popup).                                                                |
| `options.locale`          | string                   | `'default'` | Locale for date formatting (e.g., `'en-US'`, `'de-DE'`)                                                           |
| `options.positionElement` | string, element          | `null`      | Element to position calendar relative to. Auto-detects `.form-adorn` wrapper if present.                          |
| `selectedDates`           | array                    | `[]`        | Pre-selected dates in `YYYY-MM-DD` format                                                                         |
| `selectionMode`           | string                   | `'single'`  | Selection mode: `'single'`, `'multiple'`, or `'multiple-ranged'`                                                  |
| `placement`               | string                   | `'left'`    | Calendar position relative to input: `'left'`, `'center'`, `'right'`, `'auto'`                                    |
| `datepickerTheme`         | string                   | `null`      | Force datepicker popup theme: `'light'`, `'dark'`, `'auto'`, or `null` to inherit from ancestor `[data-bs-theme]` |
| `options.vcpOptions`      | object                   | `{}`        | Pass-through object for any [Vanilla Calendar Pro option][2]                                                      |
