# Chips

Small interactive elements representing entities like people, places, tags, or values. Combine with inputs for multi-value fields like skills, categories, or email recipients using themed chips.

## Overview

Chips are small interactive elements representing entities. They can be used to group and select values in forms or other interactive contexts. They're similar to the older [Badges][1] component, but have some meaningful differences.

- Chips are interactive elements, not static like Badges.
- Chips have one size—they don't scale with the parent `font-size` like Badges.
- Chips can have icons, avatars, and dismiss buttons.
- Chips can be themed, individually or as a group on the parent container. By default, chips use the `subtle` and `text` theme tokens, while active state uses the `bg` and `contrast` tokens.
- Chips can be active or disabled.
- Chips automatically gain focus when clicked into their active state.
- Chips support keyboard navigation and selection in their custom `.chip-input` container.

See examples of all of this in action below.

## Chips

Use `ChipToken` for the standalone tokens shown below, or `Chip` for a button. Add `ChipIcon` for a leading icon, `ChipImage` for an image like an avatar, and `ChipDismiss` for a remove button. Dismiss buttons use the library’s `Icon` component; use `ChipToken` rather than nesting a dismiss button inside `Chip`.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2">
        <ChipToken>Basic chip</ChipToken>
        <ChipToken>
            <ChipImage src="https://github.com/mdo.png" width={16} height={16} alt="" /> With avatar
        </ChipToken>
        <ChipToken>
            <ChipIcon name="person-fill" aria-hidden="true" /> With icon
        </ChipToken>
        <ChipToken>
            Dismissible <ChipDismiss type="button" aria-label="Remove" />
        </ChipToken>
    </div>
</DocumentCodeExample>

## Chip input

Wrap `ChipToken` components and a `FormGhost` input in `ChipInput` to create a tag input field. The component enables JavaScript behavior automatically. Chips are grayscale by default, with primary blue for active states, but you can apply any theme color to the container so that chips within inherit the color of your choosing.

Type into the input below and press <kbd>Enter</kbd> or <kbd>,</kbd> to add new chips. Use the <kbd>Backspace</kbd> or <kbd>Delete</kbd> keys to remove chips. See the [Keyboard behavior][2] section for more details.

<DocumentCodeExample>
    <ChipInput>
        <ChipInputLabel htmlFor="skillsInput">Skills:</ChipInputLabel>
        <ChipToken> JavaScript </ChipToken>
        <ChipToken> TypeScript </ChipToken>
        <FormGhost type="text" id="skillsInput" placeholder="Add more…" />
    </ChipInput>
</DocumentCodeExample>

### Theme variants

Set `theme` on `ChipInput` to apply a theme color to all chips within.

<DocumentCodeExample>
    <Stack gap={3}>
        <ChipInput theme="primary">
            <ChipToken>Approved</ChipToken>
            <ChipToken>Verified</ChipToken>
            <FormGhost type="text" placeholder="Add status..." />
        </ChipInput>
        <ChipInput theme="danger">
            <ChipToken>Bug</ChipToken>
            <ChipToken>Critical</ChipToken>
            <FormGhost type="text" placeholder="Add issue" />
        </ChipInput>
    </Stack>
</DocumentCodeExample>

You can also individually apply a theme color to a chip with the chip’s `theme` prop.

<DocumentCodeExample>
    <ChipInput theme="primary">
        <ChipToken theme="warning">Bug</ChipToken>
        <ChipToken theme="danger">Critical</ChipToken>
        <FormGhost type="text" placeholder="Add issue" />
    </ChipInput>
</DocumentCodeExample>

### Empty state

Start with just the ghost input—chips are created as users type.

<DocumentCodeExample>
    <ChipInput theme="primary">
        <FormGhost type="text" placeholder="Type and press Enter" />
    </ChipInput>
</DocumentCodeExample>

### With label

Use a form label for better accessibility.

<DocumentCodeExample>
    <FormField>
        <FormLabel htmlFor="skillsInputLabel">Skills</FormLabel>
        <ChipInput theme="primary">
            <ChipToken>
                React <ChipDismiss type="button" aria-label="Remove" />
            </ChipToken>
            <FormGhost type="text" id="skillsInputLabel" placeholder="Add skill..." />
        </ChipInput>
        <FormText>Press Enter or comma to add a skill.</FormText>
    </FormField>

### Disabled

Disable the ghost input to prevent adding new chips, and disable the dismiss buttons on existing chips. Existing chips become non-interactive.

<DocumentCodeExample>
    <ChipInput theme="primary">
        <ChipToken>
            Read only <ChipDismiss type="button" aria-label="Remove" disabled />
        </ChipToken>
        <FormGhost type="text" placeholder="Disabled..." disabled />
    </ChipInput>
</DocumentCodeExample>

## Usage

`ChipInput` initializes and disposes the plugin automatically. Pass options as props, and use `onValuesChange` to receive the current values.

### Options

Pass options directly as `ChipInput` props:

| Name              | Type           | Default | Description                                                                 |
| ----------------- | -------------- | ------- | --------------------------------------------------------------------------- |
| `separator`       | string \| null | `','`   | Character that triggers chip creation when typed. Set to `null` to disable. |
| `allowDuplicates` | boolean        | `false` | Allow duplicate chip values.                                                |
| `maxChips`        | number \| null | `null`  | Maximum number of chips allowed. `null` for unlimited.                      |
| `placeholder`     | string         | `''`    | Placeholder text for dynamically created inputs.                            |
| `dismissible`     | boolean        | `true`  | Add dismiss buttons to created chips.                                       |
| `createOnBlur`    | boolean        | `true`  | Create chip from input value when the input loses focus.                    |

<h2 id="keyboard-behavior">Keyboard behavior</h2>

Chip inputs support Mail.app-style keyboard navigation with chip selection.

### When input is focused

| Key                    | Action                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------- |
| `Enter`                | Create chip from current input value                                                     |
| `,` (or separator)     | Create chip from current input value                                                     |
| `Backspace` / `Delete` | When input is empty, select and focus last chip (first press); pressing again deletes it |
| `←`                    | When cursor is at start, move focus to last chip                                         |
| `Shift+←`              | Select last chip and extend selection                                                    |
| `Escape`               | Clear selection, clear input, and blur                                                   |

### When a chip is focused

| Key                    | Action                                                             |
| ---------------------- | ------------------------------------------------------------------ |
| `Backspace` / `Delete` | Remove selected chips, then select and focus the next closest chip |
| `←`                    | Move to previous chip                                              |
| `→`                    | Move to next chip (or input if at end)                             |
| `Shift+←` / `Shift+→`  | Extend selection in that direction                                 |
| `Home`                 | Move to first chip                                                 |
| `End`                  | Move to input                                                      |
| `Cmd/Ctrl+A`           | Select all chips                                                   |
| `Escape`               | Clear selection and focus input                                    |

### Mouse selection

| Action           | Effect                                   |
| ---------------- | ---------------------------------------- |
| Click chip       | Select chip (deselects others)           |
| `Cmd/Ctrl+Click` | Toggle chip in selection                 |
| `Shift+Click`    | Range select from anchor to clicked chip |

## Accessibility

- Use a `<label>` element associated with the chip input for screen readers
- Chips are focusable and support full keyboard navigation
- Each `.chip-dismiss` button has `aria-label="Remove"`
- Selected chips have the `.active` class for visual indication
- Chips are announced as they are added or removed
