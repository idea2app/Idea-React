# Chips

Use `Chip` for a standalone toggle button and `ChipToken` when composing a token with a dismiss
button. `ChipInput` initializes Bootstrap's keyboard, paste, selection and removal behavior.

## Quick start

<CodeExample>
    <div className="d-flex flex-wrap gap-2">
        <Chip theme="primary" active>
            Active
        </Chip>
        <Chip disabled>Disabled</Chip>
        <ChipToken theme="success">
            <ChipIcon name="person" aria-hidden="true" />
            Person
            <ChipDismiss />
        </ChipToken>
        <ChipToken>
            <ChipImage src="https://github.com/idea2app.png" alt="" width={16} height={16} />
            Team
        </ChipToken>
    </div>
    <ChipInput theme="primary" maxChips={5} allowDuplicates={false} className="mt-3">
        <ChipInputLabel htmlFor="chipsSkills">Skills:</ChipInputLabel>
        <ChipToken>React</ChipToken>
        <FormGhost id="chipsSkills" placeholder="Add a skill…" />
    </ChipInput>
    <ChipInput theme="secondary" className="mt-3">
        <ChipToken>
            Read only
            <ChipDismiss disabled />
        </ChipToken>
        <FormGhost aria-label="Disabled tags" placeholder="Disabled…" disabled />
    </ChipInput>
</CodeExample>

Press Enter or `separator` (comma by default) to create a chip. Paste separated values; use
Backspace/Delete to remove, arrow keys/Home/End to navigate, and Shift or Control/Command to
extend selections. `createOnBlur` defaults to true; set `separator={null}` to disable separator
creation. `maxChips`, `allowDuplicates`, `dismissible`, `placeholder` and `onValuesChange`
configure input behavior. Start with only `FormGhost` for an empty field.

Use a regular `FormLabel` and `FormField` for an external label. Individual `theme` values override
the input's inherited theme. Outside `ChipInput`, wire `ChipDismiss.onClick` to application state.
