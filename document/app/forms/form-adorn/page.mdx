# Form adorn

Decorate inputs with icons, text, and more using a custom wrapper that easily handles styling and positioning.

## How it works

Wrap adornments and a `FormGhost` control in `FormAdornment`. The wrapper provides the border, background, padding, and focus states, and uses flexbox to position adornments beside the visually unstyled `FormGhost`, which inherits the wrapper's styles.

`FormAdornment` renders a label by default. This lets people click the icon, text, or surrounding padding to focus the control without any JavaScript.

Mark decorative `FormAdornmentIcon` and `FormAdornmentText` components with `aria-hidden="true"`. Because the default `FormAdornment` label also labels its nested input, text adornments such as `$` can become part of the input's accessible name. Keep decorative content out of the accessibility tree, and provide meaningful names with [`FormLabel`][1] or visible label text and descriptions with [`FormText`][1].

> An input can have more than one label, so the default `FormAdornment` label and a separate [`FormLabel`][1] can work together. Set [`FormLabel`][1]'s `htmlFor` to the input's `id`. Do not put a button or another interactive control inside the default `FormAdornment` label. If the wrapper needs interactive content, use its `as` prop to render a non-label element and label the input separately.

See the [form control][2] documentation for more information on [`FormControl`][2] and `FormGhost`.

## Example

Use `FormAdornment` to wrap an icon and a `FormGhost` input. Place the adornment before the input in the DOM to position it at the start (left in LTR).

<CodeExample>
    <FormAdornment>
        <FormAdornmentIcon name="search" aria-hidden="true" />
        <FormGhost type="search" placeholder="Search..." />
    </FormAdornment>
</CodeExample>

Set the `end` prop to position the adornment on the trailing side. The DOM order stays the same while the visual order changes:

<CodeExample>
    <FormAdornment end>
        <FormAdornmentIcon name="envelope" aria-hidden="true" />
        <FormGhost type="email" placeholder="you@example.com" />
    </FormAdornment>
</CodeExample>

## With labels

Add a [`FormLabel`][1] outside `FormAdornment` to give the field a visible name. Set its `htmlFor` prop to the `id` of the `FormGhost` input so the label remains associated with the field if you change the wrapper:

<CodeExample>
    <Stack gap={3}>
        <div>
            <FormLabel htmlFor="searchInput">Search</FormLabel>
            <FormAdornment>
                <FormAdornmentIcon name="search" aria-hidden="true" />
                <FormGhost type="search" id="searchInput" placeholder="Search..." />
            </FormAdornment>
        </div>
        <div>
            <FormLabel htmlFor="emailInput">Email address</FormLabel>
            <FormAdornment end>
                <FormAdornmentIcon name="envelope" aria-hidden="true" />
                <FormGhost type="email" id="emailInput" placeholder="you@example.com" />
            </FormAdornment>
        </div>
    </Stack>
</CodeExample>

## With form field

Use [`FormField`][1] to group [`FormLabel`][1], `FormAdornment`, and [`FormText`][1] into a field with a label and description.

<CodeExample>
    <FormField>
        <FormLabel htmlFor="adornField">Search</FormLabel>
        <FormAdornment>
            <FormAdornmentIcon name="search" aria-hidden="true" />
            <FormGhost type="search" id="adornField" placeholder="Search..." />
        </FormAdornment>
        <FormText>Search across all pages and posts.</FormText>
    </FormField>
</CodeExample>

## Text adornments

Use `FormAdornmentText` for currency symbols, units, domain suffixes, and other text-based adornments. Text adornments auto-size to their content.

<CodeExample>
    <Stack gap={3}>
        <FormAdornment>
            <FormAdornmentText aria-hidden="true">$</FormAdornmentText>
            <FormGhost type="text" placeholder="0.00" />
        </FormAdornment>
        <FormAdornment end>
            <FormAdornmentText aria-hidden="true">USD</FormAdornmentText>
            <FormGhost type="text" placeholder="Amount" />
        </FormAdornment>
        <FormAdornment>
            <FormAdornmentText aria-hidden="true">https://</FormAdornmentText>
            <FormGhost type="text" placeholder="example.com" />
        </FormAdornment>
        <FormAdornment end>
            <FormAdornmentText aria-hidden="true">@example.com</FormAdornmentText>
            <FormGhost type="text" placeholder="username" />
        </FormAdornment>
    </Stack>
</CodeExample>

## Sizing

Set the `size` prop to `sm` or `lg` on `FormAdornment` to adjust its size.

<CodeExample>
    <Stack gap={3}>
        <FormAdornment size="sm">
            <FormAdornmentIcon name="search" aria-hidden="true" />
            <FormGhost type="text" placeholder="Small input" />
        </FormAdornment>
        <FormAdornment>
            <FormAdornmentIcon name="search" aria-hidden="true" />
            <FormGhost type="text" placeholder="Default input" />
        </FormAdornment>
        <FormAdornment size="lg">
            <FormAdornmentIcon name="search" aria-hidden="true" />
            <FormGhost type="text" placeholder="Large input" />
        </FormAdornment>
    </Stack>
</CodeExample>
