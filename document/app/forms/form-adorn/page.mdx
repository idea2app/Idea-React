# Form adornments

Add a leading or trailing icon or text inside a single control border. Use `FormGhost` inside
`FormAdornment` so the inner input does not add another border.

## Quick start

<CodeExample>
    <FormField>
        <FormLabel htmlFor="adornSearch">Search</FormLabel>
        <FormAdornment htmlFor="adornSearch" size="lg">
            <FormAdornmentIcon name="search" aria-hidden="true" />
            <FormGhost id="adornSearch" placeholder="Search…" aria-describedby="adornHelp" />
        </FormAdornment>
        <FormText id="adornHelp">Search by name.</FormText>
    </FormField>
    <FormAdornment htmlFor="adornPrice" end size="sm" className="mt-3">
        <FormGhost id="adornPrice" aria-label="Price" type="number" />
        <FormAdornmentText>USD</FormAdornmentText>
    </FormAdornment>
</CodeExample>

`end` places the adornment after the input; `size="sm"` and `"lg"` size the entire field.
Use `FormAdornmentText` for currencies, units or prefixes and `FormAdornmentIcon` for icons.
The wrapper can itself supply a label via `htmlFor`, or compose it inside `FormField`.
Native readonly/disabled state belongs on the input; `validation` can style both wrappers and inputs.
