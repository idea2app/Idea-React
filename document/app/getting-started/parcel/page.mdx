# Bootstrap and Parcel

[View the Bootstrap source for this page on GitHub][1]

## What is Parcel?

[Parcel][2] is a web application bundler designed to simplify development
with zero-configuration defaults. It supports the TypeScript and TSX files used by Idea React.

## Setup

This guide requires Node.js and some familiarity with the terminal. Create a project folder and
initialize its package manifest:

```sh
mkdir my-project
cd my-project
pnpm init
```

Install Parcel and its TypeScript transformer as development dependencies, followed by Idea
React's runtime peers:

```sh
pnpm add -D parcel @parcel/config-default @parcel/transformer-typescript-tsc
pnpm add idea-react@next react react-dom mobx mobx-react
```

For stable releases, install `idea-react` without the `@next` dist-tag. Use the same `@parcel`
transformer version as your Parcel version.

## Project structure

Create the HTML entry point, a TypeScript React module, and the Parcel and TypeScript
configuration files shown below. Run the following from the project root:

```sh
mkdir src
```

```text
my-project/
├── .parcelrc
├── package.json
├── tsconfig.json
└── src/
    ├── index.html
    └── main.tsx
```

## Configure Parcel

Parcel does not require configuration for a basic HTML application. To type-check TypeScript and
TSX as this repository does, use the repository's [Parcel configuration][3] to extend the default
pipeline and route `.ts` and `.tsx` files through TypeScript:

```json
{
    "extends": "@parcel/config-default",
    "transformers": {
        "*.{ts,tsx}": ["@parcel/transformer-typescript-tsc"]
    }
}
```

The relevant TypeScript compiler options enable automatic React JSX, bundler module resolution,
and standard class-field semantics:

```json
{
    "compilerOptions": {
        "target": "ES6",
        "module": "ES2020",
        "moduleResolution": "bundler",
        "useDefineForClassFields": true,
        "jsx": "react-jsx"
    }
}
```

`useDefineForClassFields` preserves the field semantics required by MobX's stage-3 decorators.
For the complete set of repository options, see its [TypeScript configuration][4].

Add scripts to `package.json`:

```json
{
    "scripts": {
        "dev": "parcel src/index.html",
        "build": "parcel build src/index.html"
    }
}
```

In `src/index.html`, provide a mount point and load the TypeScript entry. The Bootstrap stylesheet
is added in the following section:

```html
<!doctype html>
<html lang="en">
    <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
        <title>Idea React with Parcel</title>
    </head>
    <body>
        <div id="root"></div>
        <script type="module" src="./main.tsx"></script>
    </body>
</html>
```

Start the development server or create a production build:

```sh
pnpm dev
pnpm build
```

## Import Bootstrap

Load Bootstrap's CSS from unpkg or jsDelivr in the document `<head>`. The CDN stylesheet provides
the component styles without requiring a Sass pipeline:

```html
<link
    rel="stylesheet"
    href="https://unpkg.com/bootstrap@6.0.0-alpha.1/dist/css/bootstrap.min.css"
    crossorigin="anonymous"
/>
```

Then import Idea React components from the package and render them from `src/main.tsx`:

```tsx
import { createRoot } from 'react-dom/client';
import { Button } from 'idea-react/Button';

createRoot(document.getElementById('root')!).render(
    <Button type="button" variant="solid" theme="primary">
        Hello, Idea React and Parcel!
    </Button>
);
```

The component wrappers provide React behavior, so importing Bootstrap's JavaScript bundle is
unnecessary. The source package's root build uses tsdown; Parcel is configured for TypeScript
transformation and is not the command used to publish the package.
