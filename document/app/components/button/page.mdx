# Button

Use Bootstrap’s custom button styles for actions in forms, dialogs, and more with support for multiple sizes, states, and more.

`Button` renders a native button, or an anchor when given `href`. Its `variant`, `theme`, `size`,
`icon`, `styled`, `active`, and `disabled` props generate the styles described below. Use
`ButtonInput` for input elements and `ToggleButton` for checkbox- or radio-backed controls.

## Base class

`Button` applies its base button styles automatically. Set its `variant` and `theme` props to choose the visual style and color.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button>Base class</Button>
    </div>
</CodeExample>

Use `Button`'s `className` prop to add custom styles; built-in variants can be combined with the `theme` prop or extended in your own styles.

The gradient and shadow can be customized via CSS variables:

| Variable                            | Description                                                                   |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| `--bs-btn-gradient-start`           | Top of gradient (default: `rgb(255 255 255 / 12.5%)`)                         |
| `--bs-btn-gradient-end`             | Bottom of gradient (default: `rgb(0 0 0 / 7.5%)`)                             |
| `--bs-btn-border-mix-color`         | Color to mix with the button background (default: `#000`)                     |
| `--bs-btn-border-mix-amount`        | Amount of color to mix with the button background (default: `10%`)            |
| `--bs-btn-border-hover-mix-amount`  | Amount of color to mix with the button background on hover (default: `12.5%`) |
| `--bs-btn-border-active-mix-amount` | Amount of color to mix with the button background on active (default: `20%`)  |
| `--bs-btn-shadow`                   | Resting state shadow                                                          |
| `--bs-btn-active-shadow`            | Pressed/active state shadow                                                   |

## Button tags

`Button` renders a native `<button>` by default and renders an `<a>` when `href` is provided. In either case, its default ARIA role is `button`; provide an explicit `role` only when you need to override it.

`ButtonInput` renders an `<input>` element with native button behavior.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" theme="primary" href="#">
            Link
        </Button>
        <Button variant="solid" theme="primary" type="submit">
            Button
        </Button>
        <ButtonInput variant="solid" theme="primary" type="button" defaultValue="Input" />
        <ButtonInput variant="solid" theme="primary" type="submit" defaultValue="Submit" />
        <ButtonInput variant="solid" theme="primary" type="reset" defaultValue="Reset" />
    </div>
</CodeExample>

## Icon buttons

Set the `icon` prop on `Button` for a square icon-only button. It sets a 1:1 aspect ratio and removes padding, making the button square based on its minimum height. Always include an `aria-label` on icon-only buttons for screen reader users.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button icon aria-label="Magic">
            <Icon name="magic" aria-hidden />
        </Button>
        <Button variant="solid" icon theme="primary" aria-label="Confirm">
            <Icon name="check2" aria-hidden />
        </Button>
        <Button variant="outline" icon theme="secondary" aria-label="Auto theme">
            <Icon name="circle-half" aria-hidden />
        </Button>
        <Button variant="subtle" icon theme="warning" aria-label="Light theme">
            <Icon name="sun-fill" aria-hidden />
        </Button>
    </div>
</CodeExample>

Combine with the `size` prop for different icon button sizes:

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button variant="solid" icon size="xs" theme="primary" aria-label="Confirm">
            <Icon name="check2" aria-hidden />
        </Button>
        <Button variant="solid" icon size="sm" theme="primary" aria-label="Confirm">
            <Icon name="check2" aria-hidden />
        </Button>
        <Button variant="solid" icon theme="primary" aria-label="Confirm">
            <Icon name="check2" aria-hidden />
        </Button>
        <Button variant="solid" icon size="lg" theme="primary" aria-label="Confirm">
            <Icon name="check2" aria-hidden />

</CodeExample>

## Disabled state

Set the `disabled` prop on `Button` to prevent interaction and apply disabled styling. Native button elements also prevent activation when disabled.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" theme="primary" disabled>
            Primary button
        </Button>
        <Button variant="solid" theme="secondary" disabled>
            Button
        </Button>
        <Button variant="outline" theme="primary" disabled>
            Primary button
        </Button>
        <Button variant="outline" theme="secondary" disabled>
            Button
        </Button>
    </div>
</CodeExample>

When `Button` renders as a link, its `disabled` prop removes navigation and keyboard focus as well as applying disabled styling.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button variant="solid" theme="primary" disabled aria-disabled="true" href="#">
            Primary link
        </Button>
        <Button variant="solid" theme="secondary" disabled aria-disabled="true" href="#">
            Link
        </Button>
    </div>
</CodeExample>

If there’s an `href` attribute, add `tabindex="-1"` and `aria-disabled="true"` to prevent keyboard focus and assistive technologies from interacting with the link.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button
            variant="solid"
            theme="primary"
            disabled
            href="#"
            tabIndex={-1}
            aria-disabled="true"
        >
            Primary link
        </Button>
        <Button
            variant="solid"
            theme="secondary"
            disabled
            href="#"
            tabIndex={-1}
            aria-disabled="true"
        >
            Link
        </Button>
    </div>
</CodeExample>

You may also want to use custom JavaScript to disable the link functionality altogether.

In these React examples, `disabled` handles this for you: `Button` removes the link destination,
prevents navigation, and supplies `aria-disabled` and `tabIndex={-1}`.

## Block buttons

Use a grid container with gap utilities passed through `className` to create a vertical stack of
full-width buttons.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2">
            <Button variant="solid" theme="primary">
                Button
            </Button>
            <Button variant="solid" theme="primary">
                Button
            </Button>
        </div>
    </div>
</CodeExample>

This responsive variation changes from a vertical stack to a horizontal layout at the `md`
breakpoint. Resize your browser to see the layout change.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2 md:d-block">
            <Button variant="solid" theme="primary">
                Button
            </Button>
            <Button variant="solid" theme="primary">
                Button
            </Button>
        </div>
    </div>
</CodeExample>

Use a [`Col`][1] with `xs={6}` to constrain the button stack to half the available width, and center it
with margin utilities passed through `className`.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Col xs={6} className="d-grid gap-2 mx-auto">
            <Button variant="solid" theme="primary">
                Button
            </Button>
            <Button variant="solid" theme="primary">
                Button
            </Button>
        </Col>
    </div>
</CodeExample>

Additional utilities can be used to adjust the alignment of buttons when horizontal. Here we’ve taken our previous responsive example and added some flex utilities and a margin utility on the button to right-align the buttons when they’re no longer stacked.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2 md:d-flex md:justify-content-end">
            <Button variant="solid" theme="primary" className="md:me-2">
                Button
            </Button>
            <Button variant="solid" theme="primary">
                Button
            </Button>
        </div>
    </div>
</CodeExample>

## Toggle buttons

Use `ToggleButton` to create button-like checkboxes and radio buttons. It provides the button appearance and interaction behavior, and can be grouped in a [button group][2].

> Visually, these toggle buttons are identical to our [active-state buttons][3], but are conveyed differently by assistive technologies. [Checkbox][4] toggles will be announced by screen readers as "checked"/"not checked" as they are checkboxes under the hood. Active-state buttons are announced as "button"/"button pressed". It’s up to you to decide which approach makes more sense for your use case.

### Checkboxes

Checkboxes can be checked, unchecked, or disabled. Checkbox-based toggle buttons only toggle a single button’s state.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <ToggleButton variant="solid" theme="primary" type="checkbox" defaultChecked>
            Checked
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="checkbox">
            Toggle
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="checkbox" disabled>
            Disabled
        </ToggleButton>
    </div>
</CodeExample>

### Radios

Radios can be checked, unchecked, or disabled. Use radio-based toggle buttons to toggle states between a set of buttons that include input elements with the same `name` attribute value.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <ToggleButton variant="solid" theme="primary" type="radio" name="options" defaultChecked>
            Checked
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options">
            Toggle
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options" disabled>
            Disabled
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options">
            Toggle
        </ToggleButton>
    </div>
</CodeExample>

## Active state

`Button` does not manage active state. Pass `active` from application state so the application remains the source of truth.

For toggle semantics, `Button` sets `aria-pressed` when `active` is provided. Buttons without `active` remain ordinary buttons.

### Toggle buttons

Render the active state supplied by your application:

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" active={false} theme="primary">
            Inactive toggle button
        </Button>
        <Button variant="solid" active theme="primary">
            Active toggle button
        </Button>
        <Button variant="solid" active={false} theme="primary" disabled>
            Disabled toggle button
        </Button>
    </div>
</CodeExample>

<CodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" active={false} theme="primary" href="#">
            Inactive link button
        </Button>
        <Button variant="solid" active theme="primary" href="#">
            Active toggle link
        </Button>
        <Button variant="solid" theme="primary" disabled aria-disabled="true" href="#">
            Disabled link button
        </Button>
    </div>
</CodeExample>

Because `Button` defaults to the `button` role even when `href` renders an anchor, the `active` prop also supplies `aria-pressed` without additional role configuration.
