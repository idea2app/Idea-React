# Button

Use Bootstrap’s custom button styles for actions in forms, dialogs, and more with support for multiple sizes, states, and more.

`Button` renders a native button, or an anchor when given `href`. Its `variant`, `theme`, `size`,
`icon`, `styled`, `active`, and `disabled` props generate the styles described below. Use
`ButtonInput` for input elements and `ToggleButton` for checkbox- or radio-backed controls.

## Base class

Buttons have a standard `.btn` class that sets up basic styles such as padding and content alignment, along with fallback visual styles for basic accessibility. Change this class to another button class to apply different visual styles for a specific button variant and theme.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button type="button">Base class</Button>
    </div>
</DocumentCodeExample>

The `.btn` class is intended to be a starting point for your own custom button styles, while our provided button variants can be used alongside `.theme-*` classes or as a basis for your own custom styles.

The gradient and shadow can be customized via CSS variables:

| Variable                            | Description                                                                   |
| ----------------------------------- | ----------------------------------------------------------------------------- |
| `--bs-btn-gradient-start`           | Top of gradient (default: `rgb(255 255 255 / 12.5%)`)                         |
| `--bs-btn-gradient-end`             | Bottom of gradient (default: `rgb(0 0 0 / 7.5%)`)                             |
| `--bs-btn-border-mix-color`         | Color to mix with the button background (default: `#000`)                     |
| `--bs-btn-border-mix-amount`        | Amount of color to mix with the button background (default: `10%`)            |
| `--bs-btn-border-hover-mix-amount`  | Amount of color to mix with the button background on hover (default: `12.5%`) |
| `--bs-btn-border-active-mix-amount` | Amount of color to mix with the button background on active (default: `20%`)  |
| `--bs-btn-shadow`                   | Resting state shadow                                                          |
| `--bs-btn-active-shadow`            | Pressed/active state shadow                                                   |

## Button tags

The `.btn` classes are designed to be used with the `<button>` element. However, you can also use these classes on `<a>` or `<input>` elements (though some browsers may apply a slightly different rendering).

When using button classes on `<a>` elements that are used to trigger in-page functionality (like collapsing content), rather than linking to new pages or sections within the current page, these links should be given a `role="button"` to appropriately convey their purpose to assistive technologies such as screen readers.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" theme="primary" href="#" role="button">
            Link
        </Button>
        <Button variant="solid" theme="primary" type="submit">
            Button
        </Button>
        <ButtonInput variant="solid" theme="primary" type="button" defaultValue="Input" />
        <ButtonInput variant="solid" theme="primary" type="submit" defaultValue="Submit" />
        <ButtonInput variant="solid" theme="primary" type="reset" defaultValue="Reset" />
    </div>
</DocumentCodeExample>

## Icon buttons

Use `.btn-icon` for square buttons that contain only an icon. This class sets `aspect-ratio: 1` and removes padding, making the button perfectly square based on its `min-height`. Always include an `aria-label` attribute on icon-only buttons to ensure they are accessible to screen reader users.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button icon type="button" aria-label="Magic">
            <Icon name="magic" aria-hidden />
        </Button>
        <Button variant="solid" icon theme="primary" type="button" aria-label="Confirm">

## Disabled state

Make buttons look inactive by adding the `disabled` boolean attribute to any `<button>` element. Disabled buttons have `pointer-events: none`, preventing hover and active states from triggering, and some additional styling to indicate the disabled state.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" theme="primary" type="button" disabled>
            Primary button
        </Button>
        <Button variant="solid" theme="secondary" type="button" disabled>
            Button
        </Button>
        <Button variant="outline" theme="primary" type="button" disabled>
            Primary button
        </Button>
        <Button variant="outline" theme="secondary" type="button" disabled>
            Button
        </Button>
    </div>
</DocumentCodeExample>

Disabled buttons using the `<a>` element behave a bit different. Use the `.disabled` class instead of the attribute on `<a>` elements to make them visually appear disabled. If you need to keep the `href` attribute, you may need additional HTML to fully disable the link functionality.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button
            variant="solid"
            theme="primary"
            disabled
            role="button"
            aria-disabled="true"
            href="#"
        >
            Primary link
        </Button>
        <Button
            variant="solid"
            theme="secondary"
            disabled
            role="button"
            aria-disabled="true"
            href="#"
        >
            Link
        </Button>
    </div>
</DocumentCodeExample>

If there’s an `href` attribute, add `tabindex="-1"` and `aria-disabled="true"` to prevent keyboard focus and assistive technologies from interacting with the link.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Button
            variant="solid"
            theme="primary"
            disabled
            href="#"
            tabIndex={-1}
            role="button"
            aria-disabled="true"
        >
            Primary link
        </Button>
        <Button
            variant="solid"
            theme="secondary"
            disabled
            href="#"
            tabIndex={-1}
            role="button"
            aria-disabled="true"
        >
            Link
        </Button>
    </div>
</DocumentCodeExample>

You may also want to use custom JavaScript to disable the link functionality altogether.

In these React examples, `disabled` handles this for you: `Button` removes the link destination,
prevents navigation, and supplies `aria-disabled` and `tabIndex={-1}`.

## Block buttons

Use the `.d-grid` utility to create responsive stacks of full-width “block buttons”. Space them out with gap utilities.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2">
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
        </div>
    </div>
</DocumentCodeExample>

Here we create a responsive variation, starting with vertically stacked buttons until the `md` breakpoint, where `.md:d-block` replaces the `.d-grid` class, thus nullifying the `gap-2` utility. Resize your browser to see them change.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2 md:d-block">
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
        </div>
    </div>
</DocumentCodeExample>

You can adjust the width of your block buttons with grid column width classes. For example, for a half-width “block button”, use `.col-6`. Center it horizontally with `.mx-auto`, too.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <Col xs={6} className="d-grid gap-2 mx-auto">
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
        </Col>
    </div>
</DocumentCodeExample>

Additional utilities can be used to adjust the alignment of buttons when horizontal. Here we’ve taken our previous responsive example and added some flex utilities and a margin utility on the button to right-align the buttons when they’re no longer stacked.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center overflow-auto">
        <div className="d-grid gap-2 md:d-flex md:justify-content-end">
            <Button variant="solid" theme="primary" type="button" className="md:me-2">
                Button
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Button
            </Button>
        </div>
    </div>
</DocumentCodeExample>

## Toggle buttons

Create button-like checkboxes and radio buttons by adding `.btn-check` to a `<label>` element with button classes, with a checkbox or radio input nested inside. The input is visually hidden while the label provides the button appearance. These toggle buttons can further be grouped in a [button group][1] if needed.

> Visually, these toggle buttons are identical to our [active-state buttons][2], but are conveyed differently by assistive technologies. Checkbox toggles will be announced by screen readers as "checked"/"not checked" as they are checkboxes under the hood. Active-state buttons are announced as "button"/"button pressed". It’s up to you to decide which approach makes more sense for your use case.

### Checkboxes

Checkboxes can be checked, unchecked, or disabled. Checkbox-based toggle buttons only toggle a single button’s state.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <ToggleButton variant="solid" theme="primary" type="checkbox" defaultChecked>
            Checked
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="checkbox">
            Toggle
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="checkbox" disabled>
            Disabled
        </ToggleButton>
    </div>
</DocumentCodeExample>

### Radios

Radios can be checked, unchecked, or disabled. Use radio-based toggle buttons to toggle states between a set of buttons that include input elements with the same `name` attribute value.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <ToggleButton variant="solid" theme="primary" type="radio" name="options" defaultChecked>
            Checked
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options">
            Toggle
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options" disabled>
            Disabled
        </ToggleButton>
        <ToggleButton variant="solid" theme="primary" type="radio" name="options">
            Toggle
        </ToggleButton>
    </div>
</DocumentCodeExample>

## Active state

`Button` does not manage active state. Pass `active` from application state so the application remains the source of truth.

For toggle semantics, `Button` sets `aria-pressed` when `active` is provided. Buttons without `active` remain ordinary buttons.

### Toggle buttons

Render the active state supplied by your application:

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" active={false} theme="primary" type="button">
            Inactive toggle button
        </Button>
        <Button variant="solid" active theme="primary" type="button">
            Active toggle button
        </Button>
        <Button variant="solid" active={false} theme="primary" type="button" disabled>
            Disabled toggle button
        </Button>
    </div>
</DocumentCodeExample>

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 overflow-auto">
        <Button variant="solid" active={false} theme="primary" href="#" role="button">
            Inactive link button
        </Button>
        <Button variant="solid" active theme="primary" href="#" role="button">
            Active toggle link
        </Button>
        <Button
            variant="solid"
            theme="primary"
            disabled
            aria-disabled="true"
            role="button"
            href="#"
        >
            Disabled link button
        </Button>
    </div>
</DocumentCodeExample>

When using links as toggle buttons, set `role="button"` so the `active` prop also supplies `aria-pressed`.
