# Nav overflow

Automatically collapse navigation items into a "More" menu when space is limited using the Priority+ pattern.

## How it works

The nav overflow component (also known as the "Priority+" pattern) automatically detects when navigation items don’t fit within their container and moves them into a menu. This provides a responsive navigation experience without requiring different markup for different screen sizes.

Here’s what you need to know before getting started:

- Place `NavLink` and `Menu` children inside `NavOverflow`, and give the wrapper a unique `id`.
- **Responds to container size**, not viewport size. The component watches the wrapper with a ResizeObserver, so it works in embedded contexts, documentation examples, and responsive containers.
- The wrapper is what makes this reliable. Collapsing items changes the width of the nav, so the component measures the wrapper instead. Measuring the nav would feed the result back in as the input.
- Overflow items are represented in a "More" menu while the originals are hidden. A nav item that hosts a menu becomes a submenu of the overflow menu.
- Works with all nav styles: default, pills, tabs, and underline.
- Active and disabled states are preserved in the overflow menu.

> The animation effect depends on the `prefers-reduced-motion` media query. See the [reduced motion accessibility guidance][1].

## Customizing the toggle

### Custom text

Use the `moreText` option to customize the text shown in the overflow toggle button:

```tsx
<NavOverflow id="custom-text" moreText="See all">
    <NavLink href="#first">First</NavLink>
    <NavLink href="#second">Second</NavLink>
</NavOverflow>
```

### Custom icon

Provide a custom icon via the `moreIcon` prop, using the `Icon` component:

```tsx
<NavOverflow id="custom-icon" moreIcon={<Icon name="three-dots" />} moreText={false}>
    <NavLink href="#first">First</NavLink>
    <NavLink href="#second">Second</NavLink>
</NavOverflow>
```

Set `moreText` to `false` for an icon-only toggle. The component labels the button `aria-label="More"` so it still has an accessible name. An empty string does the same. React nodes are passed directly through `moreIcon`; HTML strings and `data-bs-overflow-icon` extraction are not used.

### Icon placement

Use the `iconPlacement` option to position the icon before (`'start'`, the default) or after (`'end'`) the text:

```tsx
<NavOverflow id="icon-placement" moreText="Menu" iconPlacement="end">
    <NavLink href="#first">First</NavLink>
    <NavLink href="#second">Second</NavLink>
</NavOverflow>
```

### Minimum visible items

Use the `threshold` option to ensure a minimum number of items remain visible before the overflow kicks in:

```tsx
<NavOverflow id="minimum-visible" threshold={3}>
    <NavLink href="#first">First</NavLink>
    <NavLink href="#second">Second</NavLink>
    <NavLink href="#third">Third</NavLink>
    <NavLink href="#fourth">Fourth</NavLink>
</NavOverflow>
```

### Collapse all

Use the `collapseBelow` option to force all items into the overflow dropdown when the wrapper’s width is below a threshold. Pass a breakpoint name to resolve the value from `--bs-breakpoint-{name}`, or a number for a direct pixel value.

```tsx
<NavOverflow id="collapse-at-breakpoint" variant="pills" collapseBelow="md">
    <NavLink href="#">{'Link 1'}</NavLink>
    <NavLink href="#">{'Link 2'}</NavLink>
    <NavLink href="#">{'Link 3'}</NavLink>
</NavOverflow>
```

Or use a raw pixel value:

```tsx
<NavOverflow id="collapse-at-width" collapseBelow={768}>
    <NavLink href="#first">First</NavLink>
    <NavLink href="#second">Second</NavLink>
</NavOverflow>
```

Above the threshold, normal progressive collapse resumes. Items with `.nav-overflow-keep` are never collapsed.

## Usage

### Options

Pass options as React props. The component initializes on mount, updates on resize, and disposes its observers on unmount.

| Name                  | Type                      | Default        | Description                                                                                                        |
| --------------------- | ------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------ |
| `collapseBelow`       | number or string          | `0`            | Wrapper width below which all items collapse. Pass a breakpoint name or a pixel value; `0` disables this behavior. |
| `iconPlacement`       | `'start'` or `'end'`      | `'start'`      | Position of the icon relative to the toggle text.                                                                  |
| `menuPlacement`       | string                    | `'bottom-end'` | Placement of the overflow menu.                                                                                    |
| `menuStrategy`        | `'absolute'` or `'fixed'` | `'absolute'`   | Use `'fixed'` when an overflow ancestor would clip the menu.                                                       |
| `moreText`            | string or `false`         | `'More'`       | Toggle label; `false` or an empty string produces an icon-only toggle.                                             |
| `moreIcon`            | ReactNode                 | Chevron icon   | Custom toggle icon.                                                                                                |
| `threshold`           | number                    | `0`            | Minimum number of items to keep visible before showing overflow.                                                   |
| `minimumVisibleItems` | number                    | `threshold`    | Explicit alias that takes precedence over `threshold`.                                                             |

### Methods

The instance method `updateOverflow()` manually recalculates overflow. Resizing and prop changes already trigger it automatically.

### Events

Use `onOverflowChange(overflowCount, visibleCount)` to observe overflow calculations.
