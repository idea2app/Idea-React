# Spinner button

[`SpinnerButton`][1] extends [Button](../button/) with a `loading` state that shows an inline
[Spinner](../spinner/) and disables the button while work is in progress.

## Example

<div className="d-flex flex-wrap gap-2">
    <SpinnerButton theme="primary" loading>
        Saving…
    </SpinnerButton>
    <SpinnerButton theme="primary">Save</SpinnerButton>
</div>

## Usage

```tsx
<SpinnerButton theme="primary" animation="grow" loading={submitting} onClick={submit}>
    Submit
</SpinnerButton>
```

All [Button](../button/) props pass through, and `animation` selects the spinner animation. When the
button has no children while loading, a visually hidden "Loading..." label keeps it accessible.
