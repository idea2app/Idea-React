# Alert

Provide contextual feedback messages for typical user actions with the handful of available and flexible alert messages.

## Default alert

Alerts are flex containers that can contain any length of text, as well as an optional close button. They’re designed to be used with theme colors, but have neutral fallback colors for when no theme color is applied. For inline dismissal, use the `dismissible` prop. [Custom content][1] is also supported, with additional utilities or markup required.

<DocumentCodeExample>
    <Alert>
        <p>A simple alert—check it out!</p>
    </Alert>
</DocumentCodeExample>

## Dismiss

Use the `dismissible` prop to dismiss an alert inline. Here’s how:

- `dismissible` adds a [close button][4] to the alert.
- Use `onClosed` to synchronize application state after dismissal.

An alert fades out before it is removed. The wrapper adds its exit state for the length of the transition, so no extra classes are needed in your markup. Pass `instant` to remove the alert at once instead. See [Transitions][5] for the tokens that tune the fade.

You can see this in action with a live demo:

<DocumentCodeExample>
    <Alert theme="warning" dismissible>
        <p>Something’s wrong, check the fields below and try again.</p>
    </Alert>
</DocumentCodeExample>

When an alert is dismissed, the element is completely removed from the page structure. If a keyboard user dismisses the alert using the close button, their focus will suddenly be lost and, depending on the browser, reset to the start of the page/document. For this reason, we recommend including additional JavaScript that handles the `onClosed` callback and programmatically sets `focus()` to the most appropriate location in the page. If you’re planning to move focus to a non-interactive element that normally does not receive focus, make sure to add `tabindex="-1"` to the element.

## Additional content

For simple vertical layouts, it should be enough to add the `flex-column` class to the alert.

<DocumentCodeExample>
    <Alert theme="success" className="flex-column align-items-stretch">
        <AlertHeading className="mb-2">Well done!</AlertHeading>
        <p>
            Aww yeah, you successfully read this important alert message. This example text is going
            to run a bit longer so that you can see how spacing within an alert works with this kind
            of content.
        </p>
        <hr className="my-3" />
        <p>Whenever you need to, be sure to use margin utilities to keep things nice and tidy.</p>
    </Alert>
</DocumentCodeExample>

More complex layouts may require additional HTML within the alert—like when mixing in icons and dismiss buttons.

<DocumentCodeExample>
    <Alert theme="warning" dismissible>
        <div className="pe-3">
            <AlertHeading className="mb-2">More complex alert</AlertHeading>
            <p className="fs-sm mb-0">
                Aww yeah, you successfully read this important alert message. This example text is
                going to run a bit longer so that you can see how spacing within an alert works with
                this kind of content.
            </p>
        </div>
    </Alert>
</DocumentCodeExample>

## CSS

### Variables

Local CSS custom properties expose the component’s colors, spacing, borders, and transitions. Override them through `style` or a CSS module. The defaults below come from the Bootstrap stylesheet used by Idea React; see the [upstream variable reference][6].

| Variable                         | Default                  |
| -------------------------------- | ------------------------ |
| `--bs-alert-gap`                 | `var(--bs-spacer-3)`     |
| `--bs-alert-bg`                  | `var(--bs-bg-1)`         |
| `--bs-alert-padding-x`           | `var(--bs-spacer)`       |
| `--bs-alert-padding-y`           | `var(--bs-spacer)`       |
| `--bs-alert-color`               | `inherit`                |
| `--bs-alert-border-color`        | `var(--bs-border-color)` |
| `--bs-alert-border-radius`       | `var(--bs-radius-7)`     |
| `--bs-alert-link-color`          | `inherit`                |
| `--bs-alert-transition-property` | `opacity`                |
| `--bs-alert-transition-duration` | `0.15s`                  |
| `--bs-alert-transition-timing`   | `linear`                 |

## JavaScript behavior

The React wrapper manages dismissal and removes the alert after its fade transition. Do not initialize a Bootstrap plugin on the same element.

### Events

`onClose` runs when dismissal begins, and `onClosed` runs after the transition and removal. Use `onClosed` to restore keyboard focus to an appropriate control, as in the live example.
