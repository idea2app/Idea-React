# Cards

Bootstrap's cards provide a flexible and extensible content container with multiple variants and
options.

Idea React provides the [`Card`, `CardBody`, `CardTitle`, and `CardText` wrappers][1] for these
examples. Use other Bootstrap wrappers such as [`Button`][2], [`Image`][3], and [`Nav`][4] inside
them.

## Example

Cards are flexible and extensible content containers with support for headers and footers, a wide
variety of content, contextual background colors, and additional display options. **Cards have no
fixed width to start**, so they'll naturally fill the width of their parent element, or slot into
your grid columns.

<Card style={{ maxWidth: '320px' }}>
    <Image
        src="https://picsum.photos/seed/idea-react-card/400/180"
        alt="Card image cap"
        width={400}
        height={180}
        className="card-img-top"
    />
    <CardBody>
        <CardTitle>Card title</CardTitle>
        <CardText>
            {
                "Some quick example text to build on the card title and make up the bulk of the card's content."
            }
        </CardText>
        <Button href="#" variant="solid" theme="primary">
            Go somewhere
        </Button>
    </CardBody>
</Card>

## How it works

Cards are built with as little markup and styles as possible, but still manage to deliver a ton of
control and customization.

- Cards are flexbox containers, so they offer easy alignment via flexbox utilities and grid column
  classes.

- `.card` has no default padding, you need `CardBody` for that. Use it as a modifier class or a
  child element alongside headers, footers, images, and more. This allows greater flexibility with
  the least amount of overhead.

- Cards have no `margin` by default. Use margin utilities or gap utilities as needed.

- Cards can contain text, images, lists, and most other HTML.

- Choose semantic HTML that fits the content. We use `<div>`s for simplicity's sake in our
  documentation, but you can also use `<section>`, `<article>`, etc.

## Content types

### Body

The building block of a card is the `.card-body`. Use `CardBody` whenever you need a padded section
within a card.

<Card>
    <CardBody>This is some text within a card body.</CardBody>
</Card>

For simple cards, you can render `card-body` directly on the card element.

<Card className="card-body">This is some text within a card body.</Card>

### Titles, text, and links

Card bodies arrange their direct children in a column and apply a consistent gap, so titles and text
need no styles of their own. Use these optional classes as content hooks.

- For a title, use `CardTitle` (`.card-title`).
- For a subtitle, use `.card-subtitle`. It reduces the gap above the subtitle.
- For text, use `CardText` (`.card-text`).

Use type and color utilities as needed. A color utility on `.card-subtitle` overrides
`--card-subtitle-color`. Links need no card-specific class.

<Card style={{ maxWidth: '320px' }}>
    <CardBody>
        <CardTitle>Example card title</CardTitle>
        <p className="card-subtitle fg-3">With a card subtitle</p>
        <CardText>
            {
                "Some quick example text to build on the card title and make up the bulk of the card's content."
            }
        </CardText>
        <a href="#">Card link</a>
    </CardBody>
</Card>

### List groups

When your card only contains a list group—no header, footer, or body—use a `.list-group` on its own.
A card already draws an outer border, so a default list group inside a card would double that
border.

<ul className="list-group" style={{ width: '18rem' }}>
    <li className="list-group-item">An item</li>
    <li className="list-group-item">A second item</li>
    <li className="list-group-item">A third item</li>
</ul>

When you mix a list group with other card sub-components, add `.list-group-flush` to drop the list's
own outer border.

<Card style={{ width: '18rem' }}>
    <div className="card-header">Featured</div>
    <ul className="list-group list-group-flush">
        <li className="list-group-item">An item</li>
        <li className="list-group-item">A second item</li>
        <li className="list-group-item">A third item</li>
    </ul>
</Card>

<Card style={{ width: '18rem' }}>
    <ul className="list-group list-group-flush">
        <li className="list-group-item">An item</li>
        <li className="list-group-item">A second item</li>
        <li className="list-group-item">A third item</li>
    </ul>
    <div className="card-footer">Card footer</div>
</Card>

## Width

Cards assume no specific `width` to start, so they'll be 100% wide unless otherwise stated. You can
change this as needed with custom CSS, grid classes, grid Sass mixins, or utilities.

### Grid

Using the grid, wrap cards in columns and rows as needed.

<Row>
    <Col sm={6} className="mb-3 sm:mb-0">
        <Card>
            <CardBody>
                <CardTitle>Card title</CardTitle>
                <CardText>
                    {'With supporting text below as a natural lead-in to additional content.'}
                </CardText>
                <Button href="#" variant="solid" theme="primary">
                    Go somewhere

            </CardBody>
        </Card>

In addition to styling the content within cards, Bootstrap includes a few options for laying out
series of cards.

starting at the `sm` breakpoint.

medium breakpoint up.

</Row>
