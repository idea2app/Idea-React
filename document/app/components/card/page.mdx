# Cards

Bootstrap’s cards provide a flexible and extensible content container with multiple variants and options.

The examples compose `Card` with its body, title, text, image, header, footer, and group wrappers.
Use `body`, `row`, `theme`, `subtle`, and `translucent` props instead of adding component classes.

Cards are flexible and extensible content containers with support for headers and footers, a wide variety of content, contextual background colors, and additional display options. **Cards have no fixed width to start**, so they’ll naturally fill the width of their parent element, or slot into your grid columns.

## How it works

Cards are built with as little markup and styles as possible, but still manage to deliver a ton of control and customization.

- Cards are flexbox containers, so align their contents with [flexbox utilities][1] through `className`
  and arrange them with [`Row`][2] and [`Col`][2].

- `Card` has no default padding. Add a `CardBody` child, or set `body` on `Card` for a simple padded card. This allows greater flexibility with the least amount of overhead.

- Cards have no `margin` by default. Use [margin utilities][3] through `className` or set spacing with
  `Stack`'s `gap` prop.

- Cards can contain text, images, lists, and other content components.

- Choose semantic elements that fit the content. Use the `as` prop on `Card` or its child components to render an appropriate element such as `section` or `article`.

## Content types

### Body

The building block of a card is `CardBody`. Use it whenever you need a padded section within a card.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <Card>
            <CardBody>This is some text within a card body.</CardBody>
        </Card>
    </Stack>
</CodeExample>

For simple cards, set the `body` prop directly on `Card`.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <Card body>This is some text within a card body.</Card>
    </Stack>
</CodeExample>

### Titles, text, and links

Card bodies arrange their direct children in a column and apply a consistent gap, so titles and text need no additional styles.

- Use `CardTitle` for a title, `CardSubtitle` for a subtitle, and `CardText` for text. `CardSubtitle` reduces the gap above it.

Use text and color utilities through `className` as needed. A color utility on `CardSubtitle` overrides `--bs-card-subtitle-color`. Links need no card-specific wrapper.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <Card style={{ maxWidth: '320px' }}>
            <CardBody>
                <CardTitle>Example card title</CardTitle>
                <CardSubtitle className="fg-3">With a card subtitle</CardSubtitle>
                <CardText>
                    Some quick example text to build on the card title and make up the bulk of the
                    card’s content.
                </CardText>
                <a href="#">Card link</a>
            </CardBody>
        </Card>
    </Stack>
</CodeExample>

### List groups

When your card only contains a list group—with no header, footer, or body—use [`ListGroup`][4] on its own. A card already draws an outer border, so a default list group inside a card would double that border.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <ListGroup style={{ width: '18rem' }}>
            <ListGroupItem>An item</ListGroupItem>
            <ListGroupItem>A second item</ListGroupItem>
            <ListGroupItem>A third item</ListGroupItem>
        </ListGroup>
    </Stack>
</CodeExample>

When you mix a list group with other card sub-components, set the `flush` prop on [`ListGroup`][4] to remove its outer border.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <Card style={{ width: '18rem' }}>
            <CardHeader>Featured</CardHeader>
            <ListGroup flush>
                <ListGroupItem>An item</ListGroupItem>
                <ListGroupItem>A second item</ListGroupItem>
                <ListGroupItem>A third item</ListGroupItem>
            </ListGroup>
        </Card>
    </Stack>
</CodeExample>

## Width

Cards are 100% wide by default. Set their width with custom CSS, place them in [`Col`][2] components, or
pass sizing utilities through `className`.

### Grid

Using the grid, wrap cards in columns and rows as needed.

<CodeExample>
    <Stack gap={3} className="overflow-auto">
        <Row>
            <Col sm={6} className="mb-3 sm:mb-0">

                    <CardBody>

                        <CardText>
                            With supporting text below as a natural lead-in to additional content.
                        </CardText>
                        <Button variant="solid" theme="primary" href="#">
                            Go somewhere
                        </Button>
                    </CardBody>
                </Card>
            </Col>
            <Col sm={6}>
