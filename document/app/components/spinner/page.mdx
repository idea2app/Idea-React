# Spinners

Indicate the loading state of a component or page with Bootstrap spinners, built entirely with HTML, CSS, and no JavaScript.

`Spinner` accepts `animation="border"` or `"grow"`, `size="sm"`, and native element attributes.
`SpinnerIcon` applies the rotation animation to an `Icon` from the icon font.

Bootstrap “spinners” can be used to show the loading state in your projects. They’re built only with HTML and CSS, meaning you don’t need any JavaScript to create them. You may, however, need some custom JavaScript to toggle their visibility. Their appearance, alignment, and sizing can be easily customized with our utility classes.

For accessibility purposes, each loader here includes `role="status"` and a nested `<span class="visually-hidden">Loading…</span>`.

> The animation effect depends on the `prefers-reduced-motion` media query. See the [reduced motion section of our accessibility documentation][1].

## Border spinner

Use the border spinners for a lightweight loading indicator.

<CodeExample>
    <div className="d-flex align-items-center gap-3">
        <Spinner role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
        <Badge theme="primary">
            <Spinner aria-hidden="true" />
            <span role="status">Loading</span>
        </Badge>
        <Button variant="subtle" theme="primary" type="button" disabled>
            <Spinner aria-hidden="true" />
            <span role="status">Loading…</span>
        </Button>
    </div>
</CodeExample>

## Growing spinner

If you don’t fancy a border spinner, switch to the grow spinner. While it doesn’t technically spin, it does repeatedly grow!

<CodeExample>
    <div className="d-flex align-items-center gap-3">
        <Spinner animation="grow" role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
    </div>
</CodeExample>

## Variants

Spinners use `currentColor` for their appearance, meaning you can customize the color with [text color utilities][2]. You can use any of our text color utilities on the standard spinner.

<CodeExample>
    <div className="d-flex align-items-center gap-3">
        <Spinner role="status" className="fg-primary">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
        <Spinner animation="grow" role="status" className="fg-accent">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
    </div>
</CodeExample>

## Size

Spinner are `1em` by `1em` by default, all Add `.spinner-sm` to make a smaller spinner that can quickly be used within other components.

<CodeExample>
    <div className="d-flex align-items-center gap-3">
        <Spinner size="sm" role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
        <Spinner animation="grow" size="sm" role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
    </div>
</CodeExample>

Or, use custom CSS or inline styles to change the dimensions as needed.

<CodeExample>
    <div className="d-flex align-items-center gap-3">
        <Spinner style={{ width: '3rem', height: '3rem' }} role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
        <Spinner animation="grow" style={{ width: '3rem', height: '3rem' }} role="status">
            <span className="visually-hidden">Loading…</span>
        </Spinner>
    </div>
</CodeExample>

## Custom spinners

You can use the `.spinner-rotate` class to rotate a custom SVG spinner.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <SpinnerIcon name="arrow-repeat" aria-hidden />
    </div>
</CodeExample>

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

Border spinner tokens:

| CSS variable                             | Default          |
| ---------------------------------------- | ---------------- |
| `--bs-spinner-width`                     | `1em`            |
| `--bs-spinner-height`                    | `1em`            |
| `--bs-spinner-border-width`              | `0.125em`        |
| `--bs-spinner-animation-speed`           | `1s`             |
| `--bs-spinner-animation-timing-function` | `linear`         |
| `--bs-spinner-animation-name`            | `spinner-border` |

Growing spinner tokens:

| CSS variable                             | Default          |
| ---------------------------------------- | ---------------- |
| `--bs-spinner-width`                     | `1em`            |
| `--bs-spinner-height`                    | `1em`            |
| `--bs-spinner-animation-speed`           | `1s`             |
| `--bs-spinner-animation-timing-function` | `linear`         |
| `--bs-spinner-animation-name`            | `spinner-border` |

### Keyframes

Used for creating the CSS animations for our spinners. The border spinner rotates through `360deg`; the grow spinner scales from `0` to its full size while fading in. Use `SpinnerIcon` to apply the rotation animation to an icon from the icon font.
