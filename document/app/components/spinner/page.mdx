# Spinner

Bootstrap “spinners” can be used to show the loading state in your projects. They’re built only with
HTML and CSS, meaning you don’t need any JavaScript to create them. You may, however, need some
custom JavaScript to toggle their visibility. Their appearance, alignment, and sizing can be easily
customized with our utility classes.

Idea React provides the [`Spinner` wrapper][1] for these examples.

For accessibility purposes, each loader here includes `role="status"` and a nested
`<span class="visually-hidden">Loading…</span>`.

## Border spinner

Use the border spinners for a lightweight loading indicator.

<div className="d-flex flex-wrap align-items-center gap-3">
    <Spinner role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>

    <Badge theme="primary">
        <Spinner aria-hidden="true" />
        <span role="status">Loading</span>
    </Badge>

    <Button variant="subtle" theme="primary" disabled>
        <Spinner aria-hidden="true" />
        <span role="status">Loading…</span>
    </Button>

</div>

## Growing spinner

If you don’t fancy a border spinner, switch to the grow spinner. While it doesn’t technically spin,
it does repeatedly grow!

<Spinner animation="grow" role="status">
    <span className="visually-hidden">Loading…</span>
</Spinner>

## Variants

Spinners use `currentColor` for their appearance, meaning you can customize the color with text color
utilities. In Idea React, the `theme` prop applies the matching theme color.

<div className="d-flex align-items-center gap-3">
    <Spinner theme="primary" role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
    <Spinner animation="grow" theme="accent" role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
</div>

## Size

Spinners are `1em` by `1em` by default. Add the `size="sm"` prop to make a smaller spinner that can
quickly be used within other components.

<div className="d-flex align-items-center gap-3">
    <Spinner size="sm" role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
    <Spinner animation="grow" size="sm" role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
</div>

Or, use custom CSS or inline styles to change the dimensions as needed.

<div className="d-flex align-items-center gap-3">
    <Spinner style={{ width: '3rem', height: '3rem' }} role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
    <Spinner animation="grow" style={{ width: '3rem', height: '3rem' }} role="status">
        <span className="visually-hidden">Loading…</span>
    </Spinner>
</div>

## Custom spinners

You can use the `.spinner-rotate` class to rotate a custom SVG spinner. Render icons through the
[`Icon` wrapper][2] and apply the class.

<Icon name="arrow-repeat" className="spinner-rotate" />

## CSS

### Variables

Border and growing spinners expose their dimensions, colors, and animation timing through Bootstrap
CSS variables. See the [upstream spinner CSS][3] for the variable reference and keyframes.

`SpinnerButton`, `TableSpinner`, and `Loading` reuse the same wrapper for component-level and
full-page loading states.
