# Nav

Add lists of links to your pages with various navigation components—tabs, pills, underline—and plenty of options to customize.

## Base nav

Navigation available in Bootstrap share general markup and styles, from the base `.nav` class to the active and disabled states. Swap modifier classes to switch between each style.

The base `.nav` component is built with flexbox and provides a strong foundation for building all types of navigation components. It includes some style overrides (for working with lists), some link padding for larger hit areas, and basic disabled styling.

> To convey the active state to assistive technologies, use the `aria-current` attribute — using the `page` value for current page, or `true` for the current item in a set.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Bootstrap supports lists or a `<nav>` element. The `Nav` wrapper uses a semantic `<nav>` with direct `NavLink` children. Because `.nav` uses `display: flex`, these links behave the same as wrapped nav items, without the extra list markup.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Where appropriate, you can also use `<button>` elements instead of `<a>` elements for the nav links. You can even mix and match—for example, by using buttons for menus.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <Menu nav label="Menu">
            <MenuItem href="#">{'Action'}</MenuItem>

            <MenuItem href="#">{'Another action'}</MenuItem>

            <MenuDivider />

            <MenuItem href="#">{'Something else here'}</MenuItem>
        </Menu>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Available styles

Change the style of `.nav`s component with modifiers and utilities. Mix and match as needed, or build your own.

### Tabs

Takes the basic nav from above and adds the `.nav-tabs` class to generate a tabbed interface.

<CodeExample>
    <Nav variant="tabs">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Pills

Take that same HTML, but use `.nav-pills` instead for a more themed appearance.

<CodeExample>
    <Nav variant="pills">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Pill navigation can also go vertical with an additional modifier class, `.nav-pills-vertical`.

<CodeExample>
    <Nav variant="pills" vertical>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Underline

Take that same HTML, but use `.nav-underline` instead:

## Alignment

Change the alignment of your nav with [flexbox utilities][2]. By default, navs are horizontal and left-aligned, but you can easily modify them to center or right-aligned, and even stacked vertically.

### Horizontal

Centered with `.justify-content-center`:

<CodeExample>
    <Nav className="justify-content-center">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Right-aligned with `.justify-content-end`:

<CodeExample>
    <Nav className="justify-content-end">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Vertical

Stack your navigation by changing the flex item direction with the `.flex-column` utility. Need to stack them on some viewports but not others? Use the responsive versions (e.g., `.sm:flex-column`).

<CodeExample>
    <Nav vertical>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

As always, vertical navigation is possible without `<ul>`s, too.

<CodeExample>
    <Nav vertical>
        <NavLink active aria-current="page" href="#">

        <NavLink disabled aria-disabled="true">

### Fill and justify

Force your `.nav`’s contents to extend the full available width with one of two modifier classes. To proportionately fill all available space with your `.nav-item`s, use `.nav-fill`. Notice that all horizontal space is occupied, but not every nav item has the same width.

<CodeExample>
    <Nav variant="pills" fill>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

When using a `<nav>`-based navigation, you can safely omit `.nav-item` as only `.nav-link` is required for styling `<a>` elements.

<CodeExample>
    <Nav variant="pills" fill>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

For equal-width elements, use `.nav-justified`. All horizontal space will be occupied by nav links, but unlike the `.nav-fill` above, every nav item will be the same width.

<CodeExample>
    <Nav variant="pills" justified>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Similar to the `.nav-fill` example using a `<nav>`-based navigation.

<CodeExample>
    <Nav variant="pills" justified>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Working with flex utilities

If you need responsive nav variations, consider using a series of [flexbox utilities][2]. While more verbose, these utilities offer greater customization across responsive breakpoints. In the example below, our nav will be stacked on the lowest breakpoint, then adapt to a horizontal layout that fills the available width starting from the small breakpoint.

<CodeExample>
    <Nav variant="pills" className="flex-column sm:flex-row sm:d-flex">
        <NavLink
            active
            aria-current="page"
            href="#"
            className="sm:flex-fill sm:text-center"
        >
            {'Active'}
        </NavLink>

        <NavLink href="#" className="sm:flex-fill sm:text-center">
            {'Longer nav link'}
        </NavLink>

        <NavLink href="#" className="sm:flex-fill sm:text-center">
            {'Link'}
        </NavLink>

        <NavLink disabled aria-disabled="true" className="sm:flex-fill sm:text-center">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Regarding accessibility

If you’re using navs to provide a navigation bar, be sure to add a `role="navigation"` to the most logical parent container of the `<ul>`, or wrap a `<nav>` element around the whole navigation. Do not add the role to the `<ul>` itself, as this would prevent it from being announced as an actual list by assistive technologies.

Note that navigation bars, even if visually styled as tabs with the `.nav-tabs` class, should **not** be given `role="tablist"`, `role="tab"` or `role="tabpanel"` attributes. These are only appropriate for dynamic tabbed interfaces, as described in the [ARIA Authoring Practices Guide tabs pattern][3]. See the [Tab plugin][4] for dynamic tabbed interfaces. The `aria-current` attribute is not necessary on dynamic tabbed interfaces since our JavaScript handles the selected state by adding `aria-selected="true"` on the active tab.

## CSS

### Variables

Use CSS custom properties on the component to customize its appearance without recompiling Bootstrap.

On the `.nav` base class:

```css
.nav {
    --bs-nav-gap: 0.125rem;
    --bs-nav-link-gap: 0.5rem;
    --bs-nav-link-align: center;
    --bs-nav-link-justify: center;
    --bs-nav-link-padding-x: 0.75rem;
    --bs-nav-link-padding-y: 0.375rem;
    --bs-nav-link-color: var(--bs-fg-2);
    --bs-nav-link-hover-color: var(--bs-fg-1);
    --bs-nav-link-hover-bg: var(--bs-bg-1);
    --bs-nav-link-active-color: var(--bs-fg-body);
    --bs-nav-link-active-bg: var(--bs-bg-2);
    --bs-nav-link-disabled-color: var(--bs-fg-4);
    --bs-nav-link-border-width: var(--bs-border-width);
    --bs-nav-link-transition-property: 'color, background-color, border-color';
    --bs-nav-link-transition-duration: 0.15s;
    --bs-nav-link-transition-timing: ease-in-out;
}
```

On the `.nav-tabs` modifier class:

```css
.nav {
    --bs-nav-tabs-border-width: var(--bs-border-width);
    --bs-nav-tabs-border-color: var(--bs-border-color);
    --bs-nav-tabs-border-radius: var(--bs-radius-5);
    --bs-nav-tabs-link-hover-border-color: var(--bs-border-subtle);
    --bs-nav-tabs-link-active-color: var(--bs-fg-body);
    --bs-nav-tabs-link-active-bg: var(--bs-bg-body);
    --bs-nav-tabs-link-active-border-color: var(--bs-border-color) var(--bs-border-color)
        var(--bs-bg-body);
}
```

On the `.nav-pills` modifier class:

```css
.nav {
    --bs-nav-pills-bg: var(--bs-bg-1);
    --bs-nav-pills-padding: 0.25rem;
    --bs-nav-pills-border-radius: 3rem;
    --bs-nav-pills-link-active-color: var(--bs-primary-contrast);
    --bs-nav-pills-link-active-bg: var(--bs-primary-bg);
    --bs-nav-pills-link-border-radius: 3rem;
}
```

On the `.nav-underline` modifier class:

```css
.nav {
    --bs-nav-gap: 1rem;
    --bs-nav-link-active-bg: transparent;
    --bs-nav-underline-border-width: 0.125rem;
    --bs-nav-underline-link-active-color: var(--bs-fg-body);
}
```
