# Nav

Add lists of links to your pages with various navigation components—tabs, pills, underline—and plenty of options to customize.

## Base nav

`Nav` provides a semantic navigation container with `NavLink` children. Use the `active` and `disabled` props on links, and set `variant` to switch between visual styles.

The base `Nav` component uses flexbox and provides a foundation for navigation. It includes link padding for larger hit areas and disabled styling.

> To convey the active state to assistive technologies, use the `aria-current` attribute — using the `page` value for current page, or `true` for the current item in a set.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

`Nav` renders a semantic `<nav>` element with direct `NavLink` children. Its flex layout lets the links work without extra list markup.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

When a navigation item performs an action instead of navigating, set `as="button"` on `NavLink`. You can mix these with links, for example when adding a menu.

<CodeExample>
    <Nav>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <Menu nav label="Menu">
            <MenuItem href="#">{'Action'}</MenuItem>

            <MenuItem href="#">{'Another action'}</MenuItem>

            <MenuDivider />

            <MenuItem href="#">{'Something else here'}</MenuItem>
        </Menu>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Available styles

Set the `variant` prop on `Nav` to choose a style. Mix and match with layout utilities through `className` as needed.

### Tabs

Set `variant="tabs"` on `Nav` for a tabbed appearance.

<CodeExample>
    <Nav variant="tabs">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Pills

Set `variant="pills"` on `Nav` for a more themed appearance.

<CodeExample>
    <Nav variant="pills">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Set `vertical` on a pill `Nav` to stack the links vertically.

<CodeExample>
    <Nav variant="pills" vertical>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Underline

Set `variant="underline"` on `Nav` for an underline style:

<CodeExample>

## Alignment

Change the alignment of your nav with [flexbox utilities][2]. By default, navs are horizontal and left-aligned, but you can easily modify them to center or right-aligned, and even stacked vertically.

### Horizontal

Use a flexbox alignment utility through `Nav`'s `className` to center the links:

<CodeExample>
    <Nav className="justify-content-center">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Use a flexbox alignment utility through `Nav`'s `className` to align the links to the end:

<CodeExample>
    <Nav className="justify-content-end">
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Vertical

Set `vertical` on `Nav` to stack links. To change direction only at certain viewports, pass a responsive flexbox utility through `className`.

<CodeExample>
    <Nav vertical>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

`Nav` renders a `<nav>` with direct `NavLink` children; it does not require a list wrapper.

<CodeExample>
    <Nav vertical>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

### Fill and justify

Set `fill` on `Nav` to make its links occupy the full available width proportionally. Notice that all horizontal space is occupied, but not every link has the same width.

<CodeExample>
    <Nav variant="pills" fill>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

`NavLink` components can be direct children of `Nav`; no `NavItem` wrapper is required.

<CodeExample>
    <Nav variant="pills" fill>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Set `justified` on `Nav` to make its links equal width while filling the available space.

<CodeExample>
    <Nav variant="pills" justified>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

Use `Nav` with `fill` for proportional widths, or `justified` for equal widths.

<CodeExample>
    <Nav variant="pills" justified>
        <NavLink active aria-current="page" href="#">
            {'Active'}
        </NavLink>

        <NavLink href="#">{'Much longer nav link'}</NavLink>

        <NavLink href="#">{'Link'}</NavLink>

        <NavLink disabled aria-disabled="true">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Working with flex utilities

If you need responsive nav variations, consider using a series of [flexbox utilities][2]. While more verbose, these utilities offer greater customization across responsive breakpoints. In the example below, our nav will be stacked on the lowest breakpoint, then adapt to a horizontal layout that fills the available width starting from the small breakpoint.

<CodeExample>
    <Nav variant="pills" className="flex-column sm:flex-row sm:d-flex">
        <NavLink
            active
            aria-current="page"
            href="#"
            className="sm:flex-fill sm:text-center"
        >
            {'Active'}
        </NavLink>

        <NavLink href="#" className="sm:flex-fill sm:text-center">
            {'Longer nav link'}
        </NavLink>

        <NavLink href="#" className="sm:flex-fill sm:text-center">
            {'Link'}
        </NavLink>

        <NavLink disabled aria-disabled="true" className="sm:flex-fill sm:text-center">
            {'Disabled'}
        </NavLink>
    </Nav>

</CodeExample>

## Regarding accessibility

`Nav` renders a `<nav>` landmark by default. When rendering it as another element with `as`, provide an appropriate navigation landmark; do not assign the landmark role to a list.

`Nav` with `variant="tabs"` is still navigation and should **not** be given tab roles. Use [`Tabs`][3] for a dynamic tabbed interface, as described in the [ARIA Authoring Practices Guide tabs pattern][4]. [`Tabs`][3] manages the selected state and required ARIA attributes.

## CSS

### Variables

Use CSS custom properties on the component to customize its appearance without recompiling Bootstrap.

On the `.nav` base class:

```css
.nav {
    --bs-nav-gap: 0.125rem;
    --bs-nav-link-gap: 0.5rem;
    --bs-nav-link-align: center;
    --bs-nav-link-justify: center;
    --bs-nav-link-padding-x: 0.75rem;
    --bs-nav-link-padding-y: 0.375rem;
    --bs-nav-link-color: var(--bs-fg-2);
    --bs-nav-link-hover-color: var(--bs-fg-1);
    --bs-nav-link-hover-bg: var(--bs-bg-1);
    --bs-nav-link-active-color: var(--bs-fg-body);
    --bs-nav-link-active-bg: var(--bs-bg-2);
    --bs-nav-link-disabled-color: var(--bs-fg-4);
    --bs-nav-link-border-width: var(--bs-border-width);
    --bs-nav-link-transition-property: 'color, background-color, border-color';
    --bs-nav-link-transition-duration: 0.15s;
    --bs-nav-link-transition-timing: ease-in-out;
}
```

When `variant="tabs"` is set:

```css
.nav {
    --bs-nav-tabs-border-width: var(--bs-border-width);
    --bs-nav-tabs-border-color: var(--bs-border-color);
    --bs-nav-tabs-border-radius: var(--bs-radius-5);
    --bs-nav-tabs-link-hover-border-color: var(--bs-border-subtle);
    --bs-nav-tabs-link-active-color: var(--bs-fg-body);
    --bs-nav-tabs-link-active-bg: var(--bs-bg-body);
    --bs-nav-tabs-link-active-border-color: var(--bs-border-color) var(--bs-border-color)
        var(--bs-bg-body);
}
```

When `variant="pills"` is set:

```css
.nav {
    --bs-nav-pills-bg: var(--bs-bg-1);
    --bs-nav-pills-padding: 0.25rem;
    --bs-nav-pills-border-radius: 3rem;
    --bs-nav-pills-link-active-color: var(--bs-primary-contrast);
    --bs-nav-pills-link-active-bg: var(--bs-primary-bg);
    --bs-nav-pills-link-border-radius: 3rem;
}
```

When `variant="underline"` is set:

```css
.nav {
    --bs-nav-gap: 1rem;
    --bs-nav-link-active-bg: transparent;
    --bs-nav-underline-border-width: 0.125rem;
    --bs-nav-underline-link-active-color: var(--bs-fg-body);
}
```
