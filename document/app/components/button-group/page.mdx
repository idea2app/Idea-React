# Button group

Group a series of buttons together on a single line or stack them in a vertical column.

Use `ButtonGroup` with `vertical`, `divider`, and `size` props for the variations below, and
`ButtonToolbar` to combine groups. Both wrappers supply their default grouping role; provide an
accessible label for each group or toolbar.

## Examples

Wrap a series of buttons in `.btn-group`.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Basic example">
            <Button variant="solid" theme="primary" type="button">
                Left
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Middle
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Right
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

> Button groups require an appropriate `role` attribute and explicit label to ensure assistive technologies like screen readers identify buttons as grouped and announce them. Use `role="group"` for button groups or `role="toolbar"` for button toolbars. Then use `aria-label` or `aria-labelledby` to label them.

### With links

These classes can also be added to groups of links, as an alternative to the [`.nav` navigation components][1].

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup aria-label="Related links">
            <Button variant="solid" theme="primary" active href="#" aria-current="page">
                Active link
            </Button>
            <Button variant="solid" theme="primary" href="#">
                Link
            </Button>
            <Button variant="solid" theme="primary" href="#">
                Link
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

### Dividers

Add a divider between buttons by adding the `.btn-group-divider` class to the `.btn-group`. Most useful when used with buttons that have the same theme color and a solid fill.

<CodeExample>
    <div className="d-flex gap-2">
        <ButtonGroup divider role="group" aria-label="Basic example">
            <Button variant="solid" theme="primary" type="button">
                Left
            </Button>
            <Button variant="solid" theme="primary" active type="button">
                Active
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Right
            </Button>
        </ButtonGroup>
        <ButtonGroup divider role="group" aria-label="Basic example">
            <Button variant="solid" theme="secondary" type="button">
                Left
            </Button>
            <Button variant="solid" theme="secondary" type="button">
                Right
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

Works with vertical button groups, too.

<CodeExample>
    <div className="d-flex align-items-start gap-2">

            </Button>
            <Button variant="solid" theme="primary" active type="button">
                Active
            </Button>
            <Button variant="solid" theme="primary" type="button">
                Right
            </Button>
        </ButtonGroup>
        <ButtonGroup vertical divider role="group" aria-label="Basic example">
            <Button variant="solid" theme="secondary" type="button">
                Left
            </Button>
            <Button variant="solid" theme="secondary" type="button">
                Right
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

## Theme variants

Ue the `.theme-{color}` classes to apply a theme color to a set of buttons.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Accent theme example">
            <Button variant="solid" theme="accent" type="button">
                Left
            </Button>
            <Button variant="solid" theme="accent" type="button">
                Middle
            </Button>
            <Button variant="solid" theme="accent" type="button">
                Right
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

You can mix and match button variants in a button group.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Basic mixed styles example">
            <Button variant="solid" theme="danger" type="button">
                Left
            </Button>
            <Button variant="solid" theme="warning" type="button">
                Middle
            </Button>
            <Button variant="solid" theme="success" type="button">
                Right
            </Button>
        </ButtonGroup>
    </div>
</CodeExample>

## Toggle buttons

### Checkbox

Checkbox toggle buttons can be grouped together. Any or all of the buttons can be checked.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Basic checkbox toggle button group">
            <ToggleButton variant="outline" theme="primary" type="checkbox">
                Check 1
            </ToggleButton>
            <ToggleButton variant="outline" theme="primary" type="checkbox">
                Check 2
            </ToggleButton>
            <ToggleButton variant="outline" theme="primary" type="checkbox">
                Check 3
            </ToggleButton>
        </ButtonGroup>
    </div>
</CodeExample>

### Radio

By design, radio toggle button groups can only have one button checked at a time.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Basic radio toggle button group">
            <ToggleButton
                variant="outline"
                theme="primary"
                type="radio"
                name="btnradio"
                defaultChecked
            >
                Radio 1
            </ToggleButton>
            <ToggleButton variant="outline" theme="primary" type="radio" name="btnradio">
                Radio 2
            </ToggleButton>
            <ToggleButton variant="outline" theme="primary" type="radio" name="btnradio">
                Radio 3
            </ToggleButton>
        </ButtonGroup>
    </div>
</CodeExample>

## Button toolbar

Combine sets of button groups into button toolbars for more complex components. Use utility classes as needed to space out groups, buttons, and more.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonToolbar role="toolbar" aria-label="Toolbar with button groups">
            <ButtonGroup role="group" aria-label="First group">
                <Button variant="solid" theme="primary" type="button">
                    1
                </Button>
                <Button variant="solid" theme="primary" type="button">
                    2
                </Button>
                <Button variant="solid" theme="primary" type="button">
                    3
                </Button>
                <Button variant="solid" theme="primary" type="button">
                    4
                </Button>
            </ButtonGroup>
            <ButtonGroup role="group" aria-label="Second group">
                <Button variant="solid" theme="secondary" type="button">
                    5
                </Button>
                <Button variant="solid" theme="secondary" type="button">
                    6
                </Button>
                <Button variant="solid" theme="secondary" type="button">

                <Button variant="solid" theme="info" type="button">

## Nesting

Place a `.btn-group` within another `.btn-group` when you want menus mixed with a series of buttons.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <ButtonGroup role="group" aria-label="Button group with nested menu">
            <Button variant="solid" theme="primary" type="button">
                1
            </Button>
            <Button variant="solid" theme="primary" type="button">
                2
            </Button>
            <Menu label="Menu" toggleProps={{ variant: 'solid', theme: 'primary' }}>
                <MenuItem variant={false} href="#">
                    Menu link
                </MenuItem>
                <MenuItem variant={false} href="#">
                    Menu link
                </MenuItem>
            </Menu>
        </ButtonGroup>
    </div>
</CodeExample>
