# Scrollspy

Automatically update Bootstrap navigation or list group components based on scroll position to indicate which link is currently active in the viewport.

## How it works

Scrollspy toggles the `.active` class on anchor (`<a>`) elements when the element with the `id` referenced by the anchor’s `href` is scrolled into view. Scrollspy is best used in conjunction with a Bootstrap [nav component][1] or [list group][2], but it will also work with any anchor elements in the current page. Here’s how it works.

- To start, scrollspy requires two things: a navigation, list group, or a simple set of links, plus a scrollable container. The scrollable container can be the `<body>` or a custom element with a set `height` and `overflow-y: scroll`.

- Use `ScrollSpy` as the scrollable container and set `target="#navId"`, where `navId` is the unique `id` of the associated navigation. The component supplies a focusable `tabIndex={0}` for keyboard access.

- As you scroll the “spied” container, an `.active` class is added and removed from anchor links within the associated navigation. Links must have resolvable `id` targets, otherwise they’re ignored. For example, a `<a href="#home">home</a>` must correspond to something in the DOM like `<div id="home"></div>`

- Target elements that are not visible will be ignored. See the [Non-visible elements][3] section below.

- Target `id`s are matched with `getElementById`, so ids containing special or percent-encoded characters (for example `#item.1`, `#section:overview`, or `#%2Fpath`) resolve correctly.

### Detection

Scrollspy uses an [`IntersectionObserver`][4] to track sections without `scroll-position` polling. Detection is deterministic and driven entirely by an activation line near the top of the scroll container.

- The active section is the deepest one whose top has scrolled past the activation line, like the section you’re currently reading.
- While scrolling through the gap between two headings, the last activated section stays active until the next one crosses the line.
- At the very top of the container, before any section crosses the line, the first section stays active.
- At the very bottom of the container, the last section is activated even if its top never reaches the line (handy for short final sections).

Set where the activation line sits with `topMargin` (a more user-friendly `%` or `px` value from the top of the scroll root, such as `96px` to sit below a stickied navbar), or take full control with the raw IntersectionObserver `rootMargin` string. See [Options][5].

Jump to the [debug overlay][6] section to visualize the activation line in action.

## Debug overlay

It can be hard to picture exactly where Scrollspy decides a section is active. Enable the `debug` prop to draw red guides over the scroll container and illustrate the behavior.

- **The red dashed line near the top is the activation line.** A section becomes active as its heading scrolls above this line. In this example it sits at `96px`.
- **The red bottom zone lights up when you reach the bottom of the container.** This is where the last section stays active even if its heading never reaches the activation line.

Scroll the example and watch the highlighted navigation item change as headings cross the line. Guide positions are computed from the same `topMargin`/`rootMargin` [detection][7] math the component uses.

<CodeExample>
    <Nav id="debug-scrollspy-nav" variant="pills">
        <NavLink href="#debug-scrollspy-first">First</NavLink>
        <NavLink href="#debug-scrollspy-last">Last</NavLink>
    </Nav>
    <ScrollSpy
        target="#debug-scrollspy-nav"
        debug
        topMargin="96px"
        className="overflow-y-auto border rounded p-3"
        style={{ height: 240 }}
    >
        <section id="debug-scrollspy-first" className="py-5">
            <h4>First section</h4>
            <p>Watch the activation line while scrolling this container.</p>
        </section>
        <section id="debug-scrollspy-last" className="py-5">
            <h4>Last section</h4>
            <p>The bottom zone selects the final section.</p>
        </section>
    </ScrollSpy>
</CodeExample>

## Non-visible elements

Target elements that aren’t visible will be ignored and their corresponding nav items won’t receive an `.active` class. Scrollspy instances initialized in a non-visible wrapper will ignore all target elements. Use the `refresh` method to check for observable elements once the wrapper becomes visible.

Call the component’s `refresh()` method after revealing content outside React; changes to its props are observed automatically.

## Usage

The component initializes on mount and releases its observers and listeners on unmount. Set `scrollRoot="window"` to observe page scrolling instead of the component's own scrollable element.

### Options

Pass options as React props:

| Name           | Type                   | Default  | Description                                                                                                            |
| -------------- | ---------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `rootMargin`   | string or null         | `null`   | Advanced IntersectionObserver root margin. When set, it takes precedence over `topMargin`, for example `0px 0px -40%`. |
| `smoothScroll` | boolean                | `false`  | Smoothly scroll to a clicked target, then update the URL hash and move focus to it.                                    |
| `target`       | string                 | —        | Selector for the navigation whose links match the observed sections.                                                   |
| `threshold`    | number[]               | `[0]`    | IntersectionObserver thresholds.                                                                                       |
| `topMargin`    | string                 | `'12%'`  | Position of the activation line from the top of the scroll root. Accepts percentages or pixels.                        |
| `scrollRoot`   | `'self'` or `'window'` | `'self'` | Element or viewport scrolling.                                                                                         |
| `debug`        | boolean                | `false`  | Draw the activation line and bottom-zone guides.                                                                       |

### Methods

Use the instance method `refresh()` after adding, removing, or revealing observed DOM content outside React. Children and relevant prop changes refresh the component automatically.

### Events

Use `onActiveChange(id)` to respond when a different section becomes active.
