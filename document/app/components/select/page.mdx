# Select

[`Select`][1] is an accessible value selector built on the [Menu](../menu/) component: a button
toggles a keyboard-navigable menu of `Option` items.

## Example

<Select value="react" aria-label="Framework">
    <Option value="react">React</Option>
    <Option value="vue">Vue</Option>
    <Option value="svelte">Svelte</Option>
</Select>

## Usage

`Select` is controlled: pass the current `value` and update it in `onChange`.

```tsx
<Select value={framework} onChange={setFramework}>
    <Option value="react">React</Option>
    <Option value="vue">Vue</Option>
</Select>
```

The toggle shows the selected option's content, or render a custom label with `valueRender`. Button
styling props such as `theme`, `variant`, `size`, and `disabled` pass through to the toggle, and
`align` positions the menu.
