# Form field

The `FormField` wrapper arranges a label, control, optional description, and validation message.
Associate labels with controls through `htmlFor` and `id`, and descriptions with `aria-describedby`.

## How it works

Use `FormField` for a single control. Use `FormGroup` to group related fields and `FormFieldContent`
when a control needs an adjacent label or description. The wrappers preserve native control behavior.

## Examples

### Select

<FormField>
    <FormLabel htmlFor="fieldCountry">Country</FormLabel>
    <FormSelect id="fieldCountry" name="country" defaultValue="">
        <option value="" disabled>
            Choose one…
        </option>
        <option value="ca">Canada</option>
        <option value="jp">Japan</option>
    </FormSelect>
</FormField>

### Textarea

<FormField>
    <FormLabel htmlFor="fieldMessage">Message</FormLabel>
    <FormTextArea id="fieldMessage" rows={3} />
</FormField>

### Checkbox

<FormField>
    <FormCheck id="fieldTerms" name="terms" />
    <FormLabel htmlFor="fieldTerms">Accept the terms</FormLabel>
</FormField>

### Radio

<FormFieldset>
    <legend>Choose a plan</legend>
    <FormField>
        <FormCheck id="fieldBasicPlan" type="radio" name="plan" value="basic" defaultChecked />
        <FormLabel htmlFor="fieldBasicPlan">Basic</FormLabel>
    </FormField>
    <FormField>
        <FormCheck id="fieldProPlan" type="radio" name="plan" value="pro" />
        <FormLabel htmlFor="fieldProPlan">Pro</FormLabel>
    </FormField>
</FormFieldset>

### Grouped

<FormGroup>
    <FormField>
        <FormLabel htmlFor="fieldFirst">First name</FormLabel>
        <FormControl id="fieldFirst" name="firstName" />
    </FormField>
    <FormField>
        <FormLabel htmlFor="fieldLast">Last name</FormLabel>
        <FormControl id="fieldLast" name="lastName" />
    </FormField>
</FormGroup>

### Group cards

Use the Bootstrap card and grid utilities around field components when options need a larger
clickable visual target.

<FormGroup>
    <Row className="g-3">
        <Col md={6}>
            <FormField className="border rounded p-3">
                <FormCheck id="fieldCardOne" type="radio" name="card" value="one" />
                <FormLabel htmlFor="fieldCardOne">Option one</FormLabel>
            </FormField>
        </Col>
        <Col md={6}>
            <FormField className="border rounded p-3">
                <FormCheck id="fieldCardTwo" type="radio" name="card" value="two" />
                <FormLabel htmlFor="fieldCardTwo">Option two</FormLabel>
            </FormField>
        </Col>
    </Row>
</FormGroup>

### Switch

### Combobox

Use the menu-backed `Combobox` component for searchable or custom option interfaces.

<Combobox name="fieldLanguage" value="ts" placeholder="Choose a language">
    <ComboboxOption value="js">JavaScript</ComboboxOption>
    <ComboboxOption value="ts">TypeScript</ComboboxOption>
</Combobox>

### Description

<FormField>
    <FormLabel htmlFor="fieldEmail">Email</FormLabel>
    <FormControl id="fieldEmail" type="email" aria-describedby="fieldEmailHelp fieldEmailError" />
    <FormText id="fieldEmailHelp">Use your work email address.</FormText>
    <FormFeedback id="fieldEmailError">Enter a valid email address.</FormFeedback>
</FormField>

### Validation

Validation can be client-side using native constraints or server-side using the returned state.

## Overhead label

Use `FormFieldContent` to pair a control and an overhead label when a design calls for a different
label placement.

<FormField>
    <FormFieldContent>
        <FormLabel htmlFor="fieldOverhead">Name</FormLabel>
        <FormControl id="fieldOverhead" />
    </FormFieldContent>
</FormField>

## Descriptions

Use `FormText` for help text and reference it from the related input with `aria-describedby`.

## Validation

### Client-side

Native HTML constraints such as `required`, `type`, `min`, and `max` are preserved.

### Server-side

Apply `.is-invalid` and render `FormFeedback` for server-returned errors.

## CSS

The field wrappers use Bootstrap styles from the loaded stylesheet.
