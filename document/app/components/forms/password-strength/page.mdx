# Password strength

`PasswordStrength` evaluates the controlled `value` prop using Bootstrap's eight default criteria.
The score is available as an accessible meter and as either segmented or bar presentation.

## Examples

### Segmented

<PasswordStrength value="Password123!@#$567" />

### With text feedback

Customize the displayed label with `messages`.

<PasswordStrength value="password" messages={{ weak: 'Add more variety' }} />

### Progress bar

<PasswordStrength value="Password123!@#$567" variant="bar" />

### Static segmented

The Idea React wrapper computes its meter from the controlled `value`; it does not expose a static
strength override.

### Static progress bar

The bar variant uses the same controlled score and does not expose a static strength override.

## Strength criteria

The default score checks minimum length, additional length, lowercase, uppercase, digits, symbols,
multiple symbols, and a longer total length. `minLength` changes the base length threshold.

## Usage

Connect the password input and strength meter to the same state. Describe password requirements
separately so the meter is not the only source of instructions.

<FormField>
    <FormLabel htmlFor="strengthPassword">Password</FormLabel>
    <FormControl id="strengthPassword" type="password" aria-describedby="strengthHelp" />
    <FormText id="strengthHelp">Use at least eight characters.</FormText>
    <PasswordStrength value="Password123!@#$567" />
</FormField>

### Via data attributes

The wrapper renders `data-bs-strength` from the computed score.

### Via JavaScript

The React wrapper computes its own strength score and does not create a Bootstrap JavaScript
instance.

### Dependencies

The meter only requires the Bootstrap stylesheet.

### Options

The wrapper supports `minLength`, custom level `messages`, and the `segments` or `bar` variant.

#### Default weights

`getPasswordStrength` applies the fixed default criteria. Custom scoring weights are not currently
exposed by this wrapper.

#### Custom weights

Custom scoring weights are not currently exposed by this wrapper.

#### Custom scorer

For custom scoring, calculate the score in the consuming application and adapt it to the desired UI.

### Methods

The component exposes no imperative plugin methods.

### Events

The component is controlled through its `value` prop and exposes no plugin events.

## CSS-only usage

Without a JavaScript plugin, the controlled React component still renders its meter markup.

## Accessibility

The meter exposes its level using `role="meter"` and ARIA value properties. Describe password
requirements separately.

## CSS

The loaded Bootstrap stylesheet provides the segmented and bar meter appearance.
