# List group

List groups are a flexible and powerful component for displaying a series of content. Modify and extend them to support just about any content within.

## Basic example

The most basic list group is an unordered list with list items and the proper classes. Build upon it with the options that follow, or with your own CSS as needed.

<CodeExample>
    <ListGroup>
        <ListGroupItem>{'An item'}</ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Active items

Add `.active` to a `.list-group-item` to indicate the current active selection.

<CodeExample>
    <ListGroup>
        <ListGroupItem active aria-current="true">
            {'An active item'}
        </ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Links and buttons

Use `<a>`s or `<button>`s to create _actionable_ list group items with hover, disabled, and active states by adding `.list-group-item-action`. We separate these pseudo-classes to ensure list groups made of non-interactive elements (like `<li>`s or `<div>`s) don’t provide a click or tap affordance.

Make `.list-group-item-action` instances _appear_ disabled by adding `.disabled`, and `aria-disabled="true"` to inform assistive technologies that the element is disabled. You may require additional JavaScript to fully disable links and buttons.

Be sure to **not use the standard `.btn` classes here**.

<CodeExample>
    <ListGroup as="div">
        <ListGroupItem action active href="#" aria-current="true">
            {' The current link item '}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A second link item'}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A third link item'}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A fourth link item'}
        </ListGroupItem>

        <ListGroupItem action disabled href="#" aria-disabled="true">
            {'A disabled link item'}
        </ListGroupItem>
    </ListGroup>

</CodeExample>

With `<button>`s, you can also make use of the `disabled` attribute instead of the `.disabled` class. Sadly, `<a>`s don’t support the disabled attribute.

<CodeExample>
    <ListGroup as="div">
        <ListGroupItem type="button" action active aria-current="true">
            {' The current button '}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A second button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A third button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A fourth button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action disabled>
            {'A disabled button item'}
        </ListGroupItem>
    </ListGroup>

</CodeExample>

## Flush

Add `.list-group-flush` to remove some borders and rounded corners to render list group items edge-to-edge in a parent container (e.g., cards).

<CodeExample>
    <ListGroup flush>
        <ListGroupItem>{'An item'}</ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Numbered

Add the `.list-group-numbered` modifier class (and optionally use an `<ol>` element) to opt into numbered list group items. Numbers are generated via CSS (as opposed to a `<ol>`s default browser styling) for better placement inside list group items and to allow for better customization.

Numbers are generated by `counter-reset` on the `<ol>`, and then styled and placed with a `::before` pseudo-element on the `<li>` with `counter-increment` and `content`.

<CodeExample>
    <ListGroup as="ol" numbered>
        <ListGroupItem>{'A list item'}</ListGroupItem>

        <ListGroupItem>{'A list item'}</ListGroupItem>

        <ListGroupItem>{'A list item'}</ListGroupItem>
    </ListGroup>

</CodeExample>

These work great with custom content as well.

<CodeExample>
    <ListGroup as="ol" numbered>
        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>

        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>

        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

## Horizontal

Add `.list-group-horizontal` to change the layout of list group items from vertical to horizontal across all container sizes. Alternatively, choose a responsive variant `.{sm|md|lg|xl|2xl}:list-group-horizontal` to make a list group horizontal starting at that breakpoint’s width.

The responsive variants use [container queries][1], so wrap the list group in a query container—add the `.contains-inline` utility to a parent element—for them to take effect. Currently **horizontal list groups cannot be combined with flush list groups.**

**ProTip:** Want equal-width list group items when horizontal? Add `.flex-fill` to each list group item.

<CodeExample>
    <Stack gap={3}>
        <div className="contains-inline">
            <ListGroup horizontal>
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="sm">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="md">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="lg">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="xl">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="2xl">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>
    </Stack>

</CodeExample>

Drag the handle to resize the container below and watch the list group switch between vertical and horizontal layouts as the container—not the viewport—crosses the `md` breakpoint.

<CodeExample>
    <div className="contains-inline">
        <ListGroup horizontal="md">
            <ListGroupItem>{'An item'}</ListGroupItem>

            <ListGroupItem>{'A second item'}</ListGroupItem>

            <ListGroupItem>{'A third item'}</ListGroupItem>
        </ListGroup>
    </div>

</CodeExample>

## Checkboxes and radios

Place Bootstrap’s checkboxes and radios within list group items and customize as needed. You can use them without `<label>`s, but please remember to include an `aria-label` attribute and value for accessibility.

<CodeExample>
    <ListGroup>
        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="firstCheckbox" />

                <label htmlFor="firstCheckbox">{'First checkbox'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="secondCheckbox" />

                <label htmlFor="secondCheckbox">{'Second checkbox'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="thirdCheckbox" />

                <label htmlFor="thirdCheckbox">{'Third checkbox'}</label>
            </FormField>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

<CodeExample>
    <ListGroup>
        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="firstRadio" defaultChecked />

                <label htmlFor="firstRadio">{'First radio'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="secondRadio" />

                <label htmlFor="secondRadio">{'Second radio'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="thirdRadio" />

                <label htmlFor="thirdRadio">{'Third radio'}</label>
            </FormField>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

You can use `.stretched-link` on `<label>`s to make the whole list group item clickable.

<CodeExample>
    <ListGroup>
        <ListGroupItem>

                <label htmlFor="firstCheckboxStretched" className="stretched-link">
                    {'First checkbox'}
                </label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="secondCheckboxStretched" />

                <label htmlFor="secondCheckboxStretched" className="stretched-link">
                    {'Second checkbox'}
                </label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="thirdCheckboxStretched" />

### Variables

Use CSS custom properties on the component to customize its appearance without recompiling Bootstrap.

```css
.list-group {
    --bs-list-group-color: var(--bs-fg-body);
    --bs-list-group-bg: var(--bs-bg-body);
    --bs-list-group-border-color: var(--bs-border-color);
    --bs-list-group-border-width: var(--bs-border-width);
    --bs-list-group-border-radius: var(--bs-radius-5);
    --bs-list-group-item-padding-x: var(--bs-spacer);
    --bs-list-group-item-padding-y: var(--bs-spacer-2);
    --bs-list-group-action-color: var(--bs-fg-2);
    --bs-list-group-action-hover-color: var(--bs-fg-1);
    --bs-list-group-action-hover-bg: var(--bs-bg-1);
    --bs-list-group-action-active-color: var(--bs-fg-body);
    --bs-list-group-action-active-bg: var(--bs-bg-2);
    --bs-list-group-disabled-color: var(--bs-fg-3);
    --bs-list-group-disabled-bg: var(--bs-bg-body);
    --bs-list-group-active-color: var(--bs-primary-contrast);
    --bs-list-group-active-bg: var(--bs-primary-bg);
    --bs-list-group-active-border-color: var(--bs-primary-bg);
}
```
