# List group

List groups are a flexible and powerful component for displaying a series of content. Modify and extend them to support just about any content within.

## Basic example

The most basic list group combines `ListGroup` with `ListGroupItem` children. Build upon it with the props that follow, or with your own CSS as needed.

<CodeExample>
    <ListGroup>
        <ListGroupItem>{'An item'}</ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Active items

Set `active` on `ListGroupItem` to indicate the current selection.

<CodeExample>
    <ListGroup>
        <ListGroupItem active aria-current="true">
            {'An active item'}
        </ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Links and buttons

Set `action` on `ListGroupItem` to create an interactive item with hover, disabled, and active states. Non-interactive items do not display a click or tap affordance.

Set `disabled` on `ListGroupItem` to disable interaction and communicate the disabled state to assistive technologies.

Do not use `Button` styles for list group items.

<CodeExample>
    <ListGroup as="div">
        <ListGroupItem action active href="#" aria-current="true">
            {' The current link item '}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A second link item'}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A third link item'}
        </ListGroupItem>

        <ListGroupItem action href="#">
            {'A fourth link item'}
        </ListGroupItem>

        <ListGroupItem action disabled href="#" aria-disabled="true">
            {'A disabled link item'}
        </ListGroupItem>
    </ListGroup>

</CodeExample>

For button items, `ListGroupItem` passes `disabled` to the native button. Link items do not support the native disabled attribute, so the wrapper disables navigation and keyboard focus.

<CodeExample>
    <ListGroup as="div">
        <ListGroupItem type="button" action active aria-current="true">
            {' The current button '}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A second button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A third button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action>
            {'A fourth button item'}
        </ListGroupItem>

        <ListGroupItem type="button" action disabled>
            {'A disabled button item'}
        </ListGroupItem>
    </ListGroup>

</CodeExample>

## Flush

Set `flush` on `ListGroup` to remove some borders and rounded corners so its items sit edge-to-edge in a parent container such as a card.

<CodeExample>
    <ListGroup flush>
        <ListGroupItem>{'An item'}</ListGroupItem>

        <ListGroupItem>{'A second item'}</ListGroupItem>

        <ListGroupItem>{'A third item'}</ListGroupItem>

        <ListGroupItem>{'A fourth item'}</ListGroupItem>

        <ListGroupItem>{'And a fifth one'}</ListGroupItem>
    </ListGroup>

</CodeExample>

## Numbered

Set `numbered` on `ListGroup` to number its items; use `as="ol"` when an ordered-list element is also appropriate. Numbers are generated with CSS for better placement and customization.

The `numbered` prop uses CSS counters to generate and place the item numbers.

<CodeExample>
    <ListGroup as="ol" numbered>
        <ListGroupItem>{'A list item'}</ListGroupItem>

        <ListGroupItem>{'A list item'}</ListGroupItem>

        <ListGroupItem>{'A list item'}</ListGroupItem>
    </ListGroup>

</CodeExample>

These work great with custom content as well.

<CodeExample>
    <ListGroup as="ol" numbered>
        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>

        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>

        <ListGroupItem className="d-flex justify-content-between align-items-start">
            <div className="ms-2 me-auto">
                <div className="fw-bold">{'Subheading'}</div>
                {' Content for list item '}
            </div>

            <Badge theme="primary">{'14'}</Badge>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

## Horizontal

Set `horizontal` on `ListGroup` to display items in a row at all sizes, or set it to a breakpoint such as `sm` or `md` to switch to a row at that breakpoint.

The responsive variants use [container queries][1], so place the list group in a query container with the `contains-inline` utility applied through the parent's `className`. Currently **horizontal list groups cannot be combined with flush list groups.**

**ProTip:** For equal-width horizontal items, apply the `flex-fill` utility through each `ListGroupItem`'s `className`.

<CodeExample>
    <Stack gap={3}>
        <div className="contains-inline">
            <ListGroup horizontal>
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="sm">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="md">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="lg">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="xl">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>

        <div className="contains-inline">
            <ListGroup horizontal="2xl">
                <ListGroupItem>{'An item'}</ListGroupItem>

                <ListGroupItem>{'A second item'}</ListGroupItem>

                <ListGroupItem>{'A third item'}</ListGroupItem>
            </ListGroup>
        </div>
    </Stack>

</CodeExample>

Drag the handle to resize the container below and watch the list group switch between vertical and horizontal layouts as the container—not the viewport—crosses the `md` breakpoint.

<CodeExample>
    <div className="contains-inline">
        <ListGroup horizontal="md">
            <ListGroupItem>{'An item'}</ListGroupItem>

            <ListGroupItem>{'A second item'}</ListGroupItem>

            <ListGroupItem>{'A third item'}</ListGroupItem>
        </ListGroup>
    </div>

</CodeExample>

<CodeExample>

## Checkboxes and radios

Place `Checkbox` and `Radio` components inside list group items and customize them as needed. If there is no visible label, provide an `aria-label`.

<CodeExample>
    <ListGroup>
        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="firstCheckbox" />

                <label htmlFor="firstCheckbox">{'First checkbox'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="secondCheckbox" />

                <label htmlFor="secondCheckbox">{'Second checkbox'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="thirdCheckbox" />

                <label htmlFor="thirdCheckbox">{'Third checkbox'}</label>
            </FormField>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

<CodeExample>
    <ListGroup>
        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="firstRadio" defaultChecked />

                <label htmlFor="firstRadio">{'First radio'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="secondRadio" />

                <label htmlFor="secondRadio">{'Second radio'}</label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Radio name="listGroupRadio" value="" id="thirdRadio" />

                <label htmlFor="thirdRadio">{'Third radio'}</label>
            </FormField>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

Apply the `stretched-link` utility through the item's `className` when the entire item should be clickable.

<CodeExample>
    <ListGroup>
        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="firstCheckboxStretched" />

                <label htmlFor="firstCheckboxStretched" className="stretched-link">
                    {'First checkbox'}
                </label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="secondCheckboxStretched" />

                <label htmlFor="secondCheckboxStretched" className="stretched-link">
                    {'Second checkbox'}
                </label>
            </FormField>
        </ListGroupItem>

        <ListGroupItem>
            <FormField>
                <Checkbox value="" id="thirdCheckboxStretched" />

                <label htmlFor="thirdCheckboxStretched" className="stretched-link">
                    {'Third checkbox'}
                </label>
            </FormField>
        </ListGroupItem>
    </ListGroup>

</CodeExample>

Use the `checkable` and `radio` props for the corresponding list group variants. Add `listGroup` to `FormCheck` to apply the input styling used by checkable groups.

<CodeExample>
    <Stack gap={3}>
        <ListGroup as="div" checkable>
            <FormCheck listGroup type="radio" name="checkableList" id="checkableListOne" />
            <ListGroupItem as="label" htmlFor="checkableListOne">
                {'First option'}
            </ListGroupItem>
        </ListGroup>

        <ListGroup as="div" radio>
            <FormCheck type="radio" name="radioList" id="radioListOne" />
            <ListGroupItem as="label" htmlFor="radioListOne">
                {'First option'}
            </ListGroupItem>
        </ListGroup>
    </Stack>

</CodeExample>

}
