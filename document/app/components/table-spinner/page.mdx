# Table spinner

[`TableSpinner`][1] renders a loading row for a data table: one centered [Spinner](../spinner/) in a
cell spanning the given number of columns.

## Example

<table className="table">
    <thead>
        <tr>
            <th>Name</th>
            <th>Role</th>
            <th>Score</th>
        </tr>
    </thead>
    <tbody>
        <TableSpinner colSpan={3} />
    </tbody>
</table>

## Usage

```tsx
<tbody>{loading ? <TableSpinner colSpan={columns.length} /> : rows}</tbody>
```

`colSpan` must match the table's column count; `animation`, `theme`, and `size` style the spinner.
