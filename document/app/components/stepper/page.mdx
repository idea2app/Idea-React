# Stepper

Create timelines, wizards, or step-by-step progress bars. Ideal for shopping carts, sign-up forms, and more.

Use `Stepper` and `StepperItem` for ordered steps, `StepperNav` and `StepperLink` for navigation, and
`StepperOverflow` for scrollable horizontal steps. The `horizontal` prop accepts `true` or a
breakpoint such as `"sm"`; items accept `active` and `theme`.

## Examples

Stepper is built with CSS Grid and `<ol>` elements. By default, steps are displayed vertically. You can transform them into horizontal lists with responsive modifier classes.

### Basic

Here’s a simple example of a vertical stepper.

<DocumentCodeExample>
    <div className="d-block overflow-auto">
        <Stepper>
            <StepperItem active>Create account</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</DocumentCodeExample>

### Responsive

Steppers can be made horizontal at specific breakpoints using the `contains-inline` utility on a parent element and by adding the responsive `.stepper-horizontal-{breakpoint}` modifier classes on the stepper. The extra parent element is required when using container queries.

<DocumentCodeExample>
    <div className="d-block overflow-auto p-2" style={{ resize: 'horizontal', maxWidth: '100%' }}>
        <div className="contains-inline">
            <Stepper horizontal="sm">
                <StepperItem active>Create account</StepperItem>
                <StepperItem active>Confirm email</StepperItem>
                <StepperItem>Update profile</StepperItem>
                <StepperItem>Finish</StepperItem>
            </Stepper>
        </div>
    </div>
</DocumentCodeExample>

### Gap

Customize the gap with styles that override the `--bs-stepper-gap` CSS variable.

<DocumentCodeExample>
    <div className="d-block overflow-auto">
        <Stepper style={Object.fromEntries([['--bs-stepper-gap', '3rem']])}>

            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</DocumentCodeExample>

## Overflow

Wrap your horizontal stepper in a `.stepper-overflow` container to enable horizontal scrolling when the stepper overflows its parent. Uses `container-type: inline-size` for container query support as opposed to a viewport-based media query.

<DocumentCodeExample>
    <div className="d-block overflow-auto">
        <StepperOverflow>
            <Stepper horizontal>
                <StepperItem active>Create account</StepperItem>
                <StepperItem active>Verify email address</StepperItem>
                <StepperItem>Complete profile setup</StepperItem>
                <StepperItem>Add payment method</StepperItem>
                <StepperItem>Review and confirm</StepperItem>
                <StepperItem>Finish onboarding</StepperItem>
            </Stepper>
        </StepperOverflow>
    </div>
</DocumentCodeExample>

## Alignment

Use [text alignment utilities][1] (because we use `display: inline-grid`) to align the steps. The inline grid arrangement allows us to keep the steps equal width and ensures the connecting lines are rendered correctly.

<DocumentCodeExample>
    <div className="d-block overflow-auto">
        <Stepper horizontal>
            <StepperItem active>Default stepper</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</DocumentCodeExample>

<DocumentCodeExample>
    <div className="text-center overflow-auto">
        <Stepper horizontal>

            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</DocumentCodeExample>

<DocumentCodeExample>
    <div className="text-end overflow-auto">
        <Stepper horizontal>

Apply `.w-100` to the stepper to make it full width. Stepper items will be stretched to fill the available space. Alignment doesn’t affect full-width steppers.

<DocumentCodeExample>

## With anchors

Use anchor elements to build your stepper if it links across multiple pages. Add `role="button"` or use `<button>` elements if you’re linking across sections in the same document.

Consider using our [link utilities][2] for quick color control.

    <div className="d-block overflow-auto">

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

| CSS variable                | Default                      |
| --------------------------- | ---------------------------- |
| `--bs-stepper-size`         | `2rem`                       |
| `--bs-stepper-gap`          | `1rem`                       |
| `--bs-stepper-font-size`    | `var(--bs-font-size-sm)`     |
| `--bs-stepper-text-gap`     | `0.5rem`                     |
| `--bs-stepper-track-size`   | `0.125rem`                   |
| `--bs-stepper-bg`           | `var(--bs-bg-2)`             |
| `--bs-stepper-active-color` | `var(--bs-primary-contrast)` |
| `--bs-stepper-active-bg`    | `var(--bs-primary-bg)`       |

### Overflow wrapper

The `StepperOverflow` wrapper establishes an inline-size query container with horizontal scrolling. The horizontal stepper retains its minimum content width, keeping labels readable when the available space is narrow.
