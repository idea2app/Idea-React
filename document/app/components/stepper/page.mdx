# Stepper

Create timelines, wizards, or step-by-step progress bars. Ideal for shopping carts, sign-up forms, and more.

Use `Stepper` and `StepperItem` for ordered steps, `StepperNav` and `StepperLink` for navigation, and
`StepperOverflow` for scrollable horizontal steps. The `horizontal` prop accepts `true` or a
breakpoint such as `"sm"`; items accept `active` and `theme`.

## Examples

`Stepper` renders an ordered list and uses CSS Grid for layout. Steps are vertical by default; set its `horizontal` prop to a breakpoint to switch to a horizontal layout responsively.

### Basic

Here’s a simple example of a vertical stepper.

<CodeExample>
    <div className="d-block overflow-auto">
        <Stepper>
            <StepperItem active>Create account</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

### Responsive

For container-query-based horizontal layouts, place `Stepper` inside a parent with the `contains-inline` utility applied through `className`, then set the `horizontal` prop to the desired breakpoint.

<CodeExample>
    <div className="d-block overflow-auto p-2" style={{ resize: 'horizontal', maxWidth: '100%' }}>
        <div className="contains-inline">
            <Stepper horizontal="sm">
                <StepperItem active>Create account</StepperItem>
                <StepperItem active>Confirm email</StepperItem>
                <StepperItem>Update profile</StepperItem>
                <StepperItem>Finish</StepperItem>
            </Stepper>
        </div>
    </div>
</CodeExample>

### Gap

Customize the gap with styles that override the `--bs-stepper-gap` CSS variable.

<CodeExample>
    <div className="d-block overflow-auto">
        <Stepper style={Object.fromEntries([['--bs-stepper-gap', '3rem']])}>

            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

## Overflow

Wrap a horizontal stepper in `StepperOverflow` to enable horizontal scrolling when it exceeds its parent. It uses `container-type: inline-size` to support container queries.

<CodeExample>
    <div className="d-block overflow-auto">
        <StepperOverflow>
            <Stepper horizontal>
                <StepperItem active>Create account</StepperItem>
                <StepperItem active>Verify email address</StepperItem>
                <StepperItem>Complete profile setup</StepperItem>
                <StepperItem>Add payment method</StepperItem>
                <StepperItem>Review and confirm</StepperItem>
                <StepperItem>Finish onboarding</StepperItem>
            </Stepper>
        </StepperOverflow>
    </div>
</CodeExample>

## Alignment

Use [text alignment utilities][1] on the wrapper around `Stepper` (which uses `display: inline-grid`)
to align the steps. The inline grid arrangement keeps steps equal width and ensures connecting lines
are rendered correctly.

<CodeExample>
    <div className="d-block overflow-auto">
        <Stepper horizontal>
            <StepperItem active>Default stepper</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

<CodeExample>
    <div className="text-center overflow-auto">
        <Stepper horizontal>
            <StepperItem active>Center stepper</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

<CodeExample>
    <div className="text-end overflow-auto">
        <Stepper horizontal>
            <StepperItem active>End stepper</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

Apply a full-width utility through `Stepper`'s `className` to make it span the available width. Step items will stretch to fill the space; alignment does not affect full-width steppers.

<CodeExample>
    <div className="d-block overflow-auto">
        <Stepper horizontal className="w-100">
            <StepperItem active>Create account</StepperItem>
            <StepperItem active>Confirm email</StepperItem>
            <StepperItem>Update profile</StepperItem>
            <StepperItem>Finish</StepperItem>
        </Stepper>
    </div>
</CodeExample>

## With anchors

Use `StepperLink` for steps that navigate between pages. Use `StepperButton` for steps that trigger an action within the current page.

Use link utilities through `StepperLink`'s `className` for quick color control.

<CodeExample>
    <div className="d-block overflow-auto">
        <StepperNav>
            <StepperLink active href="#" role="button">
                Create account
            </StepperLink>
            <StepperLink active href="#" role="button">
                Confirm email
            </StepperLink>
            <StepperLink theme="secondary" href="#" role="button">
                Update profile
            </StepperLink>
            <StepperLink theme="secondary" href="#" role="button">
                Finish
            </StepperLink>
        </StepperNav>
    </div>
</CodeExample>

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

| CSS variable                | Default                      |
| --------------------------- | ---------------------------- |
| `--bs-stepper-size`         | `2rem`                       |
| `--bs-stepper-gap`          | `1rem`                       |
| `--bs-stepper-font-size`    | `var(--bs-font-size-sm)`     |
| `--bs-stepper-text-gap`     | `0.5rem`                     |
| `--bs-stepper-track-size`   | `0.125rem`                   |
| `--bs-stepper-bg`           | `var(--bs-bg-2)`             |
| `--bs-stepper-active-color` | `var(--bs-primary-contrast)` |
| `--bs-stepper-active-bg`    | `var(--bs-primary-bg)`       |

### Overflow wrapper

The `StepperOverflow` wrapper establishes an inline-size query container with horizontal scrolling. The horizontal stepper retains its minimum content width, keeping labels readable when the available space is narrow.
