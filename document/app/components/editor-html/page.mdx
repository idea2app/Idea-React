# Editor HTML

[`EditorHTML`][1] converts saved [Editor.js][2] block data to HTML with [editorjs-html][3] and
renders it in an `<article>` element. Use it to display documents produced by the
[Editor](../editor/) component.

## Example

<EditorHTML
    className="border rounded p-3"
    data={{
        time: 1700000000000,
        version: '2.31.0',
        blocks: [
            { type: 'header', data: { text: 'Hello, Editor.js!', level: 2 } },
            { type: 'paragraph', data: { text: 'This article is rendered from block data.' } }
        ]
    }}
/>

## Data

`data` accepts the `OutputData` object returned by Editor.js. Links are rendered with a built-in
`link` block parser; extend the exported `parser` for custom block types.
