# Pagination

Documentation and examples for showing pagination to indicate a series of related content exists across multiple pages.

Compose `Pagination`, `PageItem`, `PageLink`, and `PageText` inside a labelled navigation element.
`Pagination` accepts `theme` and `size`; links inherit `active` and `disabled` from their `PageItem`.

## Overview

`Pagination` renders the page links as a list, providing large hit areas and allowing screen readers to announce the available links. Place it inside a navigation landmark so assistive technologies can identify its purpose.

If the page has more than one navigation landmark, give the pagination landmark a descriptive accessible name, such as "Search results pages".

<CodeExample>
    <Stack gap={3}>
        <nav aria-label="Page navigation example">
            <Pagination>
                <PageItem>
                    <PageLink href="#">Previous</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">1</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">2</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">3</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">Next</PageLink>
                </PageItem>
            </Pagination>
        </nav>
    </Stack>
</CodeExample>

## Working with icons

Looking to use an icon or symbol in place of text for some pagination links? Be sure to provide proper screen reader support with `aria` attributes.

<CodeExample>
    <Stack gap={3}>
        <nav aria-label="Page navigation example">
            <Pagination>
                <PageItem>
                    <PageLink href="#" aria-label="Previous">
                        <span aria-hidden="true">&laquo;</span>
                    </PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">1</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">2</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">3</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#" aria-label="Next">
                        <span aria-hidden="true">&raquo;</span>
                    </PageLink>
                </PageItem>
            </Pagination>
        </nav>
    </Stack>
</CodeExample>

## Active

Set `active` on `PageItem` to indicate the current page. When `PageLink` renders as a link, it also sets `aria-current="page"` for assistive technologies.

<CodeExample>
    <Stack gap={3}>
        <nav aria-label="...">
            <Pagination>
                <PageItem>
                    <PageLink href="#">Previous</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">1</PageLink>
                </PageItem>
                <PageItem active>
                    <PageLink href="#">2</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">3</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">Next</PageLink>
                </PageItem>
            </Pagination>
        </nav>
    </Stack>
</CodeExample>

For a non-interactive current page, render `PageText` instead of a link; it does not need `aria-current`.

## Disabled

Set `disabled` on `PageItem` to disable its `PageLink`. The component removes the destination and
click handler, supplies `aria-disabled`, and excludes the link from keyboard focus.

<CodeExample>
    <Stack gap={3}>
        <nav aria-label="...">
            <Pagination>
                <PageItem disabled>
                    <PageLink>Previous</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">1</PageLink>
                </PageItem>
                <PageItem active>
                    <PageLink href="#">2</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">3</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">Next</PageLink>
                </PageItem>
            </Pagination>
        </nav>
    </Stack>
</CodeExample>

## Alignment

Align pagination by passing flexbox utilities through `className`, such as
`className="justify-content-center"`:

<CodeExample>
    <Stack gap={3}>
        <nav aria-label="Page navigation example">
            <Pagination className="justify-content-center">
                <PageItem disabled>
                    <PageLink>Previous</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">1</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">2</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">3</PageLink>
                </PageItem>
                <PageItem>
                    <PageLink href="#">Next</PageLink>
                </PageItem>
            </Pagination>
        </nav>
    </Stack>
</CodeExample>
