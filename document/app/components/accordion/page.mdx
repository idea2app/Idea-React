# Accordion

Build vertically collapsing accordions with native HTML `<details>` and `<summary>` elements.

The accordion uses native HTML `<details>` and `<summary>` elements, leveraging the `name` attribute to create exclusive accordions where only one item can be open at a time. This approach requires no JavaScript for core functionality and is fully accessible by default.

## Example

Click the accordions below to expand/collapse the accordion content. Each `<details>` element shares the same `name` attribute value, creating an exclusive accordion where opening one item automatically closes the others.

To render an accordion that’s expanded by default, add the `open` attribute to the `<details>` element.

<CodeExample>
    <Accordion>
        <AccordionItem name="accordionExample" open>
            <AccordionHeader>{' Accordion Item #1 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the first item’s accordion body.'}</strong>
                {' It is shown by default because the '}
                <code>{'open'}</code>
                {' attribute is present. The native '}
                <code>{'<details>'}</code>
                {
                    ' element handles all the show/hide logic without any JavaScript. You can put any HTML content within the '
                }
                <code>{'.accordion-body'}</code>
                {'. '}
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionExample">
            <AccordionHeader>{' Accordion Item #2 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the second item’s accordion body.'}</strong>
                {' The '}
                <code>{'name'}</code>
                {
                    ' attribute groups this with other accordion items. When you open this item, any other open item in the same group will close automatically. '
                }
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionExample">
            <AccordionHeader>{' Accordion Item #3 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the third item’s accordion body.'}</strong>
                {
                    ' This exclusive accordion behavior is built into the browser—no Bootstrap JavaScript required. Just use matching '
                }
                <code>{'name'}</code>
                {' attributes on your '}
                <code>{'<details>'}</code>
                {' elements. '}
            </AccordionBody>
        </AccordionItem>
    </Accordion>

</CodeExample>

The panel height animation needs [`interpolate-size`][1]. Browsers without it open and close the panel at once. See [Transitions][2] to change the timing or to remove it.

> The animation effect depends on the `prefers-reduced-motion` media query. See the [reduced motion accessibility guidance][3].

## Gap

Add `.accordion-gap` to put space between accordion items. Each item is a separate rounded card.

The gap lives on the accordion, not the panel. The panel still animates only its `block-size`, so the open and close transition stays smooth.

<CodeExample>
    <Accordion gap>
        <AccordionItem name="accordionGapExample" open>
            <AccordionHeader>{' Accordion Item #1 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the first item’s accordion body.'}</strong>
                {' The '}
                <code>{'.accordion-gap'}</code>
                {
                    ' class spaces items apart. Each item keeps a full border radius while the panel opens and closes. '
                }
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionGapExample">
            <AccordionHeader>{' Accordion Item #2 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the second item’s accordion body.'}</strong>
                {
                    ' The gap does not change during the transition, so adjacent items do not jump. '
                }
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionGapExample">
            <AccordionHeader>{' Accordion Item #3 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the third item’s accordion body.'}</strong>
                {' Override '}
                <code>{'--accordion-gap'}</code>
                {' to change the space between items. '}
            </AccordionBody>
        </AccordionItem>
    </Accordion>

</CodeExample>

## Always open

Omit the `name` attribute on each `<details>` element to allow multiple accordion items to be open simultaneously.

<CodeExample>
    <Accordion>
        <AccordionItem open>
            <AccordionHeader>{' Accordion Item #1 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the first item’s accordion body.'}</strong>
                {' Without the '}
                <code>{'name'}</code>
                {
                    ' attribute, each accordion item operates independently. You can open multiple items at the same time. '
                }
            </AccordionBody>
        </AccordionItem>

        <AccordionItem>
            <AccordionHeader>{' Accordion Item #2 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the second item’s accordion body.'}</strong>
                {' Opening this won’t close the first item because there’s no '}
                <code>{'name'}</code>

        </AccordionItem>

                    ' Each item is completely independent—open or close them in any combination you like. '
                }
            </AccordionBody>
        </AccordionItem>
    </Accordion>

</CodeExample>

## Expand & Collapse all

To enable expanding and collapsing of all accordion items at once, remove the `name` attribute from each `<details>` element using JavaScript. This allows multiple accordion items to be open simultaneously. Restore the `name` attribute when you collapse the items again if you want exclusive behavior back.

<CodeExample>
    <AccordionToggle
        target="#accordionToggleAll"
        variant="subtle"
        size="sm"
        theme="secondary"
        type="button"
        aria-expanded="false"
        className="mb-3"
    >
        {'Expand all'}
    </AccordionToggle>

    <Accordion size="sm" id="accordionExpandCollapse">
        <AccordionItem name="accordionExpandCollapse" open>
            <AccordionHeader>{' Accordion Item #1 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the first item’s accordion body.'}</strong>
                {' Use Expand all to open every item, even when they share a '}
                <code>{'name'}</code>
                {'. '}
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionExpandCollapse">
            <AccordionHeader>{' Accordion Item #2 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the second item’s accordion body.'}</strong>
                {' Collapse all closes every item and restores exclusive '}
                <code>{'name'}</code>
                {' grouping. '}
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionExpandCollapse">
            <AccordionHeader>{' Accordion Item #3 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the third item’s accordion body.'}</strong>
                {' If your accordion has no '}
                <code>{'name'}</code>
                {', you only need to set '}
                <code>{'open'}</code>
                {' on each item. '}
            </AccordionBody>
        </AccordionItem>
    </Accordion>

</CodeExample>

## Nested

Accordions can be nested inside each other by placing a full `.accordion` within an `.accordion-body`. Use unique `name` attribute values for each level so the parent and child accordions operate independently.

<CodeExample>
    <Accordion>
        <AccordionItem name="accordionNested" open>
            <AccordionHeader>{' Accordion Item #1 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the first item’s accordion body.'}</strong>
                {' It contains a nested accordion below. '}
                <Accordion className="mt-3">
                    <AccordionItem name="accordionNestedInner" open>
                        <AccordionHeader>{' Nested Item #1 '}</AccordionHeader>

                        <AccordionBody>
                            {' This is the body of the first nested accordion item. '}
                        </AccordionBody>
                    </AccordionItem>

                    <AccordionItem name="accordionNestedInner">
                        <AccordionHeader>{' Nested Item #2 '}</AccordionHeader>

                        <AccordionBody>
                            {' This is the body of the second nested accordion item. '}
                        </AccordionBody>
                    </AccordionItem>

                    <AccordionItem name="accordionNestedInner">
                        <AccordionHeader>{' Nested Item #3 '}</AccordionHeader>

                        <AccordionBody>
                            {' This is the body of the third nested accordion item. '}
                        </AccordionBody>
                    </AccordionItem>
                </Accordion>
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionNested">
            <AccordionHeader>{' Accordion Item #2 '}</AccordionHeader>

            <AccordionBody>
                <strong>{'This is the second item’s accordion body.'}</strong>
                {' It does not contain a nested accordion. '}
            </AccordionBody>
        </AccordionItem>

        <AccordionItem name="accordionNested">
            <AccordionHeader>{' Accordion Item #3 '}</AccordionHeader>

                {' It does not contain a nested accordion. '}
            </AccordionBody>

    </Accordion>

</CodeExample>

## Accessibility

The native `<details>` and `<summary>` elements provide built-in accessibility:

- Screen readers announce the expanded/collapsed state automatically
- Keyboard navigation works out of the box (Enter/Space to toggle)
- The `<summary>` element is focusable by default
- No ARIA attributes are required as the semantics are built into the elements

## Customize

### Custom icons

Use the `icon` prop on `AccordionHeader` to choose an Icon font name, or `icon={false}` to remove it.

```tsx
<AccordionHeader icon="plus-lg">Accordion title</AccordionHeader>
```

### Events

Use the native `onToggle` prop on `AccordionItem` to respond to open-state changes.

### Programmatic control

Pass the native `open` prop to `AccordionItem` to control its state. `AccordionToggle target="#id"` expands or collapses all items together.
