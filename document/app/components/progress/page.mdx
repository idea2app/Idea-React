# Progress

Use `Progress` and `ProgressStack` to display progress bars, including stacked bars, striped backgrounds, animation, and text labels.

## How it works

`Progress` renders an accessible progress indicator and visual bar. It does not use the [HTML `<progress>` element][1], which allows the component to support stacking, animation, and labels inside the bar.

- `Progress` uses `value`, `min`, and `max` to set the current and range values, and generates the accessibility attributes automatically.
- Provide an accessible name with `aria-label` or `aria-labelledby`.
- Pass a label as `Progress`'s children.
- Use `barProps` to pass styles or utility classes to the inner bar.
- Use `ProgressStack` to group multiple progress components into a stacked bar.

Put that all together, and you have the following examples.

`Progress` generates both elements and the value attributes from `value`, `min`, and `max`.
Provide an accessible name; pass labels as children and inner-bar utilities through `barProps`.
`ProgressStack` uses CSS to place each segment’s calculated width on its outer element.

<CodeExample>
    <Stack gap={3}>
        <Progress value={0.0} aria-label="Basic example" />
        <Progress value={25.0} aria-label="Basic example" />
        <Progress value={50.0} aria-label="Basic example" />
        <Progress value={75.0} aria-label="Basic example" />
        <Progress value={100.0} aria-label="Basic example" />
    </Stack>
</CodeExample>

## Bar sizing

### Width

Use width utilities through `Progress`'s `barProps.className` when you need to adjust the visual bar width.

<CodeExample>
    <Stack gap={3}>
        <Progress value={75.0} barProps={{ className: 'w-75' }} aria-label="Basic example" />
    </Stack>
</CodeExample>

### Height

Set the height on `Progress` itself; the inner bar resizes automatically.

<CodeExample>
    <Stack gap={3}>
        <Progress value={25.0} aria-label="Example 1px high" style={{ height: '1px' }} />
        <Progress value={25.0} aria-label="Example 20px high" style={{ height: '20px' }} />
    </Stack>
</CodeExample>

## Labels

Pass a label as children of `Progress`.

<CodeExample>
    <Stack gap={3}>
        <Progress value={25.0} aria-label="Example with label">
            25%
        </Progress>
    </Stack>
</CodeExample>

### Long labels

By default, the content inside `Progress` is clipped to the bar. If the bar is shorter than its label, the content may become unreadable. To change this behavior, pass the `overflow-visible` utility through `barProps.className`.

> Labels longer than the progress bar may not be fully accessible because their text color must contrast with both the track and bar backgrounds. Use caution when implementing this example.
>
> If the text can overlap the progress bar, we often recommend displaying the label outside of the progress bar for better accessibility.

## Backgrounds

Set `theme` on `Progress` to choose a theme color for its bar. For custom colors, pass a background utility through `barProps.className`.

<CodeExample>
    <Stack gap={3}>
        <Progress
            value={25.0}
            barProps={{ className: 'bg-success' }}
            aria-label="Success example"
        />
        <Progress value={50.0} barProps={{ className: 'bg-info' }} aria-label="Info example" />
        <Progress
            value={75.0}
            barProps={{ className: 'bg-warning' }}
            aria-label="Warning example"
        />
        <Progress value={100.0} barProps={{ className: 'bg-danger' }} aria-label="Danger example" />
    </Stack>
</CodeExample>

> **Conveying meaning to assistive technologies:** Color alone is not conveyed to screen reader users. Ensure that information is also clear from the content, or include it in the accessible name with `aria-label` or `aria-labelledby`.

If you’re adding labels to progress bars with a custom background color, make sure to also set an appropriate [text color][2], so the labels remain readable and have sufficient contrast. We recommend using the [theme contrast][3] helper classes.

<CodeExample>
    <Stack gap={3}>
        <Progress value={25.0} theme="success" aria-label="Success example">
            25%
        </Progress>
        <Progress value={50.0} theme="info" aria-label="Info example">
            50%
        </Progress>
        <Progress value={75.0} theme="warning" aria-label="Warning example">
            75%
        </Progress>
        <Progress value={100.0} theme="danger" aria-label="Danger example">
            100%
        </Progress>
    </Stack>
</CodeExample>

## Multiple bars

Place multiple `Progress` components inside `ProgressStack` to create a single stacked bar. In this case, set each segment's value on `Progress`; do not set a separate width on its inner bar.

<CodeExample>
    <Stack gap={3}>
        <ProgressStack>
            <Progress value={15.0} aria-label="Segment one" />
            <Progress
                value={30.0}
                barProps={{ className: 'bg-success' }}
                aria-label="Segment two"
            />
            <Progress value={20.0} barProps={{ className: 'bg-info' }} aria-label="Segment three" />
        </ProgressStack>
    </Stack>
</CodeExample>

## Striped

Set `striped` on `Progress` to apply a gradient stripe over the bar's background color.

<CodeExample>
    <Stack gap={3}>
        <Progress value={10.0} striped aria-label="Default striped example" />
        <Progress
            value={25.0}
            striped
            barProps={{ className: 'bg-success' }}
            aria-label="Success striped example"
        />
        <Progress
            value={50.0}
            striped
            barProps={{ className: 'bg-info' }}
            aria-label="Info striped example"
        />
        <Progress
            value={75.0}
            striped
            barProps={{ className: 'bg-warning' }}
            aria-label="Warning striped example"
        />
        <Progress
            value={100.0}
            striped
            barProps={{ className: 'bg-danger' }}
            aria-label="Danger striped example"
        />
    </Stack>
</CodeExample>

## Animated stripes

Set `animated` as well as `striped` on `Progress` to animate the stripes from right to left.

<CodeExample>
    <Stack gap={3}>
        <Progress value={75.0} striped animated aria-label="Animated striped example" />
    </Stack>
</CodeExample>

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

| CSS variable                   | Default                                   |
| ------------------------------ | ----------------------------------------- |
| `--bs-progress-height`         | `1rem`                                    |
| `--bs-progress-font-size`      | `var(--bs-font-size-sm)`                  |
| `--bs-progress-bg`             | `var(--bs-bg-2)`                          |
| `--bs-progress-border-radius`  | `var(--bs-radius-5)`                      |
| `--bs-progress-box-shadow`     | `var(--bs-box-shadow-inset)`              |
| `--bs-progress-bar-color`      | `var(--bs-white)`                         |
| `--bs-progress-bar-bg`         | `var(--bs-primary-bg)`                    |
| `--bs-progress-bar-transition` | `width 0.6s ease`                         |
| `--bs-progress-bar-animation`  | `progress-bar-stripes 1s linear infinite` |

### Keyframes

Used when the `animated` prop is enabled. The animation moves the striped background from one stripe
width to zero, producing continuous motion from right to left.
