# Placeholder

Use loading placeholders (skeleton loaders) for your components or pages to indicate something may still be loading.

Use `Placeholder` for skeleton shapes, `PlaceholderAnimation` to animate a group or text, and
`PlaceholderButton` for a disabled button-shaped placeholder. Their props generate the component
styles discussed below.

## About

Placeholders are built with HTML and CSS and need no JavaScript. Render them conditionally to control
visibility, and use the `Placeholder` props to set their color, size, width, and animation.

## How it works

Render `Placeholder` for a skeleton shape, and use `Col` to set its grid width. Use the `as` prop
when the placeholder should render as a different element.

`PlaceholderButton` applies the button sizing and disabled state for button-shaped placeholders.

<CodeExample>
    <Stack gap={3}>
        <p aria-hidden="true">
            <Col as={Placeholder} xs={6} />
        </p>
        <Col
            as={PlaceholderButton}
            xs={4}
            variant="solid"
            theme="primary"
            aria-disabled="true"
            href="#"
        />
    </Stack>
</CodeExample>

> The use of `aria-hidden="true"` only indicates that the element should be hidden to screen readers. The _loading_ behavior of the placeholder depends on how authors will actually use the placeholder styles, how they plan to update things, etc. Some JavaScript code may be needed to _swap_ the state of the placeholder and inform AT users of the update.

## Width

Set the `width` prop for a fixed or percentage width, use `Col` for grid sizing, or pass width
utilities through `className`.

<CodeExample>
    <Stack gap={3}>
        <Col as={Placeholder} xs={6} />
        <Placeholder className="w-75" />
        <Placeholder style={{ width: '25%' }} />
    </Stack>
</CodeExample>

## Color

By default, `Placeholder` uses `currentColor`. Set its `theme` prop to choose a theme color, or use
`className` for a custom color.

<CodeExample>
    <Stack gap={3}>
        <Col as={Placeholder} xs={9} />
        <Col as={Placeholder} xs={6} theme="primary" />
        <Col as={Placeholder} xs={6} theme="accent" />
        <Col as={Placeholder} xs={6} theme="secondary" />
        <Col as={Placeholder} xs={6} theme="success" />
        <Col as={Placeholder} xs={6} theme="danger" />
        <Col as={Placeholder} xs={6} theme="warning" />
        <Col as={Placeholder} xs={6} theme="info" />
        <Col as={Placeholder} xs={6} theme="inverse" />
    </Stack>
</CodeExample>

## Sizing

The size of `Placeholder` follows the typographic style of its parent. Set `size` to `"lg"`, `"sm"`,
or `"xs"` to use a sizing modifier.

<CodeExample>
    <Stack gap={2}>
        <Col as={Placeholder} xs={12} size="lg" />
        <Col as={Placeholder} xs={12} />
        <Col as={Placeholder} xs={12} size="sm" />
        <Col as={Placeholder} xs={12} size="xs" />
    </Stack>
</CodeExample>

## Animation

Set `PlaceholderAnimation`'s `animation` prop to `"wave"` for the default loading animation, or
`"pulse"` for an opacity pulse. `"glow"` remains available as a compatibility alias for `"pulse"`.

<CodeExample>
    <Stack gap={3}>
        <PlaceholderAnimation animation="wave">
            <Col as={Placeholder} xs={12} />
        </PlaceholderAnimation>
        <PlaceholderAnimation animation="pulse">
            <Col as={Placeholder} xs={12} />
        </PlaceholderAnimation>
    </Stack>
</CodeExample>

### Text

Wrap text in `PlaceholderAnimation` to apply the loading animation.

<CodeExample>
    <Stack gap={3}>
        <PlaceholderAnimation animation="wave" className="fg-3 d-inline">
            Working on it…
        </PlaceholderAnimation>
    </Stack>
</CodeExample>
