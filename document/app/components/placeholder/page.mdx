# Placeholder

Use loading placeholders (skeleton loaders) for your components or pages to indicate something may still be loading.

Use `Placeholder` for skeleton shapes, `PlaceholderAnimation` to animate a group or text, and
`PlaceholderButton` for a disabled button-shaped placeholder. Their props generate the component
styles discussed below.

## About

Placeholders can be used to enhance the experience of your application. They’re built only with HTML and CSS, meaning you don’t need any JavaScript to create them. You will, however, need some custom JavaScript to toggle their visibility. Their appearance, color, and sizing can be easily customized with our utility classes.

## How it works

Create placeholders with the `.placeholder` class and a grid column class (e.g., `.col-6`) to set the `width`. They can replace the text inside an element or be added as a modifier class to an existing component.

We apply additional styling to `.btn`s via `::before` to ensure the `height` is respected. You may extend this pattern for other situations as needed, or add a `&nbsp;` within the element to reflect the height when actual text is rendered in its place.

<CodeExample>
    <Stack className="gap-3">
        <p aria-hidden="true">
            <Placeholder className="col-6" />
        </p>
        <PlaceholderButton
            variant="solid"
            theme="primary"
            aria-disabled="true"
            href="#"
            className="col-4"
        />
    </Stack>
</CodeExample>

> The use of `aria-hidden="true"` only indicates that the element should be hidden to screen readers. The _loading_ behavior of the placeholder depends on how authors will actually use the placeholder styles, how they plan to update things, etc. Some JavaScript code may be needed to _swap_ the state of the placeholder and inform AT users of the update.

## Width

You can change the `width` through grid column classes, width utilities, or inline styles.

<CodeExample>
    <Stack className="gap-3">
        <Placeholder className="col-6" />
        <Placeholder className="w-75" />
        <Placeholder style={{ width: '25%' }} />
    </Stack>
</CodeExample>

## Color

By default, the `placeholder` uses `currentColor`. This can be overridden with a custom color or utility class.

<CodeExample>
    <Stack className="gap-3">
        <Placeholder className="col-9" />
        <Placeholder theme="primary" className="col-6" />
        <Placeholder theme="accent" className="col-6" />
        <Placeholder theme="secondary" className="col-6" />
        <Placeholder theme="success" className="col-6" />
        <Placeholder theme="danger" className="col-6" />
        <Placeholder theme="warning" className="col-6" />
        <Placeholder theme="info" className="col-6" />
        <Placeholder theme="inverse" className="col-6" />
    </Stack>
</CodeExample>

## Sizing

The size of `.placeholder`s are based on the typographic style of the parent element. Customize them with sizing modifiers: `.placeholder-lg`, `.placeholder-sm`, or `.placeholder-xs`.

<CodeExample>
    <Stack className="gap-2">
        <Placeholder size="lg" className="col-12" />
        <Placeholder className="col-12" />
        <Placeholder size="sm" className="col-12" />
        <Placeholder size="xs" className="col-12" />
    </Stack>
</CodeExample>

## Animation

Use `.placeholder-wave` for the default loading animation. Use `.placeholder-pulse` for an opacity pulse. The old `.placeholder-glow` class remains as a compatibility alias for `.placeholder-pulse`.

<CodeExample>
    <Stack className="gap-3">
        <PlaceholderAnimation animation="wave">
            <Placeholder className="col-12" />
        </PlaceholderAnimation>
        <PlaceholderAnimation animation="pulse">
            <Placeholder className="col-12" />
        </PlaceholderAnimation>
    </Stack>
</CodeExample>

### Text

Add `.placeholder-wave` to an inline element to apply the loading animation to text.

<CodeExample>
    <Stack className="gap-3">
        <PlaceholderAnimation animation="wave" className="fg-3 d-inline">
            Working on it…
        </PlaceholderAnimation>
    </Stack>
</CodeExample>
