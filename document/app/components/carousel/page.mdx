# Carousel

A slider or slideshow component for cycling through series of content, ranging from products to images and more, one at a time.

## How it works

- Carousel is built on CSS’s [scroll-snap][1], so sliding, touch dragging, momentum, and keyboard scrolling all come from the browser. The React component manages autoplay, the previous/next controls, the indicators, and active-slide syncing.

- Because the slides live in a real scroll container, the carousel can show [more than one slide at a time][2], reveal a “peek” of the neighboring slides, and mix variable-width slides—all controlled with CSS.

- Carousels can have any number of slides, with just about any content within. Our examples show images and text, but you can put anything you like inside each `CarouselSlide`. We don't support nested carousels.

- Carousel items or slides do not normalize their dimensions. As such, you may need to use additional utilities or custom styles to appropriately size content. While carousels support previous/next controls and indicators, they’re not explicitly required. Add and customize as you see fit.

- `Carousel` initializes on mount, including active-slide syncing as the user scrolls or swipes. Pass `autoplay` for [autoplaying carousels][3]. Do not initialize the same carousel with Bootstrap’s JavaScript plugin.

- **The React wrapper starts on the first slide.** It manages the active state that drives indicator syncing and, with `fade`, which slide is shown. A child’s `active` prop does not select the initial slide. Controls and indicators are scoped to their own carousel, so multiple instances do not need Bootstrap target attributes.

The animation effect of this component is dependent on the `prefers-reduced-motion` media query. Slides swap immediately and the autoplay indicator countdown is disabled for users who prefer reduced motion.

## Items

Because the carousel is a real scroll container, you can change how many slides are visible and how they’re sized with a few CSS custom properties on `Carousel` without writing any JavaScript.

- `--bs-carousel-items` sets the number of whole slides visible per view (default `1`).
- `--bs-carousel-items-gap` sets the space between slides (default `0px`).
- `--bs-carousel-items-peek` sets how much of the neighboring slides to reveal (default `0px`).

### Multiple items

Set `items` to show several slides at once. Combine it with `itemsGap` for spacing; these props set the corresponding CSS custom properties.

<CodeExample source="document/component/Documentation/Components/CarouselImage/index.tsx">
    <Carousel
        id="carouselMultiple"
        aria-label="Multiple items"
        controlsPlacement="top"
        controlsStart={<h5 className="mb-0">Three at a time</h5>}
        items={3}
        itemsGap="1rem"
        ends="stop"
    >
        {['#777', '#6c6c6c', '#666', '#5c5c5c', '#555', '#4c4c4c', '#444'].map(
            (background, index) => (
                <CarouselSlide key={background}>
                    <CarouselImage
                        width={260}
                        height={200}
                        color="#fff"
                        background={background}
                        large={false}
                        rounded
                    >
                        {String(index + 1)}
                    </CarouselImage>
                </CarouselSlide>
            )
        )}
    </Carousel>
</CodeExample>

Set `items={3}` to control the count, or set `--bs-carousel-items` through a CSS module for responsive layouts.

## Autoplay

Set `autoplay` to `true` to cycle a carousel automatically on page load. Autoplay pauses on hover—configurable with the `pause` option—and while the page isn’t visible, using the [Page Visibility API][5]. As soon as a visitor takes control—clicking a control or indicator, using the keyboard, or swiping—autoplay stops, so content isn’t moved out from under them.

For accessibility reasons, we recommend avoiding the use of autoplaying carousels. If your page does include one, provide a discoverable control to pause and resume it: pass `playPause` to add a play/pause button (shown below). This satisfies [WCAG 2.2 Success Criterion 2.2.2 Pause, Stop, Hide][6], which a hover- or focus-only pause does not. The wrapper also includes this button automatically when `autoplay` is enabled.

The play/pause button reflects the current state automatically—a pause icon while playing, a play icon while stopped. The wrapper supplies an accessible name for each state. While playing, the active indicator fills like a progress bar over the current slide’s [interval][7] as a visual countdown; it pauses with autoplay and is disabled under reduced motion. Set its color with the `--bs-carousel-indicator-progress-bg` CSS variable.

<CodeExample source="document/component/Documentation/Components/CarouselImage/index.tsx">
    <Carousel
        id="carouselExampleAutoplaying"
        aria-label="Autoplay"
        controlsPlacement="bottom"
        autoplay
        playPause
        indicators
    >
        <CarouselSlide>
            <CarouselImage rounded>First slide</CarouselImage>
        </CarouselSlide>
        <CarouselSlide>
            <CarouselImage color="#444" background="#666" rounded>
                Second slide
            </CarouselImage>
        </CarouselSlide>
        <CarouselSlide>
            <CarouselImage color="#333" background="#555" rounded>
                Third slide
            </CarouselImage>
        </CarouselSlide>
    </Carousel>
</CodeExample>

## End behavior

The `ends` prop controls what happens at the first and last slide. Choose from `loop` (the default), `wrap`, or `stop`.

### Loop (default)

With `ends="loop"` the carousel scrolls seamlessly past the ends: stepping next from the last slide (or previous from the first) continues in the same direction into the destination slide instead of jumping back, for an endless conveyor effect. This is the default, so it applies with or without the prop. Seamless looping applies to single-slide carousels driven by the controls, keyboard, or autoplay; multi-item, peek, centered, and variable-width layouts—as well as users who prefer reduced motion—fall back to the `wrap` jump.

<CodeExample source="document/component/Documentation/Components/CarouselImage/index.tsx">

        id="carouselEndsLoop"
        aria-label="Loop"
        controlsPlacement="top"
        controlsStart={<h5 className="mb-0">Loop</h5>}

## Usage

### Via props

Use props to control the carousel rather than Bootstrap’s data-attribute plugin. Previous/next buttons and indicator buttons are wired automatically to their own instance.

| Prop                 | Description                                                                          |
| -------------------- | ------------------------------------------------------------------------------------ |
| `autoplay`           | Automatically cycle through slides on mount.                                         |
| `interval`           | Autoplay interval in milliseconds between slides; individual slides can override it. |
| `ends`               | Choose `stop`, `wrap`, or `loop` behavior at the ends.                               |
| `playPause`          | Render an accessible play/pause control.                                             |
| `controlsPlacement`  | Put the controls at the top, bottom, or over the slides.                             |
| `controlsStart`      | Content to display at the start of the controls row.                                 |
| `controlsClassName`  | Bootstrap utilities or a CSS module for the non-overlay controls row.                |
| `innerClassName`     | Bootstrap utilities or a CSS module for the scroll viewport.                         |
| `indicatorPlacement` | Position indicators before, after, or between the previous/next buttons.             |

### Via React

Mount the component to initialize it. Timers and scroll listeners are cleaned up on unmount.

```tsx
import { Carousel, CarouselSlide } from 'idea-react';

<Carousel aria-label="My carousel" controlsPlacement="bottom" indicators>
    <CarouselSlide>First slide</CarouselSlide>
    <CarouselSlide>Second slide</CarouselSlide>
</Carousel>;
```

### Dependencies

Load Bootstrap CSS and Bootstrap Icons alongside Idea React. The component manages its own state and scrolling and does not require Bootstrap’s JavaScript plugin. Follow the [installation guide][9].

### Options

| Prop                 | Type            | Default     | Description                                                                                                                                                                                                                           |
| -------------------- | --------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `autoplay`           | boolean         | `false`     | Automatically cycle through slides on mount.                                                                                                                                                                                          |
| `ends`               | string          | `"loop"`    | `stop` disables previous/next at the ends. `wrap` jumps to the opposite end. `loop` scrolls seamlessly for single-slide carousels, falling back to `wrap` for multi-item, peek, centered, variable-width, and reduced-motion layouts. |
| `interval`           | number          | `5000`      | Delay in milliseconds between automatically cycling an item.                                                                                                                                                                          |
| `keyboard`           | boolean         | `true`      | React to left/right arrow keys outside editable controls.                                                                                                                                                                             |
| `pause`              | string, boolean | `"hover"`   | Pause temporarily while the pointer or focus is inside the carousel. Pass `false` to disable this pause.                                                                                                                              |
| `controls`           | boolean         | `true`      | Render previous and next buttons.                                                                                                                                                                                                     |
| `controlsPlacement`  | string          | `"overlay"` | Choose `top`, `bottom`, or `overlay`.                                                                                                                                                                                                 |
| `indicators`         | boolean         | `false`     | Render slide indicators.                                                                                                                                                                                                              |
| `indicatorPlacement` | string          | `"start"`   | Choose `start`, `end`, or `between`.                                                                                                                                                                                                  |
| `playPause`          | boolean         | `false`     | Provide an explicit autoplay control; also included automatically for `autoplay`.                                                                                                                                                     |
| `auto`               | boolean         | `false`     | Let slides retain their individual widths.                                                                                                                                                                                            |
| `center`             | boolean         | `false`     | Snap the active slide to the center of the viewport.                                                                                                                                                                                  |
| `fade`               | boolean         | `false`     | Crossfade stacked slides instead of scrolling.                                                                                                                                                                                        |

The visible slide count, gap, and peek are controlled with CSS custom properties, exposed through `items`, `itemsGap`, and `itemsPeek`—see [Items][2].

### Methods

For imperative controls, attach a React ref to `Carousel` and use its model methods. Methods return before the scrolling or crossfade has visually completed.

```tsx
import { createRef } from 'react';
import { Carousel } from 'idea-react';

const carousel = createRef<Carousel>();

carousel.current?.store.play();
carousel.current?.store.pause();
carousel.current?.store.next(true);
carousel.current?.store.previous(true);
carousel.current?.store.setIndex(2, true);
```

| Method                        | Description                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------- |
| `store.play()`                | Start cycling through the carousel items.                                        |
| `store.pause()`               | Stop cycling through items.                                                      |
| `store.toggle()`              | Toggle autoplay.                                                                 |
| `store.next(true)`            | Move to the next slide and stop autoplay for user-initiated navigation.          |
| `store.previous(true)`        | Move to the previous slide and stop autoplay for user-initiated navigation.      |
| `store.setIndex(index, true)` | Select a zero-based slide index and stop autoplay for user-initiated navigation. |

The component disposes its model and scroll animation when unmounted; do not use Bootstrap’s `getInstance`, `getOrCreateInstance`, or `dispose` methods on it.

### Events

`onChange(index)` receives the zero-based active slide index after navigation or scroll synchronization. It reports logical selection, not the end of the scroll or crossfade animation. Bootstrap’s `slide.bs.carousel` and `slid.bs.carousel` plugin events are not emitted by this wrapper.

```tsx
<Carousel onChange={handleSlideChange}>
    <CarouselSlide>First slide</CarouselSlide>
    <CarouselSlide>Second slide</CarouselSlide>
</Carousel>
```
