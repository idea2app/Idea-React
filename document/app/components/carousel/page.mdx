# Carousel

A slider or slideshow component for cycling through series of content, ranging from products to images and more, one at a time.

## How it works

- Carousel is built on CSS’s [scroll-snap][1], so sliding, touch dragging, momentum, and keyboard scrolling all come from the browser. JavaScript manages autoplay, the previous/next controls, the indicators, and active-slide syncing.

- Because the slides live in a real scroll container, the carousel can show [more than one slide at a time][2], reveal a “peek” of the neighboring slides, and mix variable-width slides—all controlled with CSS.

- Carousels can have any number of slides, with just about any content within. Our examples show images and text, but you can put anything you like inside each `CarouselSlide`. We don't support nested carousels.

- Carousel items or slides do not normalize their dimensions. As such, you may need to use additional utilities or custom styles to appropriately size content. While carousels support previous/next controls and indicators, they’re not explicitly required. Add and customize as you see fit.

- `Carousel` initializes on mount, including active-slide syncing as the user scrolls or swipes. Use `autoplay` for [autoplaying carousels][3]; do not initialize the same element with Bootstrap’s JavaScript plugin.

- **The wrapper starts on the first slide.** It does not expose initial-slide selection or seed its starting index from a child’s `active` prop. It manages active state, indicators, and the visible slide when `fade` is enabled. Controls and indicators are scoped to their own carousel, so multiple carousels do not need target attributes.

The animation effect of this component is dependent on the `prefers-reduced-motion` media query.

## Items

Because the carousel is a real scroll container, you can change how many slides are visible and how they’re sized with a few CSS custom properties on `Carousel` without writing any JavaScript.

- `--bs-carousel-items` sets the number of whole slides visible per view (default `1`).
- `--bs-carousel-items-gap` sets the space between slides (default `0`).
- `--bs-carousel-items-peek` sets how much of the neighboring slides to reveal (default `0`).

## Autoplay

Set `autoplay` to `true` to cycle a carousel automatically on page load. Autoplay pauses on hover—configurable with the `pause` option—and, where the [Page Visibility API][5] is supported, while the page isn’t visible. As soon as a visitor takes control—clicking a control or indicator, using the keyboard, or swiping—autoplay stops for good, so content isn’t moved out from under them.

For accessibility reasons, we recommend avoiding the use of autoplaying carousels. If your page does include one, provide a discoverable control to pause and resume it: pass `playPause` to add a play/pause button (shown below). This satisfies [WCAG 2.2 Success Criterion 2.2.2 Pause, Stop, Hide][6], which a hover- or focus-only pause does not.

The play/pause button toggles autoplay and reflects the current state automatically—a pause icon while playing, a play icon while stopped. The wrapper supplies accessible names for both states. While playing, the active indicator fills like a progress bar over the current slide’s [interval][7] as a visual countdown; it pauses with autoplay and is disabled under reduced motion. Set its color with the `--bs-carousel-indicator-progress-bg` CSS variable.

<CodeExample>
    <Carousel aria-label="Example carousel" autoplay playPause>
        <CarouselSlide>
            <div
                className="d-flex flex-column align-items-center justify-content-center bg-body-tertiary p-5 rounded-4"
                style={{ minHeight: 240 }}
            >
                <h3>First slide</h3>
            </div>
        </CarouselSlide>
        <CarouselSlide>
            <div
                className="d-flex flex-column align-items-center justify-content-center bg-body-tertiary p-5 rounded-4"
                style={{ minHeight: 240 }}
            >
                <h3>Second slide</h3>
            </div>
        </CarouselSlide>
        <CarouselSlide>
            <div
                className="d-flex flex-column align-items-center justify-content-center bg-body-tertiary p-5 rounded-4"

</CodeExample>

## End behavior

The `ends` option controls what happens at the first and last slide. Pass `ends`, choosing from `loop` (the default), `wrap`, or `stop`.

### Loop (default)

With `ends="loop"` the carousel scrolls seamlessly past the ends: stepping next from the last slide (or previous from the first) continues in the same direction into the destination slide instead of jumping back, for an endless conveyor effect. This is the default, so it applies with or without the prop. Seamless looping applies to single-slide carousels driven by the controls, keyboard, or autoplay; multi-item, peek, centered, and variable-width layouts—as well as users who prefer reduced motion—fall back to the `wrap` jump.

<CodeExample>

                className="d-flex flex-column align-items-center justify-content-center bg-body-tertiary p-5 rounded-4"

With `ends="stop"` the carousel hard-stops at the first and last slide. The previous control is automatically disabled on the first slide and the next control on the last (via the native `disabled` attribute on `<button>` controls); when a focused control becomes disabled, focus shifts to the opposite control so it isn’t lost.

## Usage

The React component initializes on mount and cleans up its timers and listeners on unmount.

### Options

| Prop         | Default     | Description                                                                                                       |
| ------------ | ----------- | ----------------------------------------------------------------------------------------------------------------- |
| `autoplay`   | `false`     | Automatically cycle through slides on mount.                                                                      |
| `interval`   | `5000`      | Delay in milliseconds between slides; individual slides can override it.                                          |
| `keyboard`   | `true`      | React to left and right arrow keys outside editable controls.                                                     |
| `pause`      | hover/focus | Temporarily pause autoplay while the pointer or focus is inside the carousel. Pass `false` to disable this pause. |
| `ends`       | `"loop"`    | Choose seamless looping, a wraparound jump, or stopping at the ends.                                              |
| `controls`   | `true`      | Render previous and next buttons.                                                                                 |
| `indicators` | `false`     | Render slide indicators.                                                                                          |
| `playPause`  | `false`     | Provide an explicit autoplay control.                                                                             |

### Events

`onChange(index)` receives the zero-based active slide index after navigation or scroll synchronization.
