# Idea React extensions

Idea React complements Bootstrap 6 with reusable React and MobX components. Each item below links
to its implementation and describes its primary purpose.

| Export                | Purpose                                             |
| --------------------- | --------------------------------------------------- |
| `Avatar`              | Responsive, rounded user image                      |
| `ClickBoundary`       | Detects clicks outside a component boundary         |
| `CodeBlock`           | Syntax-highlighted code block                       |
| `Countdown`           | Renders a countdown from a target time              |
| `Editor`              | Rich text editor powered by Editor.js               |
| `EditorHTML`          | Converts Editor.js data to HTML                     |
| `HorizontalMarquee`   | Horizontally scrolls overflowing content            |
| `Icon`                | Bootstrap Icons font wrapper                        |
| `LiveTSX`             | Renders editable or evaluated TSX examples          |
| `Loading`             | Full-page loading overlay                           |
| `MonthCalendar`       | Interactive month grid with selectable date entries |
| `Nameplate`           | Displays a person with an avatar and name           |
| `PageNav`             | Builds a table of contents from page headings       |
| `ScrollNav`           | Horizontally scrollable navigation                  |
| `Select` and `Option` | Accessible menu-backed value selector               |
| `ShareBox`            | Captures content as a shareable image               |
| `SpinnerButton`       | Button with an inline loading indicator             |
| `TableSpinner`        | Loading row for a data table                        |
| `TextTruncate`        | Expands and collapses long text                     |
| `Time`                | Formats a date or time value                        |
| `TimeDistance`        | Displays relative time distance                     |
| `Timeline`            | Presents chronological events                       |
| `TypeEcho`            | Animates typed text                                 |
| `UserRankView`        | Displays ranked users                               |
| `VerticalMarquee`     | Vertically scrolls overflowing content              |
| `ZodiacBar`           | Displays zodiac signs for a year range              |

Core Bootstrap component wrappers are documented in the [component catalog][1]. Source files and
public API types are available in the [API reference][2].
