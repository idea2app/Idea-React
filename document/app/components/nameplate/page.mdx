# Nameplate

[`Nameplate`][1] pairs an [Avatar](../avatar/) with a person's name, for compact author or member
listings.

## Example

<LiveExample>
    <Nameplate name="idea2app" avatar="https://github.com/idea2app.png" />
</LiveExample>

## Usage

```tsx
<ul className="list-unstyled">
    {members.map(({ name, avatar }) => (
        <li key={name}>
            <Nameplate {...{ name, avatar }} />
        </li>
    ))}
</ul>
```
