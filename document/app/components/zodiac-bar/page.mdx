# Zodiac bar

[`ZodiacBar`][1] displays the Chinese zodiac sign for each year in a range, newest first, with an
optional link and title per year.

## Example

<ZodiacBar startYear={2020} endYear={2025} />

## Usage

```tsx
<ZodiacBar
    startYear={2008}
    endYear={2026}
    itemOf={(year, zodiac) => ({
        title: `${year} ${zodiac}`,
        link: `/events/${year}`
    })}
/>
```

`endYear` defaults to the current year. `itemOf` customizes each item's `title` and `link`, and
`itemClassName` restyles the year cards. The exported `zodiacOf(year)` helper returns the zodiac
emoji for any historical year.
