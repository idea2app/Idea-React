# Avatar

Documentation and examples for avatars, including image avatars, initials, status indicators, and avatar stacks.

Use `Avatar` for images, initials, and status indicators, `AvatarImage` for a standalone image, and
`AvatarStack` for overlapping groups. The `size`, `theme`, `subtle`, and `status` props generate the
Bootstrap classes described below.

## Examples

Avatars are used to represent users or entities. They can display an image or initials as a fallback.

### Image

Use `Avatar` with `AvatarImage` for image-based avatars. The parent `Avatar` element provides an easy wrapper for additional avatar features like status indicators and stacks. You’re welcome to use `AvatarImage` on its own if you only need a single HTML element.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <Avatar src="https://github.com/mdo.png" alt="mdo" />
    </div>
</DocumentCodeExample>

When used inside the `Avatar` wrapper, the image fills the wrapper and its size is set with `--bs-avatar-size`. Used on its own, `AvatarImage` honors its own `width` and `height` instead, so set them to your desired size.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <AvatarImage src="https://github.com/mdo.png" alt="mdo" width="50" height="50" />
    </div>
</DocumentCodeExample>

## Sizes

Avatars come in multiple sizes: extra small, small, default, large, and extra large.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <Avatar size="xs" src="https://github.com/mdo.png" alt="mdo" />
        <Avatar size="sm" src="https://github.com/mdo.png" alt="mdo" />
        <Avatar src="https://github.com/mdo.png" alt="mdo" />
        <Avatar size="lg" src="https://github.com/mdo.png" alt="mdo" />
        <Avatar size="xl" src="https://github.com/mdo.png" alt="mdo" />
    </div>
</DocumentCodeExample>

Use a custom size by modifying the `--bs-avatar-size` variable. The numeric `size` prop sets it in rem.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <Avatar src="https://github.com/mdo.png" alt="mdo" size={8} />
    </div>
</DocumentCodeExample>

## Status indicator

Set the `status` prop to show an indicator inside the avatar. Each status has a distinct shape and color:

- `online` — green circle
- `offline` — gray rounded square
- `busy` — red rounded square
- `away` — yellow circle

Because the status is conveyed purely through color and shape, provide a `statusLabel` (e.g. `Online`) so assistive technologies can announce it.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <Avatar src="https://github.com/mdo.png" alt="mdo" status="online" statusLabel="Online" />
        <Avatar src="https://github.com/mdo.png" alt="mdo" status="offline" statusLabel="Offline" />
        <Avatar src="https://github.com/mdo.png" alt="mdo" status="busy" statusLabel="Busy" />
        <Avatar src="https://github.com/mdo.png" alt="mdo" status="away" statusLabel="Away" />
    </div>
</DocumentCodeExample>

## Avatar stack

Use `AvatarStack` to group multiple avatars together with overlapping effect. Avatars are rendered in reverse order so the first avatar appears on top. Stacks use a percentage of the avatar size to determine how much to overlap stacked avatars.

<DocumentCodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <AvatarStack>
            <Avatar src="https://github.com/mdo.png" alt="mdo" />
            <Avatar src="https://github.com/mdo.png" alt="mdo" />
            <Avatar src="https://github.com/mdo.png" alt="mdo" />
            <Avatar src="https://github.com/mdo.png" alt="mdo" />
            <Avatar src="https://github.com/mdo.png" alt="mdo" />
        </AvatarStack>
    </div>
</DocumentCodeExample>

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

| CSS variable                      | Default                     |
| --------------------------------- | --------------------------- |
| `--bs-avatar-size`                | `2.5rem`                    |
| `--bs-avatar-border-radius`       | `50%`                       |
| `--bs-avatar-border-width`        | `2px`                       |
| `--bs-avatar-border-color`        | `var(--bs-bg-body)`         |
| `--bs-avatar-bg`                  | `var(--bs-bg-2)`            |
| `--bs-avatar-color`               | `var(--bs-fg-body)`         |
| `--bs-avatar-status-size`         | `0.75rem`                   |
| `--bs-avatar-status-border-width` | `2px`                       |
| `--bs-avatar-status-border-color` | `var(--bs-bg-body)`         |
| `--bs-avatar-stack-spacing`       | `-0.3`                      |
| `--bs-avatar-stack-transition`    | `transform .2s ease-in-out` |
