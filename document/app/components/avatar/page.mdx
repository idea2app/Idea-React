# Avatar

Avatars are used to represent users or entities. They can display an image or initials as a fallback.
Idea React provides the [`Avatar` and `AvatarStack` wrappers][1] for these examples.

## Examples

### Image

Use `.avatar` with an `.avatar-img` for image-based avatars. The parent `.avatar` element provides an
easy wrapper for additional avatar features like status indicators and stacks. You’re welcome to use
the `.avatar-img` class on its own if you only need a single HTML element.

<Avatar src="https://github.com/mdo.png" alt="mdo" />

When used inside the `.avatar` wrapper, the image fills the wrapper and its size is set with
`--bs-avatar-size`. Used on its own, `.avatar-img` honors its own `width` and `height` instead, so set
them to your desired size.

<Image className="avatar-img" src="https://github.com/mdo.png" alt="mdo" width={50} height={50} />

## Status indicator

Add a `.avatar-status` element inside the avatar to show a status indicator. Each status has a
distinct shape and color:

- `.status-online` — green circle
- `.status-offline` — gray rounded square
- `.status-busy` — red rounded square
- `.status-away` — yellow circle

Because the status is conveyed purely through color and shape, give each `.avatar-status` a
`role="img"` and an `aria-label` (e.g. `Online`) so assistive technologies can announce it. The
`status` prop renders the indicator and the accessible label automatically.

<div className="d-flex flex-wrap gap-2">
    <Avatar src="https://github.com/mdo.png" alt="mdo" status="online" />
    <Avatar src="https://github.com/mdo.png" alt="mdo" status="offline" />

## Avatar stack

Use `.avatar-stack` to group multiple avatars together with overlapping effect. Avatars are rendered
in reverse order so the first avatar appears on top. Stacks use a percentage of the avatar size to
determine how much to overlap stacked avatars.

<AvatarStack>
    <Avatar src="https://github.com/mdo.png" alt="mdo" />
    <Avatar src="https://github.com/mdo.png" alt="mdo" />
    <Avatar src="https://github.com/mdo.png" alt="mdo" />
    <Avatar src="https://github.com/mdo.png" alt="mdo" />
    <Avatar src="https://github.com/mdo.png" alt="mdo" />
</AvatarStack>

## CSS

Avatar sizes and status dimensions are defined by Bootstrap's CSS variables and the `$avatar-sizes`
Sass map. Each size specifies the avatar size and status size. See the [upstream avatar CSS][2] for
the variable and map reference.
