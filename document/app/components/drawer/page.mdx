# Drawer

Build hidden sidebars or drawers into your project for navigation, shopping carts, and more with a
few classes. Drawer replaces the old Offcanvas component.

Idea React provides the [`Drawer` wrapper][1], which composes the native `<dialog>` element, a
header with a close button, a body, and an optional footer. The examples below are interactive and
adapt the [upstream Drawer documentation][2].

## How it works

Drawer builds on the native `<dialog>` element and the [`NativeDialog` wrapper][3] to manage hidden
sidebars. These sidebars, or drawers, can appear from the left, right, top, or bottom edge of the
viewport.

- **Drawer shares the same base as the Dialog component**, using native `<dialog>` APIs for focus
  trapping, backdrop, and top-layer rendering.
- **Use the `<dialog>` element**, not a `<div>`. Due to how CSS handles animations, don't apply
  `margin` or `translate` directly to `.drawer`—wrap it if you need those.
- **Modal by default**—opens with `showModal()`, a backdrop, and focus trapping. Pass
  `modal={false}` and `backdrop={false}` to open as a non-modal drawer with `show()`: body scrolling
  stays on, and focus is not trapped.
- **Built-in backdrop** via `::backdrop` (modal only) closes the drawer on click; set
  `backdrop="static"` to lock clicks outside, or `backdrop={false}` to hide it.
- **Escape key handling** closes the drawer by default; set `keyboard={false}` to disable.
- **Only one drawer can be shown at a time**, because a modal native dialog holds the top layer.
- **Animated open and close**—drawer slides back out to its placement-specific off-screen position
  on close, with the `::backdrop` fading alongside it when opened modally. Add `.drawer-instant` to
  skip animations.

### Without JavaScript

Supported browsers can open and close a drawer with the [Invoker Commands API][4]—no JavaScript
required. Set `commandfor` to the drawer's `id`, use `command="show-modal"` to open, and
`command="close"` to dismiss.

The Invoker Commands API is not supported in all browsers. Pass `open` and `onDismiss` to control the
drawer through React state as in the examples above when you need consistent behavior or an animated
close.

```tsx
<button type="button" className="btn-solid theme-primary" commandfor="invokerDrawer" command="show-modal">
    Open drawer
</button>

<dialog className="drawer drawer-start" id="invokerDrawer" aria-labelledby="invokerDrawerLabel">
    <div className="drawer-header">
        <h5 className="drawer-title" id="invokerDrawerLabel">Invoker Commands</h5>
        <button
            type="button"
            className="btn-close"
            commandfor="invokerDrawer"
            command="close"
            aria-label="Close"
        />
    </div>
    <div className="drawer-body">
        <p>This drawer opens with `command="show-modal"` and closes with `command="close"`.</p>
    </div>
</dialog>
```

### Body scrolling

Scrolling the `<body>` element is disabled when a drawer opens modally. Use `modal={false}` with
`backdrop={false}` to keep body scrolling and open the drawer as non-modal. Focus moves into the
drawer, but is not trapped, so the page stays interactive.

## Sheet

Add `.drawer-sheet` to render the panel flush against the viewport edge. The sheet variant removes
the drawer's inset, border, border-radius, and box-shadow, so it sits edge-to-edge like a traditional
offcanvas. It works with any placement.

## Accessibility

Since the drawer is a native `<dialog>`, it gets the correct `dialog` role. Modal drawers also get
modal semantics and focus trapping from `showModal()`. Non-modal drawers (`modal={false}` and
`backdrop={false}`) use `show()` instead, so they do not trap focus or mark the rest of the page as
inert. The wrapper sets `aria-label` from a string `title`; pass `aria-label` or `aria-labelledby`
yourself when the title is not a string.

## Usage

The `Drawer` wrapper composes the classes and attributes that the upstream plugin handles:

- `.drawer` and `.drawer-{placement}` on a `<dialog>` element enable drawer behavior.
- The header contains `Drawer`'s `title` and a `CloseButton` that calls `onDismiss`.
- `footer` renders a `.drawer-footer`; `bodyClassName` extends the `.drawer-body`.
- Additional classes such as `drawer-instant`, `drawer-translucent`, and `drawer-sheet` pass through
  `className`.

Set `open` and `onDismiss` to control the drawer through React state. The native dialog keeps
`onClose` in sync when the user closes the drawer with Escape or a backdrop click.

| Name            | Type                                  | Default | Description                                                                  |
| --------------- | ------------------------------------- | ------- | ---------------------------------------------------------------------------- |
| `title`         | `ReactNode`                           |         | Header content; a string also becomes the drawer's `aria-label`.             |
| `placement`     | `start` \| `end` \| `top` \| `bottom` | `end`   | Edge of the viewport the drawer slides in from.                              |
| `footer`        | `ReactNode`                           |         | Content rendered in `.drawer-footer`.                                        |
| `bodyClassName` | `string`                              |         | Extra classes for `.drawer-body`.                                            |
| `onDismiss`     | `() => void`                          |         | Called when the close button, Escape, or a backdrop click closes the drawer. |
| `theme`         | `light` \| `dark`                     |         | Sets `data-bs-theme` on the dialog.                                          |
| `modal`         | `boolean`                             | `true`  | Opens with `showModal()` (focus trap and top layer) or `show()`.             |
| `backdrop`      | `boolean` \| `static`                 | `true`  | Shows a backdrop; `static` prevents closing when clicking outside.           |
| `keyboard`      | `boolean`                             | `true`  | Closes the drawer when Escape is pressed.                                    |

## CSS

Drawer styling uses Bootstrap's `.drawer` CSS variables for width, height, padding, background,
border, radius, shadow, and animation. Backdrop tokens style the native `::backdrop` pseudo-element.
See the [upstream drawer CSS][5] for the variable and Sass reference.
