# Drawer

Build hidden sidebars or drawers into your project for navigation, shopping carts, and more with React props and the native dialog API. Replaces the old Offcanvas component.

## How it works

Drawer builds on the native `<dialog>` element and our Dialog component to manage hidden sidebars via JavaScript. These sidebars, or drawers, can appear from the left, right, top, or bottom edge of the viewport. Buttons or anchors are used as triggers that are attached to specific elements you toggle, and React state controls the `open` prop.

- **Drawer shares the same base as [our Dialog component][1]**, using native `<dialog>` APIs for focus trapping, backdrop, and top-layer rendering.
- **Use the `<dialog>` element**, not a `<div>`. The wrapper renders this element. Due to how CSS handles animations, don’t apply `margin` or `translate` directly to `Drawer` — wrap it if you need those.
- **Modal by default** — opens with `showModal()`, a backdrop, and focus trapping. Set `scroll: true` and `backdrop: false` to open as a non-modal drawer with `show()`: body scrolling stays on, and focus is not trapped.
- **Built-in backdrop** via `::backdrop` (modal only) closes the drawer on click; set `backdrop: "static"` to lock clicks outside, or `backdrop: false` to hide it.
- **Escape key handling** closes the drawer by default; set `keyboard: false` to disable.
- **Dismissal** — the close button, Escape, and backdrop click close the drawer. The React wrapper does not currently implement the upstream swipe-to-dismiss gesture.
- **Responsive placement** — `responsive="sm"`, `responsive="md"`, and up stay drawer-like below their breakpoint and collapse inline above it, making drawers useful as responsive navbars.
- **Coordinate open drawers** through application state if only one should be shown at a time; the React wrapper does not use Bootstrap’s data API.
- **Animated open and close** — drawer slides back out to its placement-specific off-screen position on close, with the `::backdrop` fading alongside it when opened modally. When authoring custom CSS, qualify your `[open]` rules with `:not(.hiding)` so the exit transition can fall through to the base state; pass `animation="instant"` to skip animations.

The animation effect of this component is dependent on the `prefers-reduced-motion` media query.

### Without JavaScript

Supported browsers can open and close a drawer with the [Invoker Commands API][2]—no Bootstrap JavaScript required. Set `commandFor` to the drawer’s `id`, use `command="show-modal"` to open, and `command="close"` to dismiss.

The Invoker Commands API is not supported in all browsers. For guaranteed support, use React-controlled `open` and `onDismiss`, as in the examples above, when you need wrapper options, callbacks, or animated close.

<CodeExample>
    <Button
        variant="solid"
        theme="primary"
        {...{ commandfor: 'invokerDrawer', command: 'show-modal' }}
    >
        Open drawer
    </Button>
    <Drawer id="invokerDrawer" title="Invoker Commands" placement="start">
        <p>
            This drawer opens with <code>command="show-modal"</code>.
        </p>
        <Button
            variant="solid"
            theme="secondary"
            {...{ commandfor: 'invokerDrawer', command: 'close' }}
        >
            Close drawer
        </Button>
    </Drawer>
</CodeExample>

### Body scrolling

Scrolling the `<body>` element is disabled when a drawer opens modally. Pass `scroll` with `backdrop={false}` to keep body scrolling and open the drawer as non-modal. Focus moves into the drawer, but is not trapped, so the page stays interactive.

## Responsive

Responsive drawers hide content outside the viewport from a specified breakpoint and down. Above that breakpoint, the contents within will behave as usual. For example, `responsive="lg"` hides content in a drawer below the `lg` breakpoint, but shows the content above the `lg` breakpoint. Responsive drawers are available for each breakpoint.

To make a responsive drawer, set the `responsive` breakpoint prop. The wrapper wires its close button without an explicit target.

<CodeExample>
    <DrawerDemo
        label="Toggle responsive drawer"
        title="Responsive drawer"
        placement="end"
        responsive="lg"
    >
        This drawer becomes inline content above the lg breakpoint. Resize the browser to see the
        change.
    </DrawerDemo>
</CodeExample>

## Placement

Choose a `placement` for the drawer. Idea React defaults to `"end"`.

- `placement="start"` places drawer on the left of the viewport (shown above)
- `placement="end"` places drawer on the right of the viewport
- `placement="top"` places drawer on the top of the viewport
- `placement="bottom"` places drawer on the bottom of the viewport
- `fullscreen` covers the entire viewport

## Accessibility

Since the drawer is a native `<dialog>`, it gets the correct `dialog` role. Modal drawers also get modal semantics and focus trapping from `showModal()`. Non-modal drawers (`scroll: true` and `backdrop: false`) use `show()` instead, so they do not trap focus or mark the rest of the page as inert. The wrapper supplies `aria-label` for a string `title`. When supplying custom title markup, provide an accessible `aria-label` or `aria-labelledby`.

## Usage

Control `open` with React state and keep it synchronized through `onDismiss`. Native dialog behavior is supplied by `NativeDialog`.

### Options

| Prop         | Default   | Description                                                                                       |
| ------------ | --------- | ------------------------------------------------------------------------------------------------- |
| `placement`  | `"end"`   | Position the panel at `start`, `end`, `top`, or `bottom`.                                         |
| `backdrop`   | `true`    | Close on an outside click; `"static"` prevents outside dismissal, and `false` hides the backdrop. |
| `keyboard`   | `true`    | Close when Escape is pressed.                                                                     |
| `scroll`     | `false`   | Allow body scrolling; combine with `backdrop={false}` for a non-modal drawer.                     |
| `animation`  | `"slide"` | Choose the sliding transition or `"instant"`.                                                     |
| `responsive` | —         | Display inline above the selected breakpoint.                                                     |

### Events

`onDismiss()` runs when the drawer is dismissed by its close button, Escape, or a backdrop click. Use it to update the controlled `open` value.
