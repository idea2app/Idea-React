# Bootstrap components

Bootstrap 6 provides a comprehensive set of responsive interface components. This catalog mirrors
the upstream component groups and links the wrappers available in Idea React to their local guides.
Components without a React wrapper link to the [official Bootstrap documentation][1].

### All Bootstrap components

Accordion, Alert, Avatar, Badge, Breadcrumb, Button, Button group, Card, Carousel, Close button,
Collapse, Dialog, Drawer, List group, Menu, Nav, Nav overflow, Navbar, Pagination, Placeholder,
Popover, Progress, Scrollspy, Spinner, Stepper, Tab, Toasts, Toggler, and Tooltip.

### Idea React extensions

Idea React also includes components without a direct Bootstrap equivalent. See the [extension
catalog][2] for the complete public component list and quick descriptions.

The component guides adapt the corresponding Bootstrap 6 alpha documentation for this library.
