# Bootstrap components

Bootstrap 6 provides a comprehensive set of responsive interface components. This catalog mirrors
the component groups in [Bootstrap v6.0.0-alpha.1][1]. All upstream component groups have React
wrappers and local guides, including interactive behavior and the documented visual variants.

### Built-in wrappers

| Component          | Notes                                                          |
| ------------------ | -------------------------------------------------------------- |
| [Accordion][2]     | Native exclusive, always-open, compact, and nested disclosures |
| [Alert][3]         | Contextual feedback with optional dismissal                    |
| [Avatar][4]        | [Image][5] or initials avatars with status and stacks          |
| [Badge][6]         | Themed status labels and counters                              |
| [Breadcrumb][7]    | Location hierarchy with custom dividers                        |
| [Button][8]        | Native buttons and links with themes                           |
| [Button group][9]  | Grouped buttons, toolbars, and toggle groups                   |
| [Card][10]         | Flexible content containers with headers and footers           |
| [Carousel][11]     | Slides, indicators, captions, controls, and autoplay           |
| [Close button][12] | Dismiss controls for overlays and drawers                      |
| [Collapse][13]     | Vertical or horizontal panels with synchronized triggers       |
| [Dialog][14]       | Native dialog element and promise-based model                  |
| [Drawer][15]       | Edge-aligned dialogs for navigation and panels                 |
| [List group][16]   | Stacked content, actions, variants, and layouts                |
| [Menu][17]         | Keyboard-accessible contextual menus                           |
| [Nav][18]          | [Tabs][19], pills, underline, and vertical navigation          |
| [Nav overflow][20] | Overflow-aware horizontal navigation                           |
| [Navbar][21]       | Responsive navigation landmark                                 |
| [Pagination][22]   | Themed page links with active and disabled states              |
| [Placeholder][23]  | Sized, colored, animated loading skeletons                     |
| [Popover][24]      | Rich contextual overlays                                       |
| [Progress][25]     | Accessible, stacked, striped, and animated bars                |
| [Scrollspy][26]    | Active navigation tracking for scrolling sections              |
| [Spinner][27]      | Border and growing loading indicators                          |

| [Tab][19]          | Keyboard-accessible tabbed panels                              |
| [Toasts][29]       | Themed notifications with dismissal                            |
| [Toggler][30]      | Class and attribute toggles for one or many targets            |
| [Tooltip][31]      | Accessible text hints                                          |

See the separate [Forms guide][32] for the Bootstrap form components.

### Root elements

Single-root components accept `as` to select an HTML tag or another React component:

```tsx
<Card as="article" aria-label="News">
    <CardTitle as="h2">Latest news</CardTitle>
</Card>

<Button as={RouterLink} to="/docs" theme="primary">
    Documentation
</Button>
```

The selected component's additional props are inferred and forwarded, including required props.
Idea React's own props keep their meaning when names overlap. Custom roots must forward DOM props
and refs, and preserve the native capabilities required by behavioral components. Class component
refs still reference the instance. Fragment-root and multiple-root components are excluded.

### Idea React extensions

Idea React also includes components without a direct Bootstrap equivalent. See the [extension
catalog][33] for the complete public component list and quick descriptions.
Additional Bootstrap layout and content wrappers cover [Grid][34], [Images][5], and [Tables][35].
