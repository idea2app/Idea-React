# Scroll nav

[`ScrollNav`][1] is a horizontally scrollable navigation bar based on Bootstrap's `nav-scroller`
pattern. Arrow buttons appear automatically when the items overflow the container width.

## Behavior

The component tracks scroll position and container size with a `ResizeObserver`, showing a left or
right caret button only when more content is available in that direction. Each click scrolls by 80%
of the visible width with smooth scrolling.
