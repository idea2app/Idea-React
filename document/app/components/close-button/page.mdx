# Close button

A generic close button for dismissing content like modals and alerts.

`CloseButton` supplies the close-button styles, a default `type="button"`, and the accessible
label “Close”. Pass an `onClick` handler when wiring it to your own dismissible content.

## Example

Provide an option to dismiss or close a component with `.btn-close`. The icon is rendered with a CSS `mask-image`, so it inherits the `color` from the `.btn-close` class—no inline SVG required. **Be sure to include text for screen readers**, as we’ve done with `aria-label`.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <CloseButton type="button" aria-label="Close" />
    </div>
</CodeExample>

## Disabled state

Disabled close buttons change their `opacity`. We’ve also applied `pointer-events: none` and `user-select: none` to preventing hover and active states from triggering.

<CodeExample>
    <div className="d-flex flex-wrap gap-2 align-items-center">
        <CloseButton type="button" disabled aria-label="Close" />
    </div>
</CodeExample>

## Dark variant

Add `data-bs-theme="dark"` to the `.btn-close`, or to its parent element, to invert the close button. This happens automatically when in dark mode.

<CodeExample>
    <div className="bg-inverse">
        <div data-bs-theme="dark">
            <CloseButton type="button" aria-label="Close" />
            <CloseButton type="button" disabled aria-label="Close" />
        </div>
    </div>
</CodeExample>

## CSS

### Variables

Customize the component with the following local CSS variables. Override them through the wrapper’s `style` prop or your own CSS module.

| CSS variable                      | Default          |
| --------------------------------- | ---------------- |
| `--bs-btn-close-size`             | `1.25rem`        |
| `--bs-btn-close-color`            | `inherit`        |
| `--bs-btn-close-icon`             | `SVG mask image` |
| `--bs-btn-close-opacity`          | `0.5`            |
| `--bs-btn-close-hover-opacity`    | `0.75`           |
| `--bs-btn-close-focus-opacity`    | `0.85`           |
| `--bs-btn-close-disabled-opacity` | `0.25`           |
